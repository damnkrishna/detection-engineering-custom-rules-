### 1. Technique Breakdown: T1204.003

* What it is: User Execution: Malicious Image. In Cloud/IaaS environments (AWS, GCP, Azure), adversaries or malicious insiders may launch a new Virtual Machine or instance from a non-approved, newly-created, or publicly shared malicious machine image (like an AMI).
* Log Source Requirements: Cloud control plane logs (AWS CloudTrail, Azure Activity Logs, GCP Audit Logs), which are not allowed log sources.
* Coverage Check:
  * HIDS (Sysmon + Windows Defender): NO. Host-level agents cannot detect the launch of a new VM instance from the cloud control plane itself.
  * Windows Security Logs: NO. Standard Windows Security Logs (service: security) do not capture cloud control plane API calls or machine image properties.
* Conclusion: This technique is not detectable from Sysmon, Windows Security, or Defender logs.
