### 1. Technique Breakdown: T1204.004

* What it is: User Execution: Malicious Copy and Paste. Adversaries socially engineer users into copying an obfuscated command from a website, document, or email, and pasting it directly into a terminal interface (like CMD or PowerShell), initiating remote access or payload downloads.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Parent-child process relationships and terminal command-line parameters are tracked.
  - NIDS (Suricata + Zeek): YES. Egress downloads initiated by the terminal can be flagged.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Command Shell Spawned from User Application Context (AN0962-A)
id: 13c919b6-61ae-43da-8bf9-f58d5c89404b
status: experimental
description: Detects command-line interpreters or script hosts spawned directly by browsers, mail agents, or document viewers.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_parents:
        ParentImage|endswith:
            - '\chrome.exe'
            - '\msedge.exe'
            - '\firefox.exe'
            - '\outlook.exe'
            - '\excel.exe'
            - '\winword.exe'
            - '\acrord32.exe'
    selection_images:
        Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\wscript.exe'
            - '\cscript.exe'
            - '\mshta.exe'
    selection_cli:
        CommandLine|contains:
            - ' -enc '
            - ' -encodedcommand '
            - 'iex'
            - 'downloadstring'
            - 'downloadfile'
            - 'bypass'
            - '-nop'
            - '-w hidden'
    condition: selection_parents and selection_images and selection_cli
fields:
    - Image
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - IT administrators testing script integration or standard software help files opening diagnostic cmd windows.
level: high
tags:
    - attack.execution
    - attack.t1204.004
    - analytic.an0962
    - detection.det0340
```

title: Download Utility Spawned by User Application (AN0962-B)

    - Image
    - CommandLine
    - ParentImage
    - User

    - Software install updates triggered from web interface redirects.
level: medium

    - attack.execution
    - attack.t1204.004
    - analytic.an0962
    - detection.det0340
