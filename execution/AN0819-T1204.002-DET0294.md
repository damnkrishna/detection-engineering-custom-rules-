### 1. Technique Breakdown: T1204.002

* What it is: User Execution: Malicious File. Adversaries rely on a user opening a malicious file (e.g., an Office document, PDF, script, or executable) delivered via email, USB, or download. When opened, the file exploits a vulnerability, runs macros, or directly executes malicious code. This typically manifests as a user-facing application (Word, archiver) dropping payloads into user-controlled paths and spawning script engines.
* Log Source Requirements: Process creation logs (Sysmon Event ID 1) and File Creation logs (Sysmon Event ID 11).
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES. Sysmon tracks the execution chain (e.g., WinRAR spawning a `.bat` file) and files dropped into `Downloads` or `Temp`.
    * NIDS (Suricata + Zeek): PARTIAL. NIDS can detect the malicious file being downloaded (e.g., analyzing an unencrypted email attachment or HTTP download), but not the local execution.

### 2. Custom Sigma Rule

```yaml
title: User Execution - Malicious File Opened (AN0819)
id: 60992d85-e2d7-4272-ac44-9718acebda58
status: experimental
description: Detects a handler application (archiver, Office, PDF reader) spawning a new or unusual child process, indicating execution of a malicious file.
author: Krishna Gupta
date: 2026-06-09
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_parent:
        ParentImage|endswith:
            - '\winrar.exe'
            - '\7zFM.exe'
            - '\winzip64.exe'
            - '\explorer.exe'
            - '\winword.exe'
            - '\excel.exe'
            - '\AcroRd32.exe'
    selection_child:
        Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\wscript.exe'
            - '\cscript.exe'
            - '\mshta.exe'
            - '\regsvr32.exe'
            - '\rundll32.exe'
            - '\msiexec.exe'
    condition: selection_parent and selection_child
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Users legitimately extracting installer scripts from archives and running them.
    - Approved enterprise macros running administrative commands.
level: high
tags:
    - attack.execution
    - attack.t1204.002
    - analytic.an0819
    - detection.det0294
```
