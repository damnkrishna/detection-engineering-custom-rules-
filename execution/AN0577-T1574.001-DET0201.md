### 1. Technique Breakdown: T1574.001

* What it is: Hijack Execution Flow: DLL Side-Loading. Adversaries abuse the Windows search order for shared libraries (DLLs) to execute malicious payloads. By copying a legitimate, signed system binary (like calc.exe or notepad.exe) into a user-writable directory (like %TEMP% or C:\Users\Public\) and placing a malicious DLL named after a required system dependency in that same directory, the application will load the malicious DLL instead of the legitimate one from System32.
* Log Source Requirements: Endpoint logs capturing image/library loading events and file write events in user-writable paths.
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 7 (Image Load) logs when DLLs are loaded by system binaries running from non-standard paths, and Event ID 11 (File Event) logs when DLLs are written to these paths.
* NIDS (Suricata + Zeek): NO. Local host activity.
* Log Sources Covered:
  - Sysmon Event ID 7 (image_load)
  - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

The detection logic is split into monitoring DLL library load events by system utilities executing from suspicious paths, and file events capturing DLL writes to temporary or public directories.

Rule 1 of 2: DLL Side-Loading Image Load (Image Load)
```yaml
title: DLL Side-Loading Image Load (AN0577)
id: d58f7c8e-3c2f-4d92-8c8d-6f7d8e9a0b0d
status: experimental
description: Detects legitimate Windows system utilities loading libraries from temporary or user-writable paths, indicating potential DLL side-loading.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: image_load
    product: windows
detection:
    selection_system_binaries:
        - Image|endswith:
            - '\calc.exe'
            - '\notepad.exe'
            - '\svchost.exe'
            - '\cmd.exe'
            - '\powershell.exe'
            - '\wscript.exe'
            - '\cscript.exe'
            - '\regsvr32.exe'
            - '\rundll32.exe'
            - '\odbcconf.exe'
            - '\gpupdate.exe'
            - '\taskhost.exe'
            - '\wsmprovhost.exe'
        - OriginalFileName:
            - 'calc.exe'
            - 'NOTEPAD.EXE'
            - 'svchost.exe'
            - 'cmd.exe'
            - 'PowerShell.EXE'
            - 'wscript.exe'
            - 'cscript.exe'
            - 'regsvr32.exe'
            - 'RUNDLL32.EXE'
            - 'odbcconf.exe'
            - 'gpupdate.exe'
            - 'taskhost.exe'
            - 'wsmprovhost.exe'
    selection_suspicious_paths:
        ImageLoaded|contains:
            - '\AppData\Local\Temp\'
            - '\Users\Public\'
            - '\Windows\Temp\'
            - '\AppData\Roaming\'
            - '\ProgramData\'
    condition: selection_system_binaries and selection_suspicious_paths
fields:
    - Image
    - ImageLoaded
    - Signed
    - SignatureStatus
falsepositives:
    - Legacy applications running local copies of system utilities loading local modules.
level: high
tags:
    - attack.execution
    - attack.persistence
    - attack.privilege-escalation
    - attack.t1574.001
    - analytic.an0577
    - detection.det0201
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Command Line Obfuscation
  * The Issue: Adversaries can obfuscate command-line arguments using environment variables, caret escapes (^), or base64 encoding, evading simple string matching.
  * The Fix: Implement PowerShell Script Block Logging and utilize regex or script-decoding scripts in the SIEM to check arguments.

* Problem 2: Administrative Activity Noise
  * The Issue: IT administrators legitimately run command-line tools or installers that trigger these rules during system maintenance.
  * The Fix: Establish a baseline of legitimate admin tools, whitelisting specific administrative account names or management servers.

* Problem 3: Masquerading via Renamed Binaries
  * The Issue: Attackers rename native Windows utilities (such as net.exe or cmd.exe) to custom filenames to bypass path-based filters.
  * The Fix: Incorporate Masquerade-resistant criteria, matching on OriginalFileName rather than the static Image path in process creation logs.
