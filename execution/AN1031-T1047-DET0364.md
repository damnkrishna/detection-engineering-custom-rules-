### 1. Technique Breakdown: T1047

* What it is: Windows Management Instrumentation. Adversaries abuse WMI to execute local or remote commands, retrieve system information, deploy files, or create persistent backdoors.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. WMI host execution activities and process creation lineage are captured.
  - NIDS (Suricata + Zeek): YES. RPC/WMI remote protocols can be identified on ports 135/445.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Suspicious Process Spawned by WMI Host (AN1031-A)
id: 2fea2eb6-70e3-47ac-8c08-e24744760aa7
status: experimental
description: Detects command-line shells or script hosts spawned as child processes of the WMI Provider Host, indicating WMI-based code execution.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_parents:
        ParentImage|endswith:
            - '\wmiprvse.exe'
            - '\scrcons.exe'
    selection_images:
        Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\wscript.exe'
            - '\cscript.exe'
            - '\mshta.exe'
            - '\rundll32.exe'
    filter_agents:
        Image|endswith:
            - '\ccmexec.exe'
            - '\lswagent.exe'
            - '\taniumclient.exe'
            - '\monitoringhost.exe'
    condition: selection_parents and selection_images and not filter_agents
fields:
    - Image
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - IT management software (SCCM, LanSweeper, monitoring agents) executing standard queries or deploying packages.
level: medium
tags:
    - attack.execution
    - attack.t1047
    - analytic.an1031
    - detection.det0364
```

```yaml
title: WMIC CommandLine Process Creation Invitation (AN1031-B)
id: 4019906e-d5aa-44d7-8f45-6aa98bdd0fa2
status: experimental
description: Detects command-line execution of wmic.exe initiating process creations or altering shadow copies.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\wmic.exe'
    selection_orig:
        OriginalFileName:
            - 'wmic.exe'
    selection_cli:
        CommandLine|contains:
            - 'process call create'
            - 'shadowcopy delete'
            - 'useraccount'
            - 'sysenvironment'
    condition: (selection_images or selection_orig) and selection_cli
fields:
    - Image
    - CommandLine
    - User
falsepositives:
    - Administrative automation scripts gathering asset intelligence.
level: medium
tags:
    - attack.execution
    - attack.t1047
    - analytic.an1031
    - detection.det0364
```
