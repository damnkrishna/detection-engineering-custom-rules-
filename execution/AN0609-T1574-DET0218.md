### 1. Technique Breakdown: T1574

* What it is: Hijack Execution Flow. Adversaries modify the environment Windows uses to locate and execute programs (such as DLL load paths, service binary configurations, or application pathways) to hijack execution flow. By changing the binPath of a service, pointing a service's ServiceDll registry key to a malicious module, or modifying Image File Execution Options (IFEO) registry keys, they force system processes or applications to run their payload.
* Log Source Requirements: Endpoint logs capturing process creation and registry modifications.
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 (Process Creation) logs configuration utilities like sc.exe and reg.exe, and Event ID 13 (Registry Set) logs direct service path or IFEO debugger registry writes.
* NIDS (Suricata + Zeek): NO. Local host configurations.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 13 (registry_set)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Service Execution Flow Hijacking via CLI (AN0609)
id: ea43ef50-bcc6-4f82-8ed8-7b38f1c92a2b
status: experimental
description: Detects command-line service modifications or registry additions that alter the execution flow of system services (such as modifying service binPath or adding custom ServiceDlls).
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
detection:
    selection_sc:
        - Image|endswith: '\sc.exe'
        - OriginalFileName: 'sc.exe'
    selection_sc_args:
        CommandLine|contains|all:
            - 'config'
            - 'binpath'
    selection_reg:
        - Image|endswith:
            - '\reg.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
        - OriginalFileName:
            - 'reg.exe'
            - 'PowerShell.EXE'
            - 'pwsh.dll'
    selection_reg_args:
        CommandLine|contains|all:
            - 'System\CurrentControlSet\Services'
            - 'add'
        CommandLine|contains:
            - 'ImagePath'
            - 'ServiceDll'
    condition: (selection_sc and selection_sc_args) or (selection_reg and selection_reg_args)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate software installers configuring service binary paths during application deployment.
level: high
tags:
    - attack.execution
    - attack.persistence
    - attack.privilege-escalation
    - attack.t1574
    - analytic.an0609
    - detection.det0218
```
