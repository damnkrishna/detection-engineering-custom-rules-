### 1. Technique Breakdown: T1204

* What it is: User Execution. Adversaries rely on user actions (such as opening malicious email attachments, clicking malicious links, or launching zip/archive files) to initiate code execution.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Parent-child process relationships starting from user productivity software or archive managers are monitored.
  - NIDS (Suricata + Zeek): YES. Egress downloads or remote control connections initiated from user desktops can be analyzed.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

#### Rule 1 of 2: Office Application Spawning Living-off-the-Land Binaries
Detects Microsoft Office or PDF reader processes spawning command shells, installer tools, script hosts, or DLL registration helpers.

```yaml
title: Office Application Spawning Living-off-the-Land Binaries (AN1314-A)
id: f023d881-819a-44f2-9ca0-80ef522f0022
status: experimental
description: Detects command shells or administrative LOLBINs spawned directly by Office or PDF viewer parent processes.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_parents:
        ParentImage|endswith:
            - '\winword.exe'
            - '\excel.exe'
            - '\powerpnt.exe'
            - '\acrord32.exe'
    selection_images:
        Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\mshta.exe'
            - '\msiexec.exe'
            - '\rundll32.exe'
            - '\cscript.exe'
            - '\wscript.exe'
            - '\regsvr32.exe'
    condition: selection_parents and selection_images
fields:
    - Image
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Office plugins or document helpers initiating authorized application integrations.
level: critical
tags:
    - attack.execution
    - attack.t1204
    - analytic.an1314
    - detection.det0478
```

#### Rule 2 of 2: Archiver Spawning Scripting Hosts or Command Shells
Detects compression and archiving applications (7-Zip, WinRAR, WinZip) spawning command shells or script hosts.

```yaml
title: Archiver Spawning Scripting Hosts or Command Shells (AN1314-B)
id: cbdf2001-a189-4db8-bb9a-7c9802cf0023
status: experimental
description: Detects command shells or scripting engines launched directly by archive managers.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_parents:
        ParentImage|endswith:
            - '\winrar.exe'
            - '\7zfm.exe'
            - '\7zg.exe'
            - '\winzip64.exe'
    selection_images:
        Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\mshta.exe'
            - '\wscript.exe'
            - '\cscript.exe'
    condition: selection_parents and selection_images
fields:
    - Image
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Users launching administrative scripts from extracted zip archives during manual setup tasks.
level: high
tags:
    - attack.execution
    - attack.t1204
    - analytic.an1314
    - detection.det0478
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Manual Software Installers
  * The Issue: IT staff extracting software installation zip archives and executing script configurations will trigger Rule 2.
  * The Fix: Exclude specific administrative workstations or rely on SIEM-side whitelists for authorized software installation directories.
* Problem 2: Evasion via Temp Directory Drops
  * The Issue: If the document or archiver drops a compiled executable binary and launches it, rather than spawning standard built-in shells, this rule will not trigger.
  * The Fix: Monitor process creation events in temp directories referencing unsigned executables.
