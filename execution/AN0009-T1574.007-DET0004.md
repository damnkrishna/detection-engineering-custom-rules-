### 1. Technique Breakdown: T1574.007

* What it is: Hijack Execution Flow: Path Interception by PATH Environment Variable. Adversaries modify the Windows `PATH` environment variable to intercept execution flows. By appending a user-writable folder (like `%TEMP%` or a local program path) to the beginning of the `PATH` variable, the operating system will search that folder first when launching executables. If an administrator or service runs a system tool (like `taskkill` or `ping`) without specifying the full path, the OS will load and execute the attacker's malicious binary of the same name.
* Log Source Requirements: Endpoint logs capturing process creation and command line parameters (specifically targeting tools that modify system environment variables).
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 (Process Creation) logs the execution of utilities like `setx.exe`, `reg.exe`, or PowerShell command-lines modifying environment configurations.
* NIDS (Suricata + Zeek): NO. Environment variable configuration is a local operating system task. It generates no network logs.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 13 (registry_set)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Environment PATH Variable Modification via CLI (AN0009)
id: 2cbe9063-81e8-4368-9505-8adc6b7f6527
status: experimental
description: Detects command-line modifications to the system or user environment PATH variables using setx.exe, reg.exe, or PowerShell, which may indicate path interception attempts.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_setx:
        - Image|endswith: '\setx.exe'
        - OriginalFileName: 'setx.exe'
    selection_setx_args:
        CommandLine|contains:
            - ' path '
            - ' PATH '
    selection_reg:
        - Image|endswith:
            - '\reg.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
        - OriginalFileName:
            - 'reg.exe'
            - 'PowerShell.EXE'
            - 'pwsh.dll'
    selection_reg_args:
        CommandLine|contains:
            - 'Session Manager\Environment'
            - '\Environment'
        CommandLine|contains:
            - 'add'
            - 'SetEnvironmentVariable'
            - 'Path'
    condition: (selection_setx and selection_setx_args) or (selection_reg and selection_reg_args)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate software installers configuring paths during system integration or administrative path updates.
level: medium
tags:
    - attack.execution
    - attack.persistence
    - attack.privilege-escalation
    - attack.t1574.007
    - analytic.an0009
    - detection.det0004
```
