### 1. Technique Breakdown: T1559.002

* What it is: Inter-Process Communication: Dynamic Data Exchange. Adversaries abuse the DDE protocol in Microsoft Office applications to execute shell commands or run malicious scripts without utilizing macro structures.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688, and Sysmon Registry Set events (Event ID 13).
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. SCM child processes spawned by Office and registry edits enabling DDE execution are tracked.
  - NIDS (Suricata + Zeek): NO. Host-local application communication.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 13 (registry_set)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Office Application Spawning Shell via DDE (AN1393-A)
id: 67e74e2d-8dd2-4c0f-9b84-50bbe2741b75
status: experimental
description: Detects Office binaries launching cmd/powershell shells, suggesting active DDE code execution.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_parents:
        ParentImage|endswith:
            - '\winword.exe'
            - '\excel.exe'
            - '\powerpnt.exe'
    selection_images:
        Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\mshta.exe'
            - '\wscript.exe'
            - '\cscript.exe'
    condition: selection_parents and selection_images
fields:
    - Image
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Automated document updates containing legacy administrative macros (uncommon).
level: critical
tags:
    - attack.execution
    - attack.t1559.002
    - analytic.an1393
    - detection.det0504
```

```yaml
title: Registry Modification Enabling DDE Execution (AN1393-B)
id: 1a03304e-e25c-456b-9a1c-29191e9edeaa
status: experimental
description: Detects registry edits enabling AllowDDE or overriding DDE protection flags.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: registry_set
    product: windows
detection:
    selection_registry:
        TargetObject|contains:
            - '\Word\Options\AllowDDE'
            - '\Excel\Options\AllowDDE'
            - '\Word\Security\AllowDDE'
    selection_details:
        Details:
            - 'DWORD (0x00000001)'
            - '1'
    condition: selection_registry and selection_details
fields:
    - TargetObject
    - Details
    - Image
    - User
falsepositives:
    - IT administrators configuring group policies to enable legacy support for older documents.
level: high
tags:
    - attack.execution
    - attack.t1559.002
    - analytic.an1393
    - detection.det0504
```
