### 1. Technique Breakdown: T1569

* What it is: System Services. Adversaries may abuse system services for execution by modifying existing services or creating new ones. This allows them to execute binaries with `SYSTEM` privileges, load kernel drivers, or establish persistence. Commonly abused tools include `sc.exe`, PowerShell, or direct Win32 API calls (e.g., `CreateServiceW`).
* Log Source Requirements: Process creation logs (Sysmon Event ID 1 / Windows Security Event ID 4688), Windows System Log (Event ID 7045 - Service Created), and Registry modifications (Sysmon ID 12/13).
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES. Sysmon tracks `sc.exe` process execution and registry modifications under `HKLM\System\CurrentControlSet\Services`. System Event ID 7045 logs explicit service creation.
    * NIDS (Suricata + Zeek): NO. Service modification is an operating system-level configuration change.

### 2. Custom Sigma Rule

```yaml
title: System Service Creation or Modification (AN0778)
id: 901d7a6c-9fa9-449e-946e-f948c90cf314
status: experimental
description: Monitor for abnormal creation or modification of Windows services (e.g., via sc.exe) that load non-standard executables.
author: Krishna Gupta
date: 2026-06-09
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_sc:
        Image|endswith: '\sc.exe'
    selection_action:
        CommandLine|contains:
            - ' create '
            - ' config '
    selection_suspicious_paths:
        CommandLine|contains:
            - 'binPath='
            - '.bat'
            - '.ps1'
            - '\Temp\'
            - '\Users\Public\'
            - 'C:\ProgramData\'
    condition: selection_sc and selection_action and selection_suspicious_paths
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Third-party software installers creating legitimate services in non-standard directories.
    - System administrators deploying temporary scripts as services.
level: high
tags:
    - attack.execution
    - attack.t1569
    - analytic.an0778
    - detection.det0279
```
