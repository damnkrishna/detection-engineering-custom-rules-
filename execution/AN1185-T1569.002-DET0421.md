### 1. Technique Breakdown: T1569.002

* What it is: System Services: Service Execution. Adversaries abuse the Service Control Manager (SCM) to execute commands or maintain persistence by creating and running temporary services.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. SCM child process spawning and administrative service controller invocations are monitored.
  - NIDS (Suricata + Zeek): YES. Remote SCM manipulation over RPC/SMB can be analyzed.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Suspicious Child Process of Service Control Manager (AN1185-A)
id: caf6ee09-dc9c-4d66-8c70-8270f6bdb8f0
status: experimental
description: Detects non-standard binaries spawned directly by services.exe, suggesting malicious service executions.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_parent:
        ParentImage|endswith: '\services.exe'
    filter_standard:
        Image|endswith:
            - '\system32\svchost.exe'
            - '\system32\spoolsv.exe'
            - '\system32\lsass.exe'
            - '\system32\wininit.exe'
            - '\system32\searchindexer.exe'
            - '\system32\taskhostw.exe'
            - '\system32\dllhost.exe'
            - '\system32\sihost.exe'
            - '\system32\mstsc.exe'
            - '\system32\consent.exe'
            - '\system32\smartscreen.exe'
            - '\system32\runtimebroker.exe'
            - '\system32\wbem\WmiPrvSE.exe'
            - '\MsMpEng.exe'
    condition: selection_parent and not filter_standard
fields:
    - Image
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Standard enterprise software installers registering and launching components during updates.
level: high
tags:
    - attack.execution
    - attack.t1569.002
    - analytic.an1185
    - detection.det0421
```

```yaml
title: Service Controller CommandLine Creation (AN1185-B)
id: 7e6e7f4d-76fe-4c3e-ae00-1801a5ffc200
status: experimental
description: Detects command-line parameters utilizing sc.exe or net.exe to create or modify service binaries.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\sc.exe'
            - '\net.exe'
            - '\net1.exe'
    selection_orig:
        OriginalFileName:
            - 'sc.exe'
            - 'net.exe'
            - 'net1.exe'
    selection_cli:
        CommandLine|contains:
            - ' binpath='
            - ' create '
            - ' config '
    condition: (selection_images or selection_orig) and selection_cli
fields:
    - Image
    - CommandLine
    - User
falsepositives:
    - IT administration scripts registering trusted business applications or service paths.
level: medium
tags:
    - attack.execution
    - attack.t1569.002
    - analytic.an1185
    - detection.det0421
```
