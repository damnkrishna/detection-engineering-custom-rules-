### 1. Technique Breakdown: T1574.005

* What it is: Hijack Execution Flow: Executable Installer File Permissions Weakness. Adversaries exploit weak directory permissions in software installation paths (such as subfolders in `%TEMP%` or custom application directories created by installers) to overwrite or replace legitimate binaries with their own malicious payloads. When the installer runs again under an elevated context (e.g., local admin or SYSTEM), it executes the replaced binary, resulting in privilege escalation.
* Log Source Requirements: Endpoint logs capturing process creation and command line parameters (specifically targeting elevated process execution originating from temporary or user-writable directories).
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 (Process Creation) logs process executions, including the full resolved path of the executable (`Image`) and the token elevation level (`IntegrityLevel`).
* NIDS (Suricata + Zeek): NO. Exploiting local installer directory permission weaknesses is an endpoint-internal privilege escalation method. It generates no network logs.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Elevated Execution from Weak Permissions Installer Directory (AN0108)
id: c57f8e8a-2c1b-4d92-8c7a-5f6d7e8a9b0d
status: experimental
description: Detects when processes are launched under elevated contexts (High or System Integrity) from user-writable installer or temporary directories, indicating potential exploitation of installer path permission weaknesses.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_paths:
        Image|contains:
            - '\AppData\Local\Temp\'
            - '\Users\Public\'
            - '\Windows\Temp\'
            - '\AppData\Roaming\'
            - '\Downloads\'
    selection_integrity:
        IntegrityLevel:
            - 'High'
            - 'System'
    filter_known_installers:
        - CommandLine|contains:
            - 'nativeimages'
            - 'PackageStaging'
        - Image|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
            - '\install.exe'
    condition: selection_paths and selection_integrity and not filter_known_installers
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate administrative software installers executing unpacking operations and running child configuration scripts with elevated privileges in local temp folders.
level: high
tags:
    - attack.execution
    - attack.persistence
    - attack.privilege-escalation
    - attack.t1574.005
    - analytic.an0108
    - detection.det0038
```
