### 1. Technique Breakdown: T1195.003

* What it is: Supply Chain Compromise: Compromise Hardware Supply Chain. Adversaries insert malicious physical modifications or subverted firmware (such as tampered UEFI/BIOS, customized network cards, or compromised baseboard management controllers) during manufacturing or distribution. Detecting this post-delivery requires monitoring host BIOS flashing utilities, TPM validation errors, or Secure Boot policy changes.
* Log Source Requirements: Sysmon process creation logs (Event ID 1) and Sysmon driver load logs (Event ID 6).
* Coverage Check:
  * HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 tracks BIOS flashing tool executions. Sysmon Event ID 6 tracks the kernel-mode drivers loaded by these flashing utilities.
  * Windows Security/Defender Logs: NO. These sources do not capture low-level firmware changes directly, though UEFI/Secure Boot logs can be queried via advanced firmware interfaces.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 6 (driver_activity)
* Log Sources Missing / Unused:
  - None.
* Conclusion: Hardware supply chain firmware flashing and driver load can be detected using process creation and driver load logs.

### 2. Custom Sigma Rule

```yaml
title: Hardware Supply Chain - Firmware Flashing Tool Execution (AN1035-A)
id: 1d8aa070-3a64-487c-a6c1-9b377c07e817
status: experimental
description: Detects the execution of known firmware/BIOS flashing tools, which may indicate unauthorized BIOS/firmware modification.
author: Antigravity
date: 2026-06-12
logsource:
    category: process_creation
    product: windows
detection:
    selection_process:
        Image|endswith:
            - '\flashrom.exe'
            - '\fwupd.exe'
            - '\afuwingu.exe' # AMI Firmware Update Utility
            - '\HpbiosUpdate.exe'
            - '\DellBiosProvider.exe'
            - '\WinFlash.exe'
    condition: selection_process
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Authorized IT firmware upgrades or hardware maintenance tasks by technicians.
level: high
tags:
    - attack.initial-access
    - attack.t1195.003
    - analytic.an1035
    - detection.det0368
```

```yaml
title: Hardware Supply Chain - Firmware Flashing Driver Load (AN1035-B)
id: 5482478b-22e9-4d49-9562-92290aed2e9a
status: experimental
description: Detects the loading of vulnerable or low-level firmware helper drivers commonly utilized by BIOS flash utilities.
author: Antigravity
date: 2026-06-16
logsource:
    category: driver_load
    product: windows
detection:
    selection_drivers:
        ImageLoaded|endswith:
            - '\winring0.sys'
            - '\winring0x64.sys'
            - '\rwdrv.sys'
            - '\amifldrv64.sys'
            - '\amifldrv32.sys'
    condition: selection_drivers
fields:
    - ImageLoaded
    - Signature
    - Hashes
falsepositives:
    - Authorized firmware updates or hardware utility programs.
level: high
tags:
    - attack.initial-access
    - attack.t1195.003
    - analytic.an1035
    - detection.det0368
```
