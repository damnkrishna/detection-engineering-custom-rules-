### 1. Technique Breakdown: T1189

* What it is: Drive-by Compromise. Adversaries gain initial access by exploiting a user's web browser when they visit a compromised or malicious website. Successful browser exploitation is identified by the browser process (e.g., Chrome, Edge, Firefox) directly spawning shell interpreters, scripting hosts, binary loaders, or downloading and launching payloads from temporary user directories.
* Log Source Requirements: Sysmon process creation logs (Event ID 1) capturing parent-child process relationships, and PowerShell script block logs (Event ID 4104).
* Coverage Check:
  * HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 captures browser processes spawning shell/script hosts. Sysmon Event ID 4104 (Script Block) is effective at catching scripting activity containing browser context references.
  * NIDS (Suricata + Zeek): YES. Network monitoring can identify downloads of binary payloads with anomalous headers or from high-risk domains, but host-based process monitoring is needed to verify execution.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 4104 (ps_script)
* Log Sources Missing / Unused:
  - None.
* Conclusion: Drive-by compromise execution can be detected using process creation and PowerShell script block logs.

### 2. Custom Sigma Rule

```yaml
title: Drive-by Compromise - Suspicious Child Process Spawned by Browser (AN0498-A)
id: f253efb1-1ab2-4ab7-b28a-a1d2fda75040
status: experimental
description: Detects suspicious processes (e.g., cmd.exe, powershell.exe, wscript.exe, rundll32.exe, mshta.exe) spawned directly by web browser processes, which indicates browser exploitation or user opening dangerous downloaded files.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: process_creation
    product: windows
detection:
    selection_parent:
        ParentImage|endswith:
            - '\chrome.exe'
            - '\msedge.exe'
            - '\firefox.exe'
            - '\brave.exe'
            - '\opera.exe'
            - '\iexplore.exe'
            - '\safari.exe'
    selection_child:
        - Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\wscript.exe'
            - '\cscript.exe'
            - '\mshta.exe'
            - '\rundll32.exe'
            - '\regsvr32.exe'
            - '\certutil.exe'
            - '\bitsadmin.exe'
            - '\curl.exe'
            - '\scrcons.exe'
        - OriginalFileName:
            - 'Cmd.Exe'
            - 'PowerShell.EXE'
            - 'wscript.exe'
            - 'cscript.exe'
            - 'mshta.exe'
            - 'rundll32.exe'
            - 'regsvr32.exe'
            - 'certutil.exe'
            - 'bitsadmin.exe'
            - 'curl.exe'
    condition: selection_parent and selection_child
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate web applications running on localhost (e.g., local development servers, admin dashboards) that spawn shell windows.
    - Automated browser-based test tools (e.g. Selenium, Puppeteer) spawning command prompts to run testing scripts.
level: high
tags:
    - attack.initial-access
    - attack.t1189
    - analytic.an0498
    - detection.det0176
```

```yaml
title: Drive-by Compromise - PowerShell Script Block executing from Web Browser Parent (AN0498-B)
id: 864b66a5-fd99-44eb-87c2-c2e8ec9b295c
status: experimental
description: Detects PowerShell script block logs executing commands associated with browser parent processes, suggesting browser-compromise execution.
author: Krishna Gupta
date: 2026-06-16
logsource:
    category: ps_script
    product: windows
detection:
    selection_cmd:
        ScriptBlockText|contains:
            - 'Invoke-Expression'
            - 'iex'
            - 'Invoke-WebRequest'
            - 'iwr'
            - 'Net.WebClient'
            - 'DownloadFile'
            - 'DownloadString'
    selection_browsers:
        ScriptBlockText|contains:
            - 'chrome'
            - 'msedge'
            - 'firefox'
            - 'brave'
            - 'opera'
            - 'iexplore'
    condition: selection_cmd and selection_browsers
fields:
    - ScriptBlockText
falsepositives:
    - Developer scripting tools or administrative tasks triggered locally.
level: medium
tags:
    - attack.initial-access
    - attack.t1189
    - analytic.an0498
    - detection.det0176
```
