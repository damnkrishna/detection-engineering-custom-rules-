### 1. Technique Breakdown: T1566.001

* What it is: Phishing: Spearphishing Attachment. Adversaries send emails containing malicious attachments (such as macro-enabled spreadsheets, script files, shortcuts, or disk images like `.iso` and `.img`) to establish a foothold. When the user opens the email or attempts to view the attachment, the email client (e.g., Outlook) writes the attachment file to the local disk (specifically to temporary download paths or temporary internet cache directories).
* Log Source Requirements: Sysmon File Creation logs (Event ID 11) and Sysmon process creation logs (Event ID 1).
* Coverage Check:
  * HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 11 records the mail client process writing to disk. Sysmon Event ID 1 records the execution of processes directly from the mail attachment cache directory.
  * NIDS (Suricata + Zeek): YES. Network intrusion sensors analyze SMTP/IMAP streams and extract attachments, but endpoint-based process execution logs are necessary to verify execution.
* Log Sources Covered:
  - Sysmon Event ID 11 (file_event)
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.
* Conclusion: Spearphishing attachment deployment and execution can be detected using file creation and process creation logs.

### 2. Custom Sigma Rule

```yaml
title: Spearphishing Attachment - Dangerous File Written by Mail Client (AN0655-A)
id: d47d228b-7ef5-41fc-9a4a-a5fff86b09f6
status: experimental
description: Detects email client processes (e.g., outlook.exe, thunderbird.exe) writing files with dangerous or executable extensions (e.g., .exe, .lnk, .vbs, .hta, .iso, .img, .bat) to the file system.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: file_event
    product: windows
detection:
    selection_process:
        Image|endswith:
            - '\outlook.exe'
            - '\thunderbird.exe'
            - '\foxmail.exe'
    selection_extensions:
        TargetFilename|endswith:
            - '.exe'
            - '.lnk'
            - '.vbs'
            - '.vbe'
            - '.js'
            - '.jse'
            - '.hta'
            - '.iso'
            - '.img'
            - '.bat'
            - '.cmd'
            - '.scr'
            - '.wsf'
            - '.chm'
    condition: selection_process and selection_extensions
fields:
    - Image
    - TargetFilename
    - User
    - LogonId
falsepositives:
    - Users saving legitimate business files or software installers received via corporate emails.
level: high
tags:
    - attack.initial-access
    - attack.t1566.001
    - analytic.an0655
    - detection.det0236
```

```yaml
title: Spearphishing Attachment - Execution of Process from Mail Attachment Cache (AN0655-B)
id: 59f67487-d5fd-4037-a8a8-e0cbbca65da1
status: experimental
description: Detects execution of binaries or script interpreters directly from Outlook secure temp and mail cache folders.
author: Krishna Gupta
date: 2026-06-16
logsource:
    category: process_creation
    product: windows
detection:
    selection_path:
        Image|contains:
            - '\Content.Outlook\'
            - '\AppData\Local\Temp\Olk'
            - '\Temporary Internet Files\Content.Outlook\'
    condition: selection_path
fields:
    - Image
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Rare administrative tools or software updates launched directly from email links/attachments.
level: high
tags:
    - attack.initial-access
    - attack.t1566.001
    - analytic.an0655
    - detection.det0236
```
