### 1. Technique Breakdown: T1133

* What it is: External Remote Services. Adversaries leverage external-facing remote access solutions (such as virtual private networks (VPNs) or remote desktop protocols (RDP)) to gain initial access to the internal network. Once they authenticate using compromised credentials, they immediately initiate host reconnaissance by spawning built-in system administration utilities (`whoami.exe`, `net.exe`, `ipconfig.exe`, `nltest.exe`) from the remote session shell.
* Log Source Requirements: Windows Security Event Log Event ID 4624 (Logon) and Sysmon process creation logs (Event ID 1).
* Coverage Check:
  * HIDS (Sysmon + Wazuh): YES. Windows Security log captures remote RDP connections (Logon Type 10) and network logins (Logon Type 3) along with the source IP address. Sysmon Event ID 1 captures the user session initiating system discovery commands.
  * NIDS (Suricata + Zeek): YES. Network logs track RDP and VPN connections to gateways, but host logs are needed to correlate the logon with subsequent shell actions.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Windows Security Event ID 4624 (authentication)
* Log Sources Missing / Unused:
  - None.
* Conclusion: External remote services authentication and follow-on execution can be detected using process creation and security logon logs.

### 2. Custom Sigma Rule

```yaml
title: External Remote Services - Suspicious Command Execution Post-Remote Logon (AN1004-A)
id: b792df5f-2ed4-49e9-a6e6-b2d3684c0246
status: experimental
description: Detects the execution of system discovery or network configuration commands shortly after a successful RDP (Logon Type 10) or Network (Logon Type 3) logon event, indicating post-intrusion reconnaissance.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: process_creation
    product: windows
detection:
    selection_logon_context:
        LogonId|not: '0x3e7' # Exclude SYSTEM session
    selection_commands:
        - Image|endswith:
            - '\whoami.exe'
            - '\net.exe'
            - '\net1.exe'
            - '\ipconfig.exe'
            - '\nltest.exe'
            - '\systeminfo.exe'
            - '\quser.exe'
            - '\query.exe'
            - '\qwinsta.exe'
        - OriginalFileName:
            - 'whoami.exe'
            - 'net.exe'
            - 'net1.exe'
            - 'ipconfig.exe'
            - 'nltest.exe'
            - 'systeminfo.exe'
    condition: selection_logon_context and selection_commands
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - IT administrators logging in remotely to troubleshoot system issues or gather host configuration metrics.
level: high
tags:
    - attack.initial-access
    - attack.t1133
    - analytic.an1004
    - detection.det0354
```

```yaml
title: External Remote Services - Successful Remote Logon Event (AN1004-B)
id: a4fbaadd-c39e-4c42-8d61-8bc25e05ddeb
status: experimental
description: Detects successful remote desktop logons (Logon Type 10) or network logons (Logon Type 3), which are paths for external remote service logins.
author: Krishna Gupta
date: 2026-06-16
logsource:
    product: windows
    service: security
detection:
    selection_logon:
        EventID: 4624
        LogonType:
            - 3  # Network
            - 10 # Remote Interactive
    filter_common:
        TargetUserName|endswith: '$'
        TargetUserName:
            - 'ANONYMOUS LOGON'
            - 'SYSTEM'
    condition: selection_logon and not filter_common
fields:
    - EventID
    - IpAddress
    - LogonType
    - TargetUserName
falsepositives:
    - Legitimate administrative or user remote network logons.
level: medium
tags:
    - attack.initial-access
    - attack.t1133
    - analytic.an1004
    - detection.det0354
```
