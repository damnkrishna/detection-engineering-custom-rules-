### 1. Technique Breakdown: T1190

* What it is: Exploit Public-Facing Application. Adversaries exploit vulnerabilities in internet-facing web servers (such as IIS, Apache Tomcat, Exchange, or Java-based web portals) to run arbitrary code on the host. This post-exploitation activity routinely starts with the web server process spawning shell environments (like cmd or PowerShell) or admin utilities (like `whoami.exe`, `ping.exe`, or `net.exe`) to perform initial reconnaissance or drop web shells.
* Log Source Requirements: Sysmon process creation logs (Event ID 1) tracking parent-child process chains, and Sysmon network connection logs (Event ID 3).
* Coverage Check:
  * HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 records parent process paths (e.g., `w3wp.exe`, `tomcat.exe`, `java.exe`) spawning child processes. Sysmon Event ID 3 records network connections initiated by these processes. Wazuh parses and raises high-severity alerts.
  * NIDS (Suricata + Zeek): YES. Network monitoring can identify exploitation attempts (e.g. SQLi, directory traversal) in HTTP payloads, but host-based logs are critical to confirm post-exploit execution success.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 3 (network_connection)
* Log Sources Missing / Unused:
  - None.
* Conclusion: Exploitation of public-facing applications can be detected using process creation and network connection logs.

### 2. Custom Sigma Rule

```yaml
title: Exploit Public-Facing Application - Suspicious Child Process of Web Server (AN0219-A)
id: f6564559-a33a-42d0-a66f-7c885a952a0d
status: experimental
description: Detects command-line interpreters or administrative utilities spawned by web server processes (e.g., IIS, Tomcat, Apache, Java web services), suggesting successful exploitation or web shell deployment.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: process_creation
    product: windows
detection:
    selection_parent:
        ParentImage|endswith:
            - '\w3wp.exe'
            - '\httpd.exe'
            - '\nginx.exe'
            - '\tomcat.exe'
            - '\tomcat7.exe'
            - '\tomcat8.exe'
            - '\tomcat9.exe'
            - '\tomcat10.exe'
            - '\httpd.exe'
            - '\java.exe'
            - '\javaw.exe'
    selection_child:
        - Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\wscript.exe'
            - '\cscript.exe'
            - '\sh.exe'
            - '\bash.exe'
            - '\whoami.exe'
            - '\net.exe'
            - '\nltest.exe'
            - '\systeminfo.exe'
            - '\ipconfig.exe'
            - '\arp.exe'
            - '\curl.exe'
        - OriginalFileName:
            - 'Cmd.Exe'
            - 'PowerShell.EXE'
            - 'wscript.exe'
            - 'cscript.exe'
            - 'whoami.exe'
            - 'net.exe'
            - 'nltest.exe'
            - 'systeminfo.exe'
            - 'ipconfig.exe'
            - 'arp.exe'
            - 'curl.exe'
    condition: selection_parent and selection_child
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate administrative scripts triggered by web application dashboards (e.g., automated server backup scripts triggered from an admin panel).
level: critical
tags:
    - attack.initial-access
    - attack.t1190
    - analytic.an0219
    - detection.det0080
```
