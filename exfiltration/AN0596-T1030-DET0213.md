### 1. Technique Breakdown: T1030

* What it is: Data Transfer Size Limits. Adversaries bypass data threshold alerts or network monitoring controls by dividing large staged archives into smaller, chunked volumes or limiting packet sizes prior to exfiltration.
* Log Source Requirements: Network flow analysis, packet size inspection, or DLP telemetry, which are not allowed log sources.
* Coverage Check:
  * HIDS (Sysmon + Windows Defender): NO. Sysmon Event ID 3 (Network Connection) only logs connection connection metadata (IPs, ports, process images) but does not record payload sizes, packet sizes, or byte transfer counts.
  * Windows Security Logs: NO. Standard Windows Security Logs (service: security) do not capture network traffic content or transfer volume details.
* Conclusion: This technique is not detectable from Sysmon, Windows Security, or Defender logs.
