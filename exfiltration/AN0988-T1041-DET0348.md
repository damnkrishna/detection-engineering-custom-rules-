### 1. Technique Breakdown: T1041

* What it is: Exfiltration Over C2 Channel. Adversaries exfiltrate stolen data by transmitting it directly through their existing command-and-control (C2) communication channel. This avoids establishing new outbound network connections that might trigger perimeter firewall alerts. Host-local detection involves identifying suspicious processes running from non-standard folders (like temp paths, user profile folders) or running as hidden services initiating network connections (Sysmon Event ID 3) and transmitting large payloads.
* Log Source Requirements: Sysmon network connection logs (Event ID 3) combined with initiating process metadata (Sysmon Event ID 1).
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 3 logs outbound network connections along with the initiating application's file path. Wazuh aggregates these and alerts on connections from high-risk paths.
    * NIDS (Suricata + Zeek): YES. Network monitoring can track anomalous traffic volume spikes or beaconing behavior targeting C2 endpoints.

### 2. Custom Sigma Rule

```yaml
title: Exfiltration - Outbound Network Connection from Suspicious Path (AN0988)
id: 79d73fb7-4b24-4af1-9ce9-02371947ce78
status: experimental
description: Detects processes executing from temp, user appdata, or public directories initiating outbound TCP/UDP connections to external networks, which could indicate data exfiltration over a C2 channel.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: network_connection
    product: windows
    # Relies on Sysmon Event ID 3
detection:
    selection_path:
        Image|contains:
            - '\AppData\Local\Temp\'
            - '\Windows\Temp\'
            - '\Users\Public\'
            - '\PerfLogs\'
    filter_internal:
        DestinationIp|startswith:
            - '10.'
            - '192.168.'
            - '172.16.'
            - '172.17.'
            - '172.18.'
            - '172.19.'
            - '172.2'
            - '172.3'
            - '127.'
            - '169.254.'
    condition: selection_path and not filter_internal
fields:
    - Image
    - CommandLine
    - User
    - LogonId
    - Initiated
    - SourceIp
    - DestinationIp
    - DestinationPort
falsepositives:
    - Legitimate software auto-updaters (running out of AppData\Local\Temp) downloading application updates.
    - User-run portable applications initiating connections for sync or updates.
level: high
tags:
    - attack.exfiltration
    - attack.t1041
    - analytic.an0988
    - detection.det0348
```
