### 1. Technique Breakdown: T1011.001

* What it is: Exfiltration Over Physical Medium: Bluetooth-Based Data Exfiltration. Adversaries exfiltrate data from a compromised host to a nearby rogue device (such as a smartphone or laptop) over Bluetooth, bypassing corporate network egress monitoring. On Windows systems, this is typically facilitated using the native Bluetooth File Transfer wizard executable, `fsquirt.exe`, or by utilizing command-line tools that interact with Bluetooth APIs.
* Log Source Requirements: Sysmon process creation logs (Event ID 1) auditing user execution of Bluetooth transfer wizards.
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 logs process creations, including the path and name of `fsquirt.exe`. Wazuh tracks this event to alert on execution.
    * NIDS (Suricata + Zeek): NO. Network security appliances monitor IP network interfaces and cannot audit local Bluetooth radio frequencies.

### 2. Custom Sigma Rule

```yaml
title: Exfiltration - Bluetooth File Transfer Wizard Execution (AN1531)
id: a1aa945e-1864-4b44-9f33-51b0c6b1d9d6
status: experimental
description: Detects execution of the native Windows Bluetooth File Transfer Wizard (fsquirt.exe), which can be abused by insiders or threat actors to copy data to nearby mobile devices or laptops.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_process_image:
        Image|endswith:
            - '\fsquirt.exe'
    selection_process_original:
        OriginalFileName:
            - 'fsquirt.exe'
    condition: selection_process_image or selection_process_original
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate user transferring business files to an authorized corporate mobile device over Bluetooth.
level: high
tags:
    - attack.exfiltration
    - attack.t1011.001
    - analytic.an1531
    - detection.det0554
```
