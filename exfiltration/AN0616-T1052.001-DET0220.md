### 1. Technique Breakdown: T1052.001

* What it is: Exfiltration Over Physical Medium: Exfiltration over USB. Adversaries exfiltrate data by writing files directly to USB mass storage devices. To accelerate data collection and minimize interactive steps, they often execute automated command-line copy tools (like robocopy.exe, xcopy.exe) or custom scripts to scan and copy targeted files directly to plugged-in USB drives. Detections monitor file writes onto removable drive paths by these copy utilities or the process execution command lines.
* Log Source Requirements: Endpoint logs capturing file creation events and process creation events.
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 11 (File Event) logs when copy utilities write files to USB drive paths, and Event ID 1 (Process Creation) logs copy command-line executions targeting removable storage.
* NIDS (Suricata + Zeek): NO. Offline, local host actions.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: File Copy to USB Storage via CLI (AN0616)
id: 44e824ce-8c28-4fb8-ba3b-b05838ce6d7d
status: experimental
description: Detects command line execution of file copy utilities (xcopy, robocopy) or scripting engines writing files to USB/removable storage drive letters.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: file_event
    product: windows
detection:
    selection_process:
        Image|endswith:
            - '\xcopy.exe'
            - '\robocopy.exe'
            - '\powershell.exe'
            - '\cmd.exe'
    selection_paths:
        TargetFilename|startswith:
            - 'D:\'
            - 'E:\'
            - 'F:\'
            - 'G:\'
            - 'H:\'
            - 'I:\'
            - 'J:\'
    condition: selection_process and selection_paths
fields:
    - Image
    - TargetFilename
    - User
    - LogonId
falsepositives:
    - Legitimate IT administration or users manually backing up files using command line copy tools to external media.
level: medium
tags:
    - attack.exfiltration
    - attack.t1052.001
    - analytic.an0616
    - detection.det0220
```

```yaml
title: CLI Copy Command Targeting Removable Media (AN0616-B)
id: 576cfd6a-fae7-4952-ba6c-2f9b1c784ad9
status: experimental
description: Detects command line copy utility executions specifying typical USB/removable storage drive letters.
author: Krishna Gupta
date: 2026-06-17
logsource:
    category: process_creation
    product: windows
detection:
    selection_process_image:
        Image|endswith:
            - '\xcopy.exe'
            - '\robocopy.exe'
            - '\powershell.exe'
            - '\cmd.exe'
    selection_process_original:
        OriginalFileName:
            - 'xcopy.exe'
            - 'robocopy.exe'
            - 'PowerShell.EXE'
            - 'cmd.exe'
    selection_paths:
        CommandLine|contains:
            - ' D:\'
            - ' E:\'
            - ' F:\'
            - ' G:\'
            - ' H:\'
            - ' I:\'
    condition: (selection_process_image or selection_process_original) and selection_paths
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Administrative file management or users backing up personal files via command prompt.
level: medium
tags:
    - attack.exfiltration
    - attack.t1052.001
    - analytic.an0616
    - detection.det0220
```
