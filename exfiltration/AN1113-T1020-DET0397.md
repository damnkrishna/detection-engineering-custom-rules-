### 1. Technique Breakdown: T1020

* What it is: Automated Exfiltration. Adversaries automate the search, collection, packaging, and transmission of sensitive files using scheduled scripts or custom implants. Once deployed, these scripts execute at set intervals (using scheduled tasks or system daemons), compress targeted file formats (using LOLBins like tar.exe or makecab.exe), and transmit them to external infrastructure. Detections monitor automated archiving processes or the creation of staged compressed files in public directories.
* Log Source Requirements: Endpoint logs capturing process creation events and file creation events.
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 (Process Creation) logs archiving command executions spawned by scheduling or scripting interpreters, and Event ID 11 (File Event) logs creation of staged archives.
* NIDS (Suricata + Zeek): YES (Partial). Outbound network logs can reveal periodic beaconing, but host logs are required to detect local staging.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Automated Archiving and Staging via CLI (AN1113)
id: c330cb77-2e87-43d9-b0bd-e18c86898f7c
status: experimental
description: Detects command-line archiving utilities being spawned by command shells or task schedulers, which may indicate automated data harvesting and staging for exfiltration.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
detection:
    selection_parent:
        ParentImage|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\cmd.exe'
            - '\taskeng.exe'
            - '\svchost.exe'
    selection_archive_image:
        Image|endswith:
            - '\7z.exe'
            - '\7za.exe'
            - '\rar.exe'
            - '\zip.exe'
            - '\tar.exe'
            - '\makecab.exe'
    selection_archive_original:
        OriginalFileName:
            - '7z.exe'
            - '7za.exe'
            - 'rar.exe'
            - 'zip.exe'
            - 'tar.exe'
            - 'makecab.exe'
    condition: selection_parent and (selection_archive_image or selection_archive_original)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate administrative backup scripts, database backups, or software build tools performing automated file archiving.
level: medium
tags:
    - attack.exfiltration
    - attack.t1020
    - analytic.an1113
    - detection.det0397
```

```yaml
title: Automated Staging Directory Archive Creation (AN1113-B)
id: a566da7c-871f-4e11-b1b1-2378e347a774
status: experimental
description: Detects the creation or writing of compressed archive files inside user-writable temp folders, suggesting automated file aggregation.
author: Krishna Gupta
date: 2026-06-17
logsource:
    category: file_event
    product: windows
detection:
    selection_paths:
        TargetFilename|contains:
            - '\AppData\Local\Temp\'
            - '\Users\Public\'
            - '\ProgramData\'
    selection_extensions:
        TargetFilename|endswith:
            - '.zip'
            - '.7z'
            - '.rar'
            - '.tar'
            - '.tgz'
    condition: selection_paths and selection_extensions
fields:
    - TargetFilename
    - Image
    - User
falsepositives:
    - Legitimate installation routines unpacking local archives.
level: medium
tags:
    - attack.exfiltration
    - attack.t1020
    - analytic.an1113
    - detection.det0397
```
