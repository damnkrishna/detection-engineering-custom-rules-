### 1. Technique Breakdown: T1020

* What it is: Automated Exfiltration. Adversaries automate the search, collection, packaging, and transmission of sensitive files using scheduled scripts or custom implants. Once deployed, these scripts execute at set intervals (using scheduled tasks or system daemons), compress targeted file formats (using LOLBins like tar.exe or makecab.exe), and transmit them to external infrastructure. Detections monitor automated archiving processes or the creation of staged compressed files in public directories.
* Log Source Requirements: Endpoint logs capturing process creation events and file creation events.
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 (Process Creation) logs archiving command executions spawned by scheduling or scripting interpreters, and Event ID 11 (File Event) logs creation of staged archives.
* NIDS (Suricata + Zeek): YES (Partial). Outbound network logs can reveal periodic beaconing, but host logs are required to detect local staging.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

The detection logic is split into monitoring CLI archiving utility executions spawned by system/scripting parent processes, and file write events capturing compressed archives dropped in user temp directories.

Rule 1 of 2: Automated Archiving and Staging via CLI (Process Creation)
```yaml
title: Automated Archiving and Staging via CLI (AN1113)
id: 74bde7cd-79fb-44ae-bd48-51829210d551
status: experimental
description: Detects command-line archiving utilities being spawned by command shells or task schedulers, which may indicate automated data harvesting and staging for exfiltration.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
detection:
    selection_parent:
        ParentImage|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\cmd.exe'
            - '\taskeng.exe'
            - '\svchost.exe'
    selection_archive:
        - Image|endswith:
            - '\7z.exe'
            - '\7za.exe'
            - '\rar.exe'
            - '\zip.exe'
            - '\tar.exe'
            - '\makecab.exe'
        - OriginalFileName:
            - '7z.exe'
            - '7za.exe'
            - 'rar.exe'
            - 'zip.exe'
            - 'tar.exe'
            - 'makecab.exe'
    condition: selection_parent and selection_archive
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate administrative backup scripts, database backups, or software build tools performing automated file archiving.
level: medium
tags:
    - attack.exfiltration
    - attack.t1020
    - analytic.an1113
    - detection.det0397
```

Rule 2 of 2: Automated Staging Directory Archive Creation (File Event)
```yaml
title: Automated Staging Directory Archive Creation (AN1113-B)
id: 629d8a9f-3e1a-4d2c-8068-15cf9c08d59c
status: experimental
description: Detects the creation or writing of compressed archive files inside user-writable temp folders, suggesting automated file aggregation.
author: Krishna Gupta
date: 2026-06-17
logsource:
    category: file_event
    product: windows
detection:
    selection_paths:
        TargetFilename|contains:
            - '\AppData\Local\Temp\'
            - '\Users\Public\'
            - '\ProgramData\'
    selection_extensions:
        TargetFilename|endswith:
            - '.zip'
            - '.7z'
            - '.rar'
            - '.tar'
            - '.tgz'
    condition: selection_paths and selection_extensions
fields:
    - TargetFilename
    - Image
    - User
falsepositives:
    - Legitimate installation routines unpacking local archives.
level: medium
tags:
    - attack.exfiltration
    - attack.t1020
    - analytic.an1113
    - detection.det0397
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Command Line Obfuscation
  * The Issue: Adversaries can obfuscate command-line arguments using environment variables, caret escapes (^), or base64 encoding, evading simple string matching.
  * The Fix: Implement PowerShell Script Block Logging and utilize regex or script-decoding scripts in the SIEM to check arguments.

* Problem 2: Administrative Activity Noise
  * The Issue: IT administrators legitimately run command-line tools or installers that trigger these rules during system maintenance.
  * The Fix: Establish a baseline of legitimate admin tools, whitelisting specific administrative account names or management servers.

* Problem 3: Masquerading via Renamed Binaries
  * The Issue: Attackers rename native Windows utilities (such as net.exe or cmd.exe) to custom filenames to bypass path-based filters.
  * The Fix: Incorporate Masquerade-resistant criteria, matching on OriginalFileName rather than the static Image path in process creation logs.
