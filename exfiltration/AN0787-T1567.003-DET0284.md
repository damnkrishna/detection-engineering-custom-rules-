### 1. Technique Breakdown: T1567.003

* What it is: Exfiltration Over Web Service: Exfiltration to Code Repository. Adversaries exfiltrate sensitive files or credentials by uploading their content as plain text snippets to public paste bins (such as Pastebin, Hastebin, or Ghostbin) where text can be hosted anonymously. Detections target processes initiating connections over domains associated with these sites, or CLI command-line parameters specifying paste bin destinations.
* Log Source Requirements: Endpoint logs capturing network connection events and process creation events.
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 3 (Network Connection) logs outbound connections targeting public paste site domains, and Event ID 1 (Process Creation) logs commands referencing these domains.
* NIDS (Suricata + Zeek): YES. Network boundary logs capture TLS handshake metadata and SNI hostnames for paste bin sites.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 3 (network_connection)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

The detection logic is split into outbound network connections to public paste bin domains initiated by scripting hosts, and process creation events of scripting hosts executing commands that target paste sites.

Rule 1 of 2: Outbound Data Exfiltration to Paste Sites via CLI (Network Connection)
```yaml
title: Outbound Data Exfiltration to Paste Sites via CLI (AN0787)
id: aaee7d8e-1a7e-4867-932a-9462b39a6970
status: experimental
description: Detects command-line interpreters, scripting hosts, or file transfer tools initiating network connections or DNS queries to known paste sites (e.g., Pastebin, Hastebin), which may indicate data exfiltration.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: network_connection
    product: windows
detection:
    selection_process:
        Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\cmd.exe'
            - '\wscript.exe'
            - '\cscript.exe'
            - '\curl.exe'
    selection_domains:
        DestinationHostname|contains:
            - 'pastebin.com'
            - 'hastebin.com'
            - 'ghostbin.co'
            - 'paste.ee'
            - 'controlc.com'
    condition: selection_process and selection_domains
fields:
    - Image
    - CommandLine
    - User
    - LogonId
    - Initiated
    - SourceIp
    - DestinationIp
    - DestinationPort
falsepositives:
    - Highly unlikely in standard enterprise environments. Some administration scripts may query paste sites for update configs.
level: high
tags:
    - attack.exfiltration
    - attack.t1567.003
    - analytic.an0787
    - detection.det0284
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Dynamic Client IP Range
  * The Issue: Legitimate client processes communicating with external SaaS platforms can generate massive outbound log volumes.
  * The Fix: Baseline client egress destinations, restricting alerts to network connections initiated by execution shells or scripting hosts.

* Problem 2: Encrypted Payload Blind Spots
  * The Issue: Standard port monitoring cannot inspect encrypted TLS/HTTPS payload contents, leaving C2 beaconing undetected.
  * The Fix: Analyze TLS handshake metadata (specifically SNI domain names) and calculate connection frequency or beaconing heuristics.

* Problem 3: Proxy and Gateway Redirection
  * The Issue: Outbound connections routed through internal proxy servers will report the proxy IP as destination, masking the target C2 server.
  * The Fix: Correlate client endpoint process logs with proxy server access logs to resolve the true external destination IP.

* True Positive 1: Outbound Data Exfiltration to Paste Sites (Rule 1)
  * The Log: Network Activity from PowerShell connecting to pastebin.com.
  * Expected Outcome: Matches `selection_process` and `selection_domains`. MUST trigger an alert.

* True Positive 2: Paste Site Exfiltration Command Execution (Rule 2)
  * The Log: Process Activity executing curl.exe to hastebin.com.
  * Expected Outcome: Matches `selection_process_image` and `selection_args`. MUST trigger an alert.

* True Positive 3: Malformed JSON Robustness Test (Rule 1)
  * The Log: Network Activity simulating TP-01 but intentionally omitting the `actor` object entirely.
  * Expected Outcome: Engine parser should degrade gracefully and still trigger the alert. MUST trigger an alert.

* True Positive 4: Schema Type Validation Failure (Rule 1)
  * The Log: Exact match of TP-01, but `activity_id` is passed as a string `"1"` instead of an integer `1`.
  * Expected Outcome: Tests if the engine's JSON parser crashes on type mismatches or coerces the type gracefully. MUST trigger an alert.

* True Positive 5: Exact Duplicate Event (Rule 1)
  * The Log: Exact duplicate of TP-01 with the exact same timestamp.
  * Expected Outcome: Tests if the engine's deduplication window correctly suppresses identical events.

#### True Negatives
* True Negative 1: Legitimate Domain (Rule 1 Filter)
  * The Log: Network Activity from PowerShell to microsoft.com.
  * Expected Outcome: Fails to match `selection_domains`. MUST NOT trigger an alert.
