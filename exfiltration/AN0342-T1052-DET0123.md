### 1. Technique Breakdown: T1052

* What it is: Exfiltration Over Physical Medium. Adversaries copy stolen data directly to removable media devices (such as USB flash drives, external hard drives, or writeable CDs/DVDs) to bypass network filters and perimeter controls. Detections monitor for files being written or created on removable storage drive letters (e.g., E:\, F:\) or command-line commands copying files to these drives.
* Log Source Requirements: Endpoint logs capturing file creation events and process creation events.
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 11 (File Event) logs archive file creation paths (including drive letters) and Sysmon Event ID 1 (Process Creation) logs CLI copy commands targeting removable storage.
* NIDS (Suricata + Zeek): NO. Physical media exfiltration is entirely local and offline.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Archive File Creation on Removable Media (AN0342)
id: 4164f71c-5b17-43cf-a58f-bd17cf7cc521
status: experimental
description: Detects the creation or writing of compressed archive files (such as .zip, .rar, .7z) onto removable storage drive paths (e.g. D:, E:, F:, G:, H:\), which may indicate staging data for physical exfiltration.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: file_event
    product: windows
detection:
    selection_paths:
        TargetFilename|startswith:
            - 'D:\'
            - 'E:\'
            - 'F:\'
            - 'G:\'
            - 'H:\'
            - 'I:\'
            - 'J:\'
    selection_archives:
        TargetFilename|endswith:
            - '.zip'
            - '.rar'
            - '.7z'
            - '.tar'
            - '.cab'
            - '.tgz'
            - '.iso'
    condition: selection_paths and selection_archives
fields:
    - Image
    - TargetFilename
    - User
    - LogonId
falsepositives:
    - Legitimate users saving archives or backing up data to USB flash drives or external drives.
level: medium
tags:
    - attack.exfiltration
    - attack.t1052
    - analytic.an0342
    - detection.det0123
```

```yaml
title: CLI Copy to Removable Drive (AN0342-B)
id: c7e2b1b3-4f9c-4b8a-8742-b6cf716ba388
status: experimental
description: Detects command-line utilities copying files or folders to typical removable storage drive letters (D:, E:, F:, etc.).
author: Krishna Gupta
date: 2026-06-17
logsource:
    category: process_creation
    product: windows
detection:
    selection_binaries_image:
        Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\robocopy.exe'
            - '\xcopy.exe'
    selection_binaries_original:
        OriginalFileName:
            - 'cmd.exe'
            - 'PowerShell.EXE'
            - 'pwsh.dll'
            - 'robocopy.exe'
            - 'xcopy.exe'
    selection_args:
        CommandLine|contains:
            - ' D:\'
            - ' E:\'
            - ' F:\'
            - ' G:\'
            - ' H:\'
            - ' I:\'
    condition: (selection_binaries_image or selection_binaries_original) and selection_args
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Users or administrators performing local manual file backups.
level: medium
tags:
    - attack.exfiltration
    - attack.t1052
    - analytic.an0342
    - detection.det0123
```
