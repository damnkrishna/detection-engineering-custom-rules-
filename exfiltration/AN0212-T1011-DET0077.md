### 1. Technique Breakdown: T1011

* What it is: Exfiltration Over Other Network Medium. Adversaries bypass corporate firewall and proxy monitors by exfiltrating data through non-primary network interfaces connected directly to the internet (such as local WiFi hotspots, mobile cellular adapters, or Bluetooth links). Detections focus on identifying command-line configurations of wireless adapters or registry modifications of Bluetooth drivers, indicating out-of-band network staging.
* Log Source Requirements: Endpoint logs capturing process creation and registry modifications.
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 (Process Creation) logs commands querying/configuring wireless interfaces, and Event ID 13 (Registry Set) logs Bluetooth service configuration modifications.
* NIDS (Suricata + Zeek): NO. Traffic bypasses corporate security boundary proxies and gateways.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 13 (registry_set)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: WiFi or Secondary Network Interface Configuration via CLI (AN0212)
id: fec142f1-c3f4-41db-81ad-e335625fd6d6
status: experimental
description: Detects command-line execution of netsh.exe or PowerShell network cmdlets being used to configure, enable, or connect to wireless (WLAN) or secondary network interfaces, which can be used to bypass corporate network boundaries for exfiltration.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
detection:
    selection_netsh:
        - Image|endswith: '\netsh.exe'
        - OriginalFileName: 'netsh.exe'
    selection_netsh_args:
        CommandLine|contains:
            - ' wlan '
            - ' wlan'
            - 'wlan '
    selection_powershell:
        - Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
        - OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.dll'
    selection_powershell_noun:
        CommandLine|contains:
            - 'NetAdapter'
            - 'NetRoute'
    selection_powershell_verb:
        CommandLine|contains:
            - 'Set-'
            - 'Enable-'
            - 'New-'
    condition: (selection_netsh and selection_netsh_args) or (selection_powershell and (selection_powershell_noun and selection_powershell_verb))
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - IT administrators or users troubleshooting mobile workstation wireless connections or configuring VPN routing.
level: medium
tags:
    - attack.exfiltration
    - attack.t1011
    - analytic.an0212
    - detection.det0077
```
