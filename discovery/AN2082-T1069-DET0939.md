### 1. Technique Breakdown: T1069

* What it is: Permission Groups Discovery. Adversaries may attempt to find local system or domain-level groups and permission settings.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): YES. Domain group queries (LDAP/SAMR) can be detected on the wire.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

---

### 2. Custom Sigma Rule

#### Rule 1 of 1: Local and Domain Group Discovery
Detects the use of `net.exe` or `dsquery.exe` to enumerate high-value administrative groups.

```yaml
title: Local and Domain Group Discovery (AN2082)
id: cbdf2001-a189-4db8-bb9a-7c9802cf0046
status: experimental
description: Detects command-line utilities querying local or domain administrative groups. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\net.exe'
            - '\net1.exe'
            - '\dsquery.exe'
    selection_ofn:
        OriginalFileName:
            - 'net.exe'
            - 'net1.exe'
            - 'dsquery.exe'
    selection_cli:
        CommandLine|contains:
            - ' localgroup'
            - ' group '
    selection_targets:
        CommandLine|contains:
            - 'administrators'
            - 'domain admins'
            - 'enterprise admins'
    condition: (selection_images or selection_ofn) and selection_cli and selection_targets
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Auditors or identity management software assessing group memberships.
level: medium
tags:
    - attack.discovery
    - attack.t1069
    - analytic.an2082
    - detection.det0939
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: BloodHound / Sharphound
  * The Issue: Advanced tools use LDAP queries directly rather than shelling out to `net.exe`.
  * The Fix: Monitor Windows Security Event ID 4661 (SAM object access) or Zeek LDAP logs for high volumes of domain enumeration queries.
* Problem 2: Unmonitored Custom Groups
  * The Issue: Organizations with non-standard administrative group names (e.g., `Tier0-Admins`) will not trigger the specific string matches.
  * The Fix: Expand the `selection_targets` list to include custom internal high-value groups.
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present in Sysmon logs when PE metadata is intact; packed or hollowed binaries may lack it.
  * The Fix: Treat the Image and OriginalFileName paths as complementary — either catch alone is sufficient.
