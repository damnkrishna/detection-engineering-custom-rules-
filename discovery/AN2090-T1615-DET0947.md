### 1. Technique Breakdown: T1615

* What it is: Group Policy Discovery. Adversaries may gather information on Group Policy settings to identify paths for privilege escalation or lateral movement.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines for gpresult.exe and PowerShell are captured.
  - NIDS (Suricata + Zeek): NO. Host-local discovery.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

#### Rule 1 of 1: Group Policy Enumeration
Detects the use of `gpresult.exe` or PowerShell cmdlets to enumerate applied Group Policy objects.

```yaml
title: Group Policy Enumeration (AN2090)
id: d4e5f6a7-b8c9-0123-def0-123456789003
status: experimental
description: Detects command-line utilities enumerating Group Policy Objects (GPOs) applied to the system or domain. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_gpresult:
        Image|endswith:
            - '\gpresult.exe'
    selection_gpresult_ofn:
        OriginalFileName: 'gpresult.exe'
    selection_gpresult_cli:
        CommandLine|contains:
            - '/r'
            - '/z'
            - '/scope'
    selection_ps:
        Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
    selection_ps_ofn:
        OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.exe'
    selection_ps_cli:
        CommandLine|contains:
            - 'Get-GPO'
            - 'Get-GPResultantSetOfPolicy'
            - 'Get-DomainGPO'
    condition: ((selection_gpresult or selection_gpresult_ofn) and selection_gpresult_cli) or ((selection_ps or selection_ps_ofn) and selection_ps_cli)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - System administrators verifying applied policy settings during troubleshooting.
level: medium
tags:
    - attack.discovery
    - attack.t1615
    - analytic.an2090
    - detection.det0947
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: LDAP Direct Queries
  * The Issue: Attackers may query the SYSVOL share or enumerate GPOs via LDAP without using `gpresult.exe` or PowerShell.
  * The Fix: Monitor file system access to `\\<DC>\SYSVOL\` using Sysmon Event ID 11 or Zeek SMB logs.
* Problem 2: BloodHound GPO Collection
  * The Issue: BloodHound/SharpHound collects GPO data silently over LDAP.
  * The Fix: Detect high-frequency LDAP queries to Domain Controllers using Zeek LDAP logs or Windows Event ID 1644.
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present when PE metadata is intact.
  * The Fix: Treat Image and OriginalFileName as complementary — either match alone is sufficient.
