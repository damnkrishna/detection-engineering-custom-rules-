### 1. Technique Breakdown: T1012

* What it is: Query Registry. Adversaries may interact with the Windows Registry to gather information about the system, configuration, and installed software.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): NO. Host-local discovery.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

---

### 2. Custom Sigma Rule

#### Rule 1 of 1: Registry Query for Sensitive Configurations
Detects the use of reg.exe to query sensitive registry hives often targeted for privilege escalation or credential extraction.

```yaml
title: Registry Query for Sensitive Configurations (AN2077)
id: f023d881-819a-44f2-9ca0-80ef522f0041
status: experimental
description: Detects command-line queries of the Windows Registry for LSA providers, Autoruns, or SAM information. Covers renamed reg.exe via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_image:
        Image|endswith:
            - '\reg.exe'
    selection_ofn:
        OriginalFileName: 'reg.exe'
    selection_action:
        CommandLine|contains:
            - ' query '
    selection_hives:
        CommandLine|contains:
            - 'LSA'
            - 'SecurityProviders'
            - 'CurrentVersion\Run'
            - 'SAM\Domains'
    condition: (selection_image or selection_ofn) and selection_action and selection_hives
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Administrative scripts verifying security configurations or startup items.
level: medium
tags:
    - attack.discovery
    - attack.t1012
    - analytic.an2077
    - detection.det0934
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: PowerShell Equivalents
  * The Issue: Attackers using `Get-ItemProperty` in PowerShell will bypass the `reg.exe` check.
  * The Fix: Rely on PowerShell Script Block Logging (Event ID 4104) rules for equivalent registry paths.
* Problem 2: EDR Telemetry Gaps
  * The Issue: If process command-line logging is disabled or truncated, the specific hive queried may be lost.
  * The Fix: Ensure full command-line auditing is enabled via GPO (Event ID 4688).
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present in Sysmon logs when PE metadata is intact; packed or hollowed binaries may lack it.
  * The Fix: Treat the Image and OriginalFileName paths as complementary — either catch alone is sufficient.
