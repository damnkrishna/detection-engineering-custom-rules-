### 1. Technique Breakdown: T1120

* What it is: Peripheral Device Discovery. Adversaries may attempt to gather information about attached peripheral devices (e.g., USB drives, cameras).
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688 / PowerShell Event ID 4104.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. PowerShell script block contents and process command lines are captured.
  - NIDS (Suricata + Zeek): NO. Host-local discovery.
* Log Sources Covered:
  - PowerShell Event ID 4104 (script_block)
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Peripheral Device Discovery via PowerShell or WMI (AN2086)
id: dec8f10b-fce6-403f-b093-2ea4b07b1951
status: experimental
description: Detects command-line execution or PowerShell script blocks querying Win32_PnPEntity to enumerate peripheral devices. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_wmic:
        Image|endswith:
            - '\wmic.exe'
    selection_wmic_ofn:
        OriginalFileName: 'wmic.exe'
    selection_wmic_cli:
        CommandLine|contains:
            - 'path win32_pnpentity'
    selection_powershell:
        Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
    selection_ps_ofn:
        OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.exe'
    selection_ps_cli:
        CommandLine|contains:
            - 'Get-PnpDevice'
            - 'Win32_PnPEntity'
    condition: ((selection_wmic or selection_wmic_ofn) and selection_wmic_cli) or ((selection_powershell or selection_ps_ofn) and selection_ps_cli)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Device management software or driver update utilities auditing attached hardware.
level: low
tags:
    - attack.discovery
    - attack.t1120
    - analytic.an2086
    - detection.det0943
```
