### 1. Technique Breakdown: T1082

* What it is: System Information Discovery. Adversaries may attempt to get detailed information about the operating system and hardware.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): NO. Host-local discovery.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

---

### 2. Custom Sigma Rule

#### Rule 1 of 1: System and Hardware Information Enumeration
Detects the use of `systeminfo.exe` or `wmic` to gather OS, patch levels, or hardware details.

```yaml
title: System and Hardware Information Enumeration (AN2083)
id: f023d881-819a-44f2-9ca0-80ef522f0047
status: experimental
description: Detects command-line utilities extracting detailed system, patch, and OS information. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_sysinfo:
        Image|endswith:
            - '\systeminfo.exe'
    selection_sysinfo_ofn:
        OriginalFileName: 'systeminfo.exe'
    selection_wmic:
        Image|endswith:
            - '\wmic.exe'
    selection_wmic_ofn:
        OriginalFileName: 'wmic.exe'
    selection_wmic_args:
        CommandLine|contains:
            - ' qfe '
            - ' os get '
            - ' logicaldisk '
            - ' computersystem '
    condition: (selection_sysinfo or selection_sysinfo_ofn) or ((selection_wmic or selection_wmic_ofn) and selection_wmic_args)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - SCCM or other asset management tools collecting hardware inventory.
level: low
tags:
    - attack.discovery
    - attack.t1082
    - analytic.an2083
    - detection.det0940
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: High False Positive Rate from Automation
  * The Issue: Inventory tools run these commands routinely.
  * The Fix: Add filters for the parent processes of known inventory agents (e.g. `ccmexec.exe`).
* Problem 2: Evasion via WMI COM Objects
  * The Issue: Attackers using PowerShell or C# to query WMI namespaces (`Win32_OperatingSystem`) will bypass `wmic.exe` detection.
  * The Fix: Enable PowerShell Script Block logging (Event ID 4104) to monitor for `Get-WmiObject` or `Get-CimInstance` calls.
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present in Sysmon logs when PE metadata is intact; packed or hollowed binaries may lack it.
  * The Fix: Treat the Image and OriginalFileName paths as complementary — either catch alone is sufficient.
