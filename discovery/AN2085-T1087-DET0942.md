### 1. Technique Breakdown: T1087

* What it is: Account Discovery. Adversaries may attempt to get a listing of local or domain accounts.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): YES. LDAP or SAMR queries can be detected on the network.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

#### Rule 1 of 1: Local and Domain Account Enumeration
Detects standard command-line tools used to list users or query account policies.

```yaml
title: Local and Domain Account Enumeration (AN2085)
id: f023d881-819a-44f2-9ca0-80ef522f0049
status: experimental
description: Detects command-line execution of net user, net accounts, or dsquery user to enumerate accounts. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\net.exe'
            - '\net1.exe'
            - '\dsquery.exe'
    selection_ofn:
        OriginalFileName:
            - 'net.exe'
            - 'net1.exe'
            - 'dsquery.exe'
    selection_cli:
        CommandLine|contains:
            - ' user '
            - ' users '
            - ' accounts '
    condition: (selection_images or selection_ofn) and selection_cli
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Identity and access management (IAM) tools performing daily account synchronizations.
level: medium
tags:
    - attack.discovery
    - attack.t1087
    - analytic.an2085
    - detection.det0942
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Native Active Directory APIs
  * The Issue: Attackers using `ADSI` (Active Directory Service Interfaces) via custom VBScript or C# tools will bypass command-line monitoring.
  * The Fix: Monitor Domain Controller logs for unusual LDAP query patterns or rely on network-based LDAP inspection.
* Problem 2: Evasion via WMIC
  * The Issue: `wmic useraccount list` achieves the same goal.
  * The Fix: Add `wmic.exe` with `useraccount` parameters to the rule, or rely on a generic WMIC monitoring rule.
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present in Sysmon logs when PE metadata is intact; packed or hollowed binaries may lack it.
  * The Fix: Treat the Image and OriginalFileName paths as complementary — either catch alone is sufficient.
