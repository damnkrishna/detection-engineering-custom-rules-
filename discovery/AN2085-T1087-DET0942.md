### 1. Technique Breakdown: T1087

* What it is: Account Discovery. Adversaries may attempt to get a listing of local or domain accounts.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): YES. LDAP or SAMR queries can be detected on the network.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Local and Domain Account Enumeration (AN2085)
id: 2f40d4bf-82bd-4bec-a790-6a0aa2435944
status: experimental
description: Detects command-line execution of net user, net accounts, or dsquery user to enumerate accounts. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\net.exe'
            - '\net1.exe'
            - '\dsquery.exe'
    selection_ofn:
        OriginalFileName:
            - 'net.exe'
            - 'net1.exe'
            - 'dsquery.exe'
    selection_cli:
        CommandLine|contains:
            - ' user '
            - ' users '
            - ' accounts '
    condition: (selection_images or selection_ofn) and selection_cli
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Identity and access management (IAM) tools performing daily account synchronizations.
level: medium
tags:
    - attack.discovery
    - attack.t1087
    - analytic.an2085
    - detection.det0942
```

### 3. OCSF Normalized Rule

```yaml
title: 'Local and Domain Account Enumeration (AN2085) (OCSF-Normalized)'
id: '2f40d4bf-82bd-4bec-a790-6a0aa2435944'
status: experimental
description: 'OCSF Normalized rule for Local and Domain Account Enumeration (AN2085)'
author: Krishna Gupta

    product: ocsf
    class: process_activity
detection:
    selection_images:
        process.file.path|endswith:
            - '\net.exe'
            - '\net1.exe'
            - '\dsquery.exe'
    selection_ofn:
        process.file.name:
            - 'net.exe'
            - 'net1.exe'
            - 'dsquery.exe'
    selection_cli:
        process.cmd_line|contains:
            - ' user '
            - ' users '
            - ' accounts '
    condition: (selection_images or selection_ofn) and selection_cli
fields:
    - time
level: high
tags:
    - attack.discovery
    - attack.t1087
    - analytic.an2085
    - detection.det0942
```
