### 1. Technique Breakdown: T1033

* What it is: System Owner/User Discovery. Adversaries enumerate the current user context, logged-on users, or domain accounts to understand who is operating a system, identify high-value targets, or tailor further lateral movement. On Windows, typical methods include whoami.exe, query.exe user, quser.exe, net.exe user, or WMI/PowerShell queries (Get-WmiObject Win32_ComputerSystem, Get-LocalUser, Get-ADUser).
* Log Source Requirements: Host process creation and command line logs (Sysmon Event ID 1 / Windows Security Event ID 4688) and PowerShell Script Block Logs (Event ID 4104).
* Coverage Check:
    * HIDS (Sysmon + Windows Defender): YES. Sysmon Event ID 1 captures spawning of whoami.exe, quser.exe, and net.exe. Event ID 4104 logs script block details.
    * Windows Security Logs: PARTIAL. Security logs EID 4688 captures command lines if enabled.
* Log Sources Covered:
    - Sysmon Event ID 1 (process_creation)
    - PowerShell Event ID 4104 (ps_script)
* Log Sources Missing / Unused:
    - None.

### 2. Custom Sigma Rule

```yaml
title: System Owner and User Discovery via Built-in Utilities (AN0254-A)
id: 643273c9-be67-42c0-a46d-9a5ef83a5a09
status: experimental
description: Detects adversarial execution of built-in user enumeration tools (whoami, quser, query user, net user) or PowerShell cmdlets used to discover local and domain user accounts.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_whoami:
        - Image|endswith: '\whoami.exe'
        - OriginalFileName: 'whoami.exe'
    selection_quser:
        - Image|endswith:
            - '\quser.exe'
            - '\query.exe'
        - OriginalFileName:
            - 'quser.exe'
            - 'query.exe'
    selection_net:
        - Image|endswith: '\net.exe'
        - OriginalFileName: 'net.exe'
    selection_net_args:
        CommandLine|contains:
            - ' user'
            - ' localgroup'
    selection_powershell:
        - Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
        - OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.dll'
    selection_powershell_args:
        CommandLine|contains:
            - 'Get-LocalUser'
            - 'Get-ADUser'
            - 'Win32_ComputerSystem'
            - 'Win32_UserAccount'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_whoami or selection_quser or (selection_net and selection_net_args) or (selection_powershell and selection_powershell_args)) and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - IT administrators executing user discovery commands for asset inventory or helpdesk support activities.
level: low
tags:
    - attack.discovery
    - attack.t1033
    - analytic.an0254
    - detection.det0093
```
