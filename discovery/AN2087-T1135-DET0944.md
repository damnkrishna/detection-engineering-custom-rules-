### 1. Technique Breakdown: T1135

* What it is: Network Share Discovery. Adversaries may look for folders and drives shared on remote systems as a means of identifying sources of information to gather or as a precursor to Lateral Movement.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): YES. SMB traffic enumeration is detectable on the wire.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

#### Rule 1 of 1: Network Share Enumeration via Native Tools
Detects the use of `net.exe` or `net1.exe` to enumerate shared folders on local or remote hosts.

```yaml
title: Network Share Enumeration via Native Tools (AN2087)
id: a1b2c3d4-e5f6-7890-abcd-ef1234567890
status: experimental
description: Detects execution of net.exe or net1.exe to list network shares on local or remote systems. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\net.exe'
            - '\net1.exe'
    selection_ofn:
        OriginalFileName:
            - 'net.exe'
            - 'net1.exe'
    selection_cli:
        CommandLine|re:
            - '(?i)\bnet(1)?\s+(share|view)\b'
    filter_logon:
        ParentCommandLine|contains: '\NETLOGON\'
    condition: (selection_images or selection_ofn) and selection_cli and not filter_logon
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Helpdesk personnel or automated scripts inventorying available shares.
level: medium
tags:
    - attack.discovery
    - attack.t1135
    - analytic.an2087
    - detection.det0944
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: SMB-Level Enumeration
  * The Issue: Tools like SharpShares or Snaffler use direct SMB API calls without invoking `net.exe`.
  * The Fix: Monitor Zeek SMB logs for high-frequency `TREE_CONNECT` requests from a single source host.
* Problem 2: PowerShell Cmdlets
  * The Issue: `Get-SmbShare` and `Get-WmiObject -Class Win32_Share` achieve the same result silently.
  * The Fix: Enable PowerShell Script Block Logging (Event ID 4104) and monitor for those cmdlets.
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present when PE metadata is intact.
  * The Fix: Treat Image and OriginalFileName as complementary — either match alone is sufficient.
