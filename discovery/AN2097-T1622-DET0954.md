### 1. Technique Breakdown: T1622

* What it is: Debugger Evasion. Adversaries may employ various means to detect and avoid debuggers to prevent reverse engineering or dynamic analysis.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines querying debug-related artifacts are captured.
  - NIDS (Suricata + Zeek): NO. Host-local discovery.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Debugger Presence Check via Registry or Process Query (AN2097)
id: e1f2a3b4-c5d6-7890-4567-890000000010
status: experimental
description: Detects command-line queries targeting debugger artifacts in the registry (Image File Execution Options, postmortem debugger) used by malware to determine if it is being debugged. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_reg:
        Image|endswith:
            - '\reg.exe'
    selection_reg_ofn:
        OriginalFileName: 'reg.exe'
    selection_reg_cli:
        CommandLine|contains:
            - 'Image File Execution Options'
            - 'AeDebug'
            - 'GlobalFlag'
            - 'postmortem'
    condition: (selection_reg or selection_reg_ofn) and selection_reg_cli
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Developers configuring just-in-time (JIT) debugging for application crash handling.
level: medium
tags:
    - attack.defense_evasion
    - attack.t1622
    - analytic.an2097
    - detection.det0954
```
