### 1. Technique Breakdown: T1497

* What it is: Virtualization/Sandbox Evasion. Adversaries may employ various means to detect and avoid virtualization or analysis environments, delaying or stopping execution in response to those conditions.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines querying VM artifacts are captured.
  - NIDS (Suricata + Zeek): NO. Host-local discovery.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

#### Rule 1 of 1: VM and Sandbox Detection Artifact Queries
Detects command-line queries for artifacts commonly checked by malware to detect virtual machine or sandbox environments.

```yaml
title: VM and Sandbox Detection Artifact Queries (AN2094)
id: b8c9d0e1-f2a3-4567-1234-567890000007
status: experimental
description: Detects execution of commands querying VM-specific registry keys, services, or hardware strings used by malware to evade analysis sandboxes. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_reg:
        Image|endswith:
            - '\reg.exe'
    selection_reg_ofn:
        OriginalFileName: 'reg.exe'
    selection_reg_cli:
        CommandLine|contains:
            - 'VirtualBox'
            - 'VMware'
            - 'VBOX'
            - 'QEMU'
            - 'Hyper-V'
            - 'Xen'
    selection_wmic:
        Image|endswith:
            - '\wmic.exe'
    selection_wmic_ofn:
        OriginalFileName: 'wmic.exe'
    selection_wmic_cli:
        CommandLine|contains:
            - 'VBOX'
            - 'VMware'
            - 'VirtualBox'
            - 'biosseralnum'
    filter_hyperv_admin:
        ParentImage|endswith:
            - '\vmconnect.exe'
            - '\vmms.exe'
    condition: (((selection_reg or selection_reg_ofn) and selection_reg_cli) or ((selection_wmic or selection_wmic_ofn) and selection_wmic_cli)) and not filter_hyperv_admin
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Legitimate virtualization management software querying its own artifacts.
level: high
tags:
    - attack.defense_evasion
    - attack.discovery
    - attack.t1497
    - analytic.an2094
    - detection.det0951
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Timing Checks
  * The Issue: Malware using execution timing (e.g. RDTSC instruction or Sleep-then-check) to detect sandboxes will leave no command-line trace.
  * The Fix: Requires dynamic analysis or behavioral sandbox engines, not Sigma rules.
* Problem 2: CPUID Instruction Checks
  * The Issue: Hypervisor detection via the `CPUID` instruction is completely invisible to process-level monitoring.
  * The Fix: Same as above — out-of-scope for host-based Sigma detection.
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present when PE metadata is intact.
  * The Fix: Treat Image and OriginalFileName as complementary — either match alone is sufficient.
