### 1. Technique Breakdown: T1124

* What it is: System Time Discovery. Adversaries may gather the system time and/or time zone information from a local or remote system to delay execution or to fingerprint the environment.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): NO. Host-local discovery.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

---

### 2. Custom Sigma Rule

#### Rule 1 of 1: System Time and Timezone Discovery
Detects the use of `net time`, `w32tm`, or `time` to gather the current system time.

```yaml
title: System Time and Timezone Discovery (AN2089)
id: c3d4e5f6-a7b8-9012-cdef-012345678902
status: experimental
description: Detects command-line queries for system time or timezone information used to fingerprint the target environment. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_net:
        Image|endswith:
            - '\net.exe'
            - '\net1.exe'
    selection_net_ofn:
        OriginalFileName:
            - 'net.exe'
            - 'net1.exe'
    selection_net_cli:
        CommandLine|re:
            - '(?i)\bnet(1)?\s+time\b'
    filter_ntp:
        ParentImage|endswith: '\w32tm.exe'
    selection_w32tm:
        Image|endswith:
            - '\w32tm.exe'
    selection_w32tm_ofn:
        OriginalFileName: 'w32tm.exe'
    selection_w32tm_cli:
        CommandLine|contains:
            - '/query'
            - '/tz'
    condition: (((selection_net or selection_net_ofn) and selection_net_cli) or ((selection_w32tm or selection_w32tm_ofn) and selection_w32tm_cli)) and not filter_ntp
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - NTP synchronization scripts or administrators verifying time skew before Kerberos authentication.
level: low
tags:
    - attack.discovery
    - attack.t1124
    - analytic.an2089
    - detection.det0946
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: GetSystemTime API
  * The Issue: Malware querying `GetSystemTime()` or `GetLocalTime()` directly will not spawn any visible process.
  * The Fix: Requires EDR telemetry for Win32 API-level monitoring.
* Problem 2: Low Signal-to-Noise as a Standalone Rule
  * The Issue: Time queries are extremely common and benign in isolation.
  * The Fix: Correlate with other discovery commands within a short time window — time discovery becomes suspicious when grouped with account/network enumeration.
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present when PE metadata is intact.
  * The Fix: Treat Image and OriginalFileName as complementary — either match alone is sufficient.
