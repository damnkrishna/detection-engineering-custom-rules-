### 1. Technique Breakdown: T1124

* What it is: System Time Discovery. Adversaries may gather the system time and/or time zone information from a local or remote system to delay execution or to fingerprint the environment.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): NO. Host-local discovery.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: System Time and Timezone Discovery (AN2089)
id: a1095471-4f29-4de4-b0ed-bfa80a5f64bb
status: experimental
description: Detects command-line queries for system time or timezone information used to fingerprint the target environment. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_net:
        Image|endswith:
            - '\net.exe'
            - '\net1.exe'
    selection_net_ofn:
        OriginalFileName:
            - 'net.exe'
            - 'net1.exe'
    selection_net_cli:
        CommandLine|re:
            - '(?i)\bnet(1)?\s+time\b'
    filter_ntp:
        ParentImage|endswith: '\w32tm.exe'
    selection_w32tm:
        Image|endswith:
            - '\w32tm.exe'
    selection_w32tm_ofn:
        OriginalFileName: 'w32tm.exe'
    selection_w32tm_cli:
        CommandLine|contains:
            - '/query'
            - '/tz'
    condition: (((selection_net or selection_net_ofn) and selection_net_cli) or ((selection_w32tm or selection_w32tm_ofn) and selection_w32tm_cli)) and not filter_ntp
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - NTP synchronization scripts or administrators verifying time skew before Kerberos authentication.
level: low
tags:
    - attack.discovery
    - attack.t1124
    - analytic.an2089
    - detection.det0946
```

### 3. OCSF Normalized Rule

```yaml
title: 'System Time and Timezone Discovery (AN2089) (OCSF-Normalized)'
id: 'a1095471-4f29-4de4-b0ed-bfa80a5f64bb'
status: experimental
description: 'OCSF Normalized rule for System Time and Timezone Discovery (AN2089)'
author: Krishna Gupta
logsource:
    product: ocsf
    class: process_activity
detection:
    selection_net:
        process.file.path|endswith:
            - '\net.exe'
            - '\net1.exe'
    selection_net_ofn:
        process.file.name:
            - 'net.exe'
            - 'net1.exe'
    selection_net_cli:
        process.cmd_line|re:
            - '(?i)\bnet(1)?\s+time\b'
    filter_ntp:
        unmapped.parent_image|endswith: '\w32tm.exe'
    selection_w32tm:
        process.file.path|endswith:
            - '\w32tm.exe'
    selection_w32tm_ofn:
        process.file.name: 'w32tm.exe'
    selection_w32tm_cli:
        process.cmd_line|contains:
            - '/query'
            - '/tz'
    condition: (((selection_net or selection_net_ofn) and selection_net_cli) or ((selection_w32tm or selection_w32tm_ofn) and selection_w32tm_cli)) and not filter_ntp
fields:
    - time
level: high
tags:
    - attack.discovery
    - attack.t1124
    - analytic.an2089
    - detection.det0946
```
