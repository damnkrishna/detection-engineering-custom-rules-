### 1. Technique Breakdown: T1007

* What it is: System Service Discovery. Adversaries may try to get information about registered local system services.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): NO. Host-local discovery.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: System Service Enumeration (AN2076)
id: cdef9001-a189-4db8-bb9a-7c9802cf0040
status: experimental
description: Detects the execution of sc.exe or net.exe to enumerate system services. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\sc.exe'
            - '\net.exe'
            - '\net1.exe'
    selection_ofn:
        OriginalFileName:
            - 'sc.exe'
            - 'net.exe'
            - 'net1.exe'
    selection_cli:
        CommandLine|contains:
            - ' query'
    condition: (selection_images or selection_ofn) and selection_cli
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - IT administrators querying service status during troubleshooting.
level: medium
tags:
    - attack.discovery
    - attack.t1007
    - analytic.an2076
    - detection.det0933
```

### 3. OCSF Normalized Rule

```yaml
title: 'System Service Enumeration (AN2076) (OCSF-Normalized)'
id: 'cdef9001-a189-4db8-bb9a-7c9802cf0040'
status: experimental
description: 'OCSF Normalized rule for System Service Enumeration (AN2076)'
author: Krishna Gupta
logsource:
    product: ocsf
    class: process_activity
detection:
    selection_images:
        process.file.path|endswith:
            - '\sc.exe'
            - '\net.exe'
            - '\net1.exe'
    selection_ofn:
        process.file.name:
            - 'sc.exe'
            - 'net.exe'
            - 'net1.exe'
    selection_cli:
        process.cmd_line|contains:
            - ' query'
    condition: (selection_images or selection_ofn) and selection_cli
fields:
    - time
level: high
tags:
    - attack.discovery
    - attack.t1007
    - analytic.an2076
    - detection.det0933
```
