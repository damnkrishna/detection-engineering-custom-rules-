### 1. Technique Breakdown: T1673

* What it is: Virtual Machine Discovery. Adversaries may attempt to gather information about any virtual machine (VM) environment present in the network to identify targets for lateral movement or to understand the infrastructure.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): NO. Host-local discovery.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

#### Rule 1 of 1: Virtual Machine Infrastructure Enumeration
Detects the use of PowerShell or WMI to enumerate virtual machine infrastructure on a Windows host.

```yaml
title: Virtual Machine Infrastructure Enumeration (AN2095)
id: c9d0e1f2-a3b4-5678-2345-678900000008
status: experimental
description: Detects command-line queries enumerating Hyper-V, VMware, or other virtualization platform infrastructure used for lateral movement planning. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_ps:
        Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
    selection_ps_ofn:
        OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.exe'
    selection_ps_cli:
        CommandLine|contains:
            - 'Get-VM'
            - 'Get-VMHost'
            - 'Get-VirtualMachine'
            - 'Get-SCVirtualMachine'
    selection_wmic:
        Image|endswith:
            - '\wmic.exe'
    selection_wmic_ofn:
        OriginalFileName: 'wmic.exe'
    selection_wmic_cli:
        CommandLine|contains:
            - 'HypervisorPresent'
            - 'Msvm_ComputerSystem'
            - 'Win32_VirtualSystemManagementService'
    condition: ((selection_ps or selection_ps_ofn) and selection_ps_cli) or ((selection_wmic or selection_wmic_ofn) and selection_wmic_cli)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Hyper-V administrators or SCVMM management tools legitimately inventorying virtual machines.
level: medium
tags:
    - attack.discovery
    - attack.t1673
    - analytic.an2095
    - detection.det0952
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: VMware vSphere API
  * The Issue: Attackers with vCenter access can enumerate all VMs via the vSphere API without touching the Windows command line.
  * The Fix: Monitor vCenter audit logs for unauthorized API calls to VM enumeration methods.
* Problem 2: Third-Party Management Consoles
  * The Issue: Tools like Veeam, Zerto, or Nutanix management consoles enumerate VMs via their own interfaces.
  * The Fix: Whitelist known management console service accounts as false positive sources.
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present when PE metadata is intact.
  * The Fix: Treat Image and OriginalFileName as complementary — either match alone is sufficient.
