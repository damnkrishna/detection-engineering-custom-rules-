### 1. Technique Breakdown: T1652

* What it is: Device Driver Discovery. Adversaries may attempt to enumerate installed device drivers to identify security software, system configurations, or potential kernel exploitation targets.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688 / PowerShell Event ID 4104.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): NO. Host-local discovery.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

---

### 2. Custom Sigma Rule

#### Rule 1 of 1: Device Driver Enumeration
Detects the use of `driverquery.exe` or `sc.exe` to enumerate installed kernel and user-mode drivers.

```yaml
title: Device Driver Enumeration (AN2092)
id: f6a7b8c9-d0e1-2345-f012-345678900005
status: experimental
description: Detects command-line utilities enumerating installed device drivers, used to identify security software or kernel exploitation targets. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_driverquery:
        Image|endswith:
            - '\driverquery.exe'
    selection_driverquery_ofn:
        OriginalFileName: 'driverquery.exe'
    selection_sc:
        Image|endswith:
            - '\sc.exe'
    selection_sc_ofn:
        OriginalFileName: 'sc.exe'
    selection_sc_cli:
        CommandLine|contains:
            - ' query type= driver'
            - ' query type=driver'
    selection_wmic:
        Image|endswith:
            - '\wmic.exe'
    selection_wmic_ofn:
        OriginalFileName: 'wmic.exe'
    selection_wmic_cli:
        CommandLine|contains: 'sysdriver'
    condition: selection_driverquery or selection_driverquery_ofn or ((selection_sc or selection_sc_ofn) and selection_sc_cli) or ((selection_wmic or selection_wmic_ofn) and selection_wmic_cli)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Administrators auditing driver health or diagnosing hardware compatibility issues.
level: medium
tags:
    - attack.discovery
    - attack.t1652
    - analytic.an2092
    - detection.det0949
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: WMI Driver Query
  * The Issue: `wmic sysdriver list` enumerates drivers without invoking `driverquery.exe`.
  * The Fix: Add a WMIC block or a generic WMIC monitoring rule for `sysdriver` queries.
* Problem 2: Registry Enumeration
  * The Issue: Attackers can read `HKLM\SYSTEM\CurrentControlSet\Services` to list drivers without any external tool.
  * The Fix: Monitor Sysmon Event ID 12/13 for access to that registry subtree.
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present when PE metadata is intact.
  * The Fix: Treat Image and OriginalFileName as complementary — either match alone is sufficient.
