### 1. Technique Breakdown: T1049

* What it is: System Network Connections Discovery. Adversaries may attempt to get a listing of network connections to or from the compromised system.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): NO. Host-local discovery command execution.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: SMB Share and Session Discovery (AN2081)
id: f023d881-819a-44f2-9ca0-80ef522f0045
status: experimental
description: Detects command-line execution querying active network sessions or mapped drives. Covers renamed net.exe via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_image:
        Image|endswith:
            - '\net.exe'
            - '\net1.exe'
    selection_ofn:
        OriginalFileName:
            - 'net.exe'
            - 'net1.exe'
    selection_cli:
        CommandLine|contains:
            - ' use'
            - ' session'
    condition: (selection_image or selection_ofn) and selection_cli
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Logon scripts mapping network drives automatically for users.
level: low
tags:
    - attack.discovery
    - attack.t1049
    - analytic.an2081
    - detection.det0938
```

### 3. OCSF Normalized Rule

```yaml
title: 'SMB Share and Session Discovery (AN2081) (OCSF-Normalized)'
id: 'f023d881-819a-44f2-9ca0-80ef522f0045'
status: experimental
description: 'OCSF Normalized rule for SMB Share and Session Discovery (AN2081)'
author: Krishna Gupta
logsource:
    product: ocsf
    class: process_activity
detection:
    selection_image:
        process.file.path|endswith:
            - '\net.exe'
            - '\net1.exe'
    selection_ofn:
        process.file.name:
            - 'net.exe'
            - 'net1.exe'
    selection_cli:
        process.cmd_line|contains:
            - ' use'
            - ' session'
    condition: (selection_image or selection_ofn) and selection_cli
fields:
    - time
level: high
tags:
    - attack.discovery
    - attack.t1049
    - analytic.an2081
    - detection.det0938
```
