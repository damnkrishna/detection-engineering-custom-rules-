### 1. Technique Breakdown: T1049

* What it is: System Network Connections Discovery. Adversaries may attempt to get a listing of network connections to or from the compromised system.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): NO. Host-local discovery command execution.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

---

### 2. Custom Sigma Rule

#### Rule 1 of 1: SMB Share and Session Discovery
Detects the use of `net.exe` to enumerate active SMB connections or open sessions on a system.

```yaml
title: SMB Share and Session Discovery (AN2081)
id: f023d881-819a-44f2-9ca0-80ef522f0045
status: experimental
description: Detects command-line execution querying active network sessions or mapped drives. Covers renamed net.exe via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_image:
        Image|endswith:
            - '\net.exe'
            - '\net1.exe'
    selection_ofn:
        OriginalFileName:
            - 'net.exe'
            - 'net1.exe'
    selection_cli:
        CommandLine|contains:
            - ' use'
            - ' session'
    condition: (selection_image or selection_ofn) and selection_cli
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Logon scripts mapping network drives automatically for users.
level: low
tags:
    - attack.discovery
    - attack.t1049
    - analytic.an2081
    - detection.det0938
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Logon Script Noise
  * The Issue: Enterprise environments use `net use` in standard `logon.bat` scripts.
  * The Fix: Filter out standard script execution paths (`ParentImage` ending in `\cmd.exe` executing from `\NETLOGON\`) or whitelist specific automated service accounts.
* Problem 2: Broad ' file' Substring Removed
  * The Issue: `' file'` was previously included but is too broad — it matches any command line containing that sequence.
  * The Fix: Removed. Covered adequately by `' use'` and `' session'` which are specific to network connection discovery.
* Problem 3: Evasion via PowerShell
  * The Issue: `Get-SmbConnection` or `Get-SmbSession` provides the same data without triggering this rule.
  * The Fix: Enable PowerShell Script Block logging (Event ID 4104) to catch cmdlet equivalents.
* Problem 4: OriginalFileName availability
  * The Issue: OriginalFileName is only present in Sysmon logs when PE metadata is intact; packed or hollowed binaries may lack it.
  * The Fix: Treat the Image and OriginalFileName paths as complementary — either catch alone is sufficient.
