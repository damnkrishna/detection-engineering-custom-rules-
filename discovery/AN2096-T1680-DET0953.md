### 1. Technique Breakdown: T1680

* What it is: Local Storage Discovery. Adversaries may enumerate local storage devices to identify data stores for collection or to locate credentials and sensitive files.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): NO. Host-local discovery.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

---

### 2. Custom Sigma Rule

#### Rule 1 of 1: Local Storage Device Enumeration
Detects the use of `fsutil`, `diskpart`, or WMIC to enumerate local storage volumes and drives.

```yaml
title: Local Storage Device Enumeration (AN2096)
id: d0e1f2a3-b4c5-6789-3456-789000000009
status: experimental
description: Detects command-line enumeration of local disk volumes and storage devices used to identify data collection targets. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_fsutil:
        Image|endswith:
            - '\fsutil.exe'
    selection_fsutil_ofn:
        OriginalFileName: 'fsutil.exe'
    selection_fsutil_cli:
        CommandLine|contains:
            - ' fsinfo drives'
    selection_wmic:
        Image|endswith:
            - '\wmic.exe'
    selection_wmic_ofn:
        OriginalFileName: 'wmic.exe'
    selection_wmic_cli:
        CommandLine|contains:
            - ' logicaldisk '
            - ' diskdrive '
    filter_inventory:
        ParentImage|endswith: '\ccmexec.exe'
    condition: (((selection_fsutil or selection_fsutil_ofn) and selection_fsutil_cli) or ((selection_wmic or selection_wmic_ofn) and selection_wmic_cli)) and not filter_inventory
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Asset inventory scripts or disk management utilities performing routine checks.
level: low
tags:
    - attack.discovery
    - attack.t1680
    - analytic.an2096
    - detection.det0953
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Win32 API Enumeration
  * The Issue: Malware using `GetLogicalDrives()` or `FindFirstVolume()` directly will produce no command-line artifacts.
  * The Fix: Requires EDR API-level monitoring for volume enumeration calls.
* Problem 2: PowerShell Equivalents
  * The Issue: `Get-PSDrive` or `Get-Volume` provides equivalent information without invoking the detected binaries.
  * The Fix: Enable PowerShell Script Block Logging (Event ID 4104) and monitor for those cmdlets.
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present when PE metadata is intact.
  * The Fix: Treat Image and OriginalFileName as complementary — either match alone is sufficient.
