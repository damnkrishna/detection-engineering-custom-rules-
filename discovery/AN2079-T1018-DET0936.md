### 1. Technique Breakdown: T1018

* What it is: Remote System Discovery. Adversaries may attempt to get a listing of other systems by IP address, hostname, or other logical identifiers on a network that may be used for Lateral Movement.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines for Active Directory queries and network viewing are captured.
  - NIDS (Suricata + Zeek): YES. Active Directory LDAP queries (port 389) or SMB enumeration (port 445) can be observed.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

#### Rule 1 of 1: Remote System Discovery via Native Tools
Detects the use of native Windows utilities to enumerate domain controllers or remote endpoints.

```yaml
title: Remote System Discovery via Native Tools (AN2079)
id: f023d881-819a-44f2-9ca0-80ef522f0043
status: experimental
description: Detects command-line utilities querying the domain for computer objects or domain controllers. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\nltest.exe'
            - '\net.exe'
            - '\net1.exe'
    selection_ofn:
        OriginalFileName:
            - 'nltest.exe'
            - 'net.exe'
            - 'net1.exe'
    selection_cli:
        CommandLine|contains:
            - '/dclist:'
            - '/domain_trusts'
            - ' view'
    condition: (selection_images or selection_ofn) and selection_cli
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Domain administrators checking trust relationships or listing available shares.
level: medium
tags:
    - attack.discovery
    - attack.t1018
    - analytic.an2079
    - detection.det0936
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: PowerShell ActiveDirectory Module
  * The Issue: If the attacker uses `Get-ADComputer` or `Get-ADDomainController`, this process rule will not catch it.
  * The Fix: Ensure PowerShell module logging is enabled, or monitor LDAP traffic at the network level using Suricata.
* Problem 2: Evasion via Third-Party Scanners
  * The Issue: Tools like Advanced IP Scanner or Nmap do not rely on `nltest` or `net view`.
  * The Fix: Detect the execution of the scanner binaries or the resulting internal port-scanning traffic.
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present in Sysmon logs when PE metadata is intact; packed or hollowed binaries may lack it.
  * The Fix: Treat the Image and OriginalFileName paths as complementary — either catch alone is sufficient.
