### 1. Technique Breakdown: T1083

* What it is: File and Directory Discovery. Adversaries may enumerate files and directories or search in specific locations for interesting data or credentials.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): NO. Host-local discovery.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

---

### 2. Custom Sigma Rule

#### Rule 1 of 1: Recursive Directory Enumeration
Detects command-line parameters indicating a recursive search or full directory tree listing.

```yaml
title: Recursive Directory Enumeration (AN2084)
id: cbdf2001-a189-4db8-bb9a-7c9802cf0048
status: experimental
description: Detects command-line operations performing recursive directory listings or searching for files across the entire file system. Covers renamed binaries via OriginalFileName to resist trivial binary-rename evasion.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_cmd:
        Image|endswith:
            - '\cmd.exe'
    selection_cmd_ofn:
        OriginalFileName: 'Cmd.Exe'
    selection_cmd_args:
        CommandLine|contains:
            - 'dir /s'
            - 'tree /F'
    selection_tree:
        Image|endswith:
            - '\tree.com'
    selection_tree_ofn:
        OriginalFileName: 'TREE.COM'
    condition: ((selection_cmd or selection_cmd_ofn) and selection_cmd_args) or selection_tree or selection_tree_ofn
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Developers searching for lost source files or administrators documenting folder structures.
level: low
tags:
    - attack.discovery
    - attack.t1083
    - analytic.an2084
    - detection.det0941
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Shell-less Traversal
  * The Issue: Ransomware and data-stealers use native Windows APIs (e.g. `FindFirstFile`, `FindNextFile`) to crawl directories without spawning `cmd.exe` or `tree.com`.
  * The Fix: Monitor for rapid file access patterns using Windows Security Event ID 4663 (File Access) or File System Minifilter drivers (Sysmon Event ID 11).
* Problem 2: Evasion via PowerShell
  * The Issue: `Get-ChildItem -Recurse` provides identical functionality and bypasses this rule.
  * The Fix: Implement corresponding PowerShell script block monitoring (Event ID 4104).
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present in Sysmon logs when PE metadata is intact; packed or hollowed binaries may lack it.
  * The Fix: Treat the Image and OriginalFileName paths as complementary — either catch alone is sufficient.
