### 1. Technique Breakdown: T1201

* What it is: Password Policy Discovery. Adversaries query local or domain password policies to understand account lockout thresholds, minimum password lengths, and complexity requirements. This informs credential attacks — for example, discovering a 10-attempt lockout threshold allows attackers to safely attempt 9 passwords per account without triggering lockouts. Common tools include net.exe accounts, secedit.exe /export, or PowerShell Active Directory cmdlets like Get-ADDefaultDomainPasswordPolicy.
* Log Source Requirements: Host process creation and command line logs (Sysmon Event ID 1 / Windows Security Event ID 4688) and PowerShell Script Block Logs (Event ID 4104).
* Coverage Check:
    * HIDS (Sysmon + Windows Defender): YES. Sysmon Event ID 1 captures execution of net.exe, secedit.exe, and PowerShell along with their command-line arguments. Event ID 4104 logs script block details.
    * Windows Security Logs: PARTIAL. Security logs EID 4688 captures command lines if enabled.
* Log Sources Covered:
    - Sysmon Event ID 1 (process_creation)
    - PowerShell Event ID 4104 (ps_script)
* Log Sources Missing / Unused:
    - None.

### 2. Custom Sigma Rule

```yaml
title: Password Policy Discovery via CLI (AN0455-A)
id: 5a70d96f-5372-42b7-900f-60b5a8f9f334
status: experimental
description: Detects adversarial execution of commands querying local or domain password policy settings such as net accounts, secedit /export, or PowerShell AD cmdlets for password policy discovery.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_net:
        - Image|endswith: '\net.exe'
        - OriginalFileName: 'net.exe'
    selection_net_args:
        CommandLine|contains: ' accounts'
    selection_secedit:
        - Image|endswith: '\secedit.exe'
        - OriginalFileName: 'secedit.exe'
    selection_secedit_args:
        CommandLine|contains: '/export'
    selection_powershell:
        - Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
        - OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.dll'
    selection_powershell_args:
        CommandLine|contains:
            - 'Get-ADDefaultDomainPasswordPolicy'
            - 'Get-ADFineGrainedPasswordPolicy'
            - 'PasswordPolicy'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: ((selection_net and selection_net_args) or (selection_secedit and selection_secedit_args) or (selection_powershell and selection_powershell_args)) and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Security compliance scripts or audit tools that query password policies as part of regular CIS benchmark assessments.
level: medium
tags:
    - attack.discovery
    - attack.t1201
    - analytic.an0455
    - detection.det0161
```
