### 1. Technique Breakdown: T1057

* What it is: Process Discovery. Adversaries enumerate running processes on a target host to identify active security tools, running services, or user applications. The information helps adversaries determine if a host is being monitored, which security products are active, or where to inject malicious code. Common enumeration tools include tasklist.exe, wmic.exe process list, or PowerShell's Get-Process cmdlet.
* Log Source Requirements: Host process creation and command line logs (Sysmon Event ID 1 / Windows Security Event ID 4688) and PowerShell Script Block Logs (Event ID 4104).
* Coverage Check:
    * HIDS (Sysmon + Windows Defender): YES. Sysmon Event ID 1 captures spawning of tasklist.exe, wmic.exe, and PowerShell. Event ID 4104 logs script block details.
    * Windows Security Logs: PARTIAL. Security logs EID 4688 captures command lines if enabled.
* Log Sources Covered:
    - Sysmon Event ID 1 (process_creation)
    - PowerShell Event ID 4104 (ps_script)
* Log Sources Missing / Unused:
    - None.

### 2. Custom Sigma Rule

```yaml
title: Process Discovery via Enumeration Utilities (AN0095-A)
id: 751319f9-8e8b-4e58-8ac1-5dc06ebb146c
status: experimental
description: Detects adversarial execution of process enumeration tools (tasklist.exe, wmic process, Get-Process) used to discover running processes on a compromised host.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_tasklist:
        - Image|endswith: '\tasklist.exe'
        - OriginalFileName: 'tasklist.exe'
    selection_wmic:
        - Image|endswith: '\wmic.exe'
        - OriginalFileName: 'wmic.exe'
    selection_wmic_args:
        CommandLine|contains:
            - ' process'
    selection_powershell:
        - Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
        - OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.dll'
    selection_powershell_args:
        CommandLine|contains:
            - 'Get-Process'
            - 'Get-WmiObject Win32_Process'
            - 'Get-CimInstance Win32_Process'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_tasklist or (selection_wmic and selection_wmic_args) or (selection_powershell and selection_powershell_args)) and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - System administrators running process inventories for health checks, or monitoring tools that periodically enumerate running services.
level: medium
tags:
    - attack.discovery
    - attack.t1057
    - analytic.an0095
    - detection.det0034
```

```yaml
title: Process Discovery via PowerShell Script Block (AN0095-B)
id: d476969e-159d-422c-bc32-efb3a362fa71
status: experimental
description: Detects PowerShell script blocks querying active processes using Win32 API or WMI cmdlets.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: ps_script
    product: windows
    # Relies on PowerShell Script Block Logging (Event ID 4104)
detection:
    selection_keywords:
        ScriptBlockText|contains:
            - 'Get-Process'
            - 'Win32_Process'
            - 'System.Diagnostics.Process'
            - 'Get-WmiObject -Class Win32_Process'
    condition: selection_keywords
fields:
    - ScriptBlockText
falsepositives:
    - Authorized administrative or developer script tasks running process diagnostics.
level: medium
tags:
    - attack.discovery
    - attack.t1057
    - analytic.an0095
    - detection.det0034
```
