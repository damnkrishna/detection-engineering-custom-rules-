### 1. Technique Breakdown: T1572 & T1059.001

* **Description**: Detects an inbound SSH connection (Zeek) followed by powershell.exe making outbound network connections (Sysmon Event ID 3) on the same host within 15 minutes, which indicates a reverse shell tunnel or command injection over SSH.
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Zeek connection logs auditing inbound SSH connections.
  * Sysmon Network Connection (Event ID 3) where the initiating process is `powershell.exe` or `pwsh.exe`.
* **Coverage Check**:
  * HIDS (Sysmon): YES. Logs process network connections.
  * NIDS (Zeek): YES. Logs SSH connections.

### 3. Blind Spots & Tuning (The "Problems")

* **Problem 1: Administrative Server Operations**
  * *Issue*: System administrators may log in using SSH to run PowerShell commands that retrieve system updates or contact external APIs.
  * *Fix*: Ignore outbound connections to trusted internal update nodes, or whitelist IP ranges belonging to internal developer systems.
* **Problem 2: Non-shell PowerShell Network Queries**
  * *Issue*: Legitimate scripts running inside the active user context might periodically make DNS or API requests during the SSH session.
  * *Fix*: Check the child process command argument parameters in Stage 1 to require explicit network connection flags.
