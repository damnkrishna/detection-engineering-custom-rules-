### 1. Technique Breakdown: T1071.001 & T1218.011

* **Description**: Detects Cobalt Strike beacon HTTP communication traffic (Suricata malleable profile signature match) followed by `rundll32.exe` executing with an empty or abnormally short command line (Sysmon) on the target host within 15 minutes.
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Suricata NIDS signatures auditing Cobalt Strike malleable profile request patterns.
  * Sysmon Process Creation (Event ID 1) tracking `rundll32.exe` executions.
* **Coverage Check**:
  * HIDS (Sysmon): YES. Cobalt Strike beacons injected into `rundll32.exe` often run without standard command arguments, which is a major execution indicator.
  * NIDS (Suricata): YES. Excellent for auditing malleable C2 communication headers.

### 3. Blind Spots & Tuning (The "Problems")

* **Problem 1: Malleable Profile Customization**
  * *Issue*: Skilled adversaries customize their malleable profiles to blend in with legitimate traffic (e.g., mimicking Google Analytics headers), bypassing default Suricata rules.
  * *Fix*: Look for anomalous domain reputations or SSL certificate parameters rather than relying on default HTTP header patterns.
* **Problem 2: Benign Empty Command Lines**
  * *Issue*: Standard application installers occasionally spawn `rundll32.exe` without parameters for initialization hooks.
  * *Fix*: Require the Suricata event in Stage 0 to confirm external egress before alerting on empty parameter execution.
