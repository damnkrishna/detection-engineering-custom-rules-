### 1. Technique Breakdown: T1071.001 & T1055

* **Description**: Detects outbound HTTPS connection patterns indicative of periodic command and control (C2) beaconing (Zeek), followed by a local process thread injection event (Sysmon Event ID 8) on the same host within 30 minutes.
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Zeek SSL connection logs auditing outbound connection intervals.
  * Sysmon Process Access/Injection logs (Event ID 8) auditing thread creations in external processes.
* **Coverage Check**:
  * HIDS (Sysmon): YES. Sysmon logs thread injection target and source processes.
  * NIDS (Zeek): YES. Identifies repetitive TLS connection parameters and interval patterns.
