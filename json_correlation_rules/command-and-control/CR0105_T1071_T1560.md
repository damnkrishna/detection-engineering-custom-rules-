### 1. Technique Breakdown: T1071.001 & T1560

* **Description**: Detects an anomalous ratio of HTTP POST traffic relative to GET traffic outbound (Zeek), followed by the execution of a file compression utility like 7z or WinRAR (Sysmon) on the target host within 30 minutes.
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Zeek HTTP logs tracking POST request byte sizes and counts.
  * Sysmon Process Creation (Event ID 1) auditing compression utilities (`7z.exe`, `winrar.exe`, `tar.exe`, `zip.exe`).
* **Coverage Check**:
  * HIDS (Sysmon): YES. Detects archive tool executions.
  * NIDS (Zeek): YES. Identifies anomalies in POST vs GET ratios.
