### 1. Technique Breakdown: T1095 & T1572

* **Description**: Detects outbound traffic on non-standard network ports (Zeek) followed by local administrative commands executing `netsh.exe` to configure port forwarding/proxying (Sysmon) on the target host within 15 minutes.
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Zeek connection logs auditing outbound network sessions on non-standard/uncommon ports.
  * Sysmon Process Creation (Event ID 1) auditing `netsh.exe` with arguments containing `portproxy` or `v4tov4`.
* **Coverage Check**:
  * HIDS (Sysmon): YES. Tracks process command lines for netsh configurations.
  * NIDS (Zeek): YES. Identifies anomalies in outbound ports and connection durations.
