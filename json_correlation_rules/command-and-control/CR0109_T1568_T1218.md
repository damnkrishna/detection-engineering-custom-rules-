### 1. Technique Breakdown: T1568 & T1218.007

* **Description**: Detects outbound DNS requests for dynamic DNS (DDNS) providers (Zeek) followed by the execution of `certutil.exe` with flags configured to download files (`-urlcache`, `-split`, `-ping`) on the target host within 15 minutes.
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Zeek DNS logs resolving dynamic DNS provider domains (e.g. `no-ip.org`, `dyndns.org`, `duckdns.org`).
  * Sysmon Process Creation (Event ID 1) tracking `certutil.exe` execution.
* **Coverage Check**:
  * HIDS (Sysmon): YES. Processes spawned post-execution are audited.
  * NIDS (Zeek): YES. Identifies dynamic DNS domain queries.

### 3. Blind Spots & Tuning (The "Problems")

* **Problem 1: Legitimate IT Diagnostics**
  * *Issue*: IT administrators occasionally run diagnostics checking CRLs (Certificate Revocation Lists) using `certutil.exe -urlcache` which queries dynamic/CDN-based domains.
  * *Fix*: Restrict the Stage 0 domains to ignore standard CRL endpoints (like `crl.microsoft.com` or `sectigo.com`).
* **Problem 2: Alternate Certutil Binary Name**
  * *Issue*: Attackers can copy `certutil.exe` to a temporary directory and rename it (e.g. `helper.exe`), bypassing the process name check.
  * *Fix*: Include checking for the Original File Name property (`certutil.exe`) in the Sysmon Event ID 1 configurations.
