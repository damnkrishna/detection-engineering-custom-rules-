### 1. Technique Breakdown: T1071.004 & T1218

* **Description**: Detects DNS tunneling traffic on port 53 (high frequency of TXT/MX queries or anomalous subdomain lengths detected by Zeek/Suricata) followed by local shell or LOLBin execution on the same host within 5 minutes.
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Zeek DNS log auditing query frequencies and large query payloads on port 53 with target anchoring.
  * Sysmon Process Creation (Event ID 1) logging scripting hosts or LOLBin execution with suspicious command-line arguments, excluding common benign parent processes.
* **Coverage Check**:
  * HIDS (Sysmon): YES. Processes spawned post-execution are audited.
  * NIDS (Zeek): YES. Excellent for auditing anomalous domain resolutions.
