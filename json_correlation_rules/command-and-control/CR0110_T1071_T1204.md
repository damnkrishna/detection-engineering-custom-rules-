### 1. Technique Breakdown: T1071.003 & T1204

* **Description**: Detects outbound email protocol traffic over SMTP/IMAP ports (Zeek) associated with a non-mail client process executing on the host (Sysmon Event ID 3 network connection initiated by scripting tools, shells, or unrecognized executables) within 15 minutes.
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Zeek connection logs auditing traffic on port 25, 465, 587, 143, or 993.
  * Sysmon Network Connection (Event ID 3) where the initiating process is not a recognized mail client (excluding `outlook.exe`, `thunderbird.exe`, `mail.exe`).
* **Coverage Check**:
  * HIDS (Sysmon): YES. Processes initiating TCP network sockets are logged.
  * NIDS (Zeek): YES. Identifies standard email protocol communication.

### 3. Blind Spots & Tuning (The "Problems")

* **Problem 1: Administrative Alerting Scripts**
  * *Issue*: Local custom script files running under PowerShell might be configured to send automated diagnostic emails using local SMTP servers.
  * *Fix*: Ignore outbound connections to verified internal enterprise SMTP relay servers.
* **Problem 2: Non-standard Ports**
  * *Issue*: Legacy web mail systems running custom applications might use customized ports for synchronization.
  * *Fix*: Ensure the Zeek network parser triggers on SMTP/IMAP protocol identification rather than hardcoded port numbers.
