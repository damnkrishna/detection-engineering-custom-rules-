### 1. Technique Breakdown: T1021.001, T1003.001 & T1572

* **Description**: Detects lateral movement where an attacker utilizes a port forwarding mechanism to perform a Remote Desktop Protocol (RDP) logon on the local loopback interface (protocol tunneling), followed by LSASS memory dumping to harvest credentials.
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Windows Security/Sysmon logs auditing local loopback RDP connections (Logon Type 10/3 from `127.0.0.1` or `::1`).
  * Sysmon Process Access Event ID 10 targeting `lsass.exe` with credential-dumping access rights (`0x1010`).
* **Coverage Check**:
  * HIDS (Sysmon + Windows Security logs): YES. Captures local loopback logons and LSASS handle requests.
