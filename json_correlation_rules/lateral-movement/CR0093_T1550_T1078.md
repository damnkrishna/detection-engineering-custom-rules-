### 1. Technique Breakdown: T1550.002 & T1078.002

* **Description**: Detects lateral movement via Pass-the-Hash (PtH) where NTLM authentication is observed over the network (Zeek), followed by a successful administrative logon on the target endpoint utilizing NTLM instead of Kerberos (Sysmon / Event ID 4624 Logon Type 3).
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Zeek connection/security logs auditing NTLM network authentication sessions.
  * Windows Security Event ID 4624 Logon Type 3 where the authentication package is NTLM, and the key length is 0 (indicative of PtH since no cleartext password or standard hash exchange took place).
* **Coverage Check**:
  * HIDS (Windows Security logs): YES. Mapped to Logon Type 3 with NTLM package.
  * NIDS (Zeek): YES. Identifies the NTLM authentication layer over ports 445/139.
