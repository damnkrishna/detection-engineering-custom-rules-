### 1. Technique Breakdown: T1021.002 & T1105

* **Description**: Detects an inbound SMB share map connection on port 445 (Zeek) followed by a file creation event (Sysmon Event ID 11) of payload file extensions from the remote mapped share on the target host within 15 minutes, identifying incoming payload delivery over remote mount points.
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Zeek logs auditing SMB Tree Connect events mapping network shares on port 445 with target anchoring.
  * Sysmon File Create (Event ID 11) logging file creation of executable/payload extensions originating from a UNC mapped path.
* **Coverage Check**:
  * HIDS (Sysmon): YES. Logs file creation timestamps, extensions, and directory paths.
  * NIDS (Zeek): YES. Identifies SMB tree connections (mapping shares) on port 445.
