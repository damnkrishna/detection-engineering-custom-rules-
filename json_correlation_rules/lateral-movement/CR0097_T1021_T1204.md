### 1. Technique Breakdown: T1021.003

* **Description**: Detects lateral movement via Distributed COM (DCOM) where an inbound RPC/DCOM session on port 135 (Zeek) is followed by Microsoft Excel (`excel.exe`) spawning process shells (such as `cmd.exe`, `powershell.exe`, `pwsh.exe`, `cscript.exe`, or `wscript.exe`) on the target host within 15 minutes.
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Zeek connection logs auditing RPC traffic on port 135 (DCOM port) with target anchoring.
  * Sysmon Process Creation (Event ID 1) where the parent process is `excel.exe` and the child process is a shell or scripting interpreter.
* **Coverage Check**:
  * HIDS (Sysmon): YES. Mapped to process creation. When Excel runs via DCOM, it is instantiated by `svchost.exe -k DcomLaunch`, and if it spawns a command shell, that process runs as a child of `excel.exe`.
  * NIDS (Zeek): YES. Captures the initial RPC bind calls and DCOM activations on port 135.
