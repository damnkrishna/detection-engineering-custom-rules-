### 1. Technique Breakdown: T1021 & T1547.001

* **Description**: Detects lateral movement where an attacker utilizes remote RPC calls to connect to the target machine's Registry (Zeek), followed by modifying standard auto-run persistence keys (`Run`, `RunOnce`) via remote registry edits (Sysmon Event ID 13).
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Zeek connection logs auditing RPC traffic associated with winreg/remote registry services.
  * Sysmon Registry Event (Event ID 13 - Registry value set) modifying `CurrentVersion\Run` or `CurrentVersion\RunOnce` paths.
* **Coverage Check**:
  * HIDS (Sysmon): YES. Mapped to registry key writes.
  * NIDS (Zeek): YES. Identifies RPC binds to the winreg UUID.

### 3. Blind Spots & Tuning (The "Problems")

* **Problem 1: Centralized GPO Update Deployment**
  * *Issue*: GPO updates pushed from domain controllers modifying client registries remotely can look like remote registry auto-run modifications.
  * *Fix*: Ignore registry writes originating from domain controller IP ranges or SYSTEM accounts associated with domain controllers.
* **Problem 2: Security Agent Updates**
  * *Issue*: Remote deployment of endpoint protection agents often updates registry startup settings.
  * *Fix*: Add exclusions for known antivirus service accounts or authorized deployment tools.
