### 1. Technique Breakdown: T1071.001 & T1055

* **Description**: Detects outbound HTTPS connection patterns indicative of periodic command and control (C2) beaconing (Zeek), followed by a local process thread injection event (Sysmon Event ID 8) on the same host within 30 minutes.
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Zeek SSL connection logs auditing outbound connection intervals.
  * Sysmon Process Access/Injection logs (Event ID 8) auditing thread creations in external processes.
* **Coverage Check**:
  * HIDS (Sysmon): YES. Sysmon logs thread injection target and source processes.
  * NIDS (Zeek): YES. Identifies repetitive TLS connection parameters and interval patterns.

### 3. Blind Spots & Tuning (The "Problems")

* **Problem 1: Legitimate Software Telemetry Beaconing**
  * *Issue*: Software agents (like Chrome update service, Dropbox client) establish persistent HTTPS connections at scheduled intervals, mimicking beacons.
  * *Fix*: Tune Stage 0 by filtering out SSL connections destined for well-known CDN networks or verified software updater domains.
* **Problem 2: Browser Thread Injection False Positives**
  * *Issue*: Browsers (like Chrome, Edge) use remote threads between tab processes, creating noise in Sysmon Event ID 8.
  * *Fix*: Exclude thread injection events where the source and target process are both instances of the same signed browser executable (e.g. `chrome.exe` injecting into `chrome.exe`).
