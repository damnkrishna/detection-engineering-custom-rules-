* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Zeek DNS log auditing query frequencies and large query payloads on port 53 with target anchoring.
  * Sysmon Process Creation (Event ID 1) logging scripting hosts or LOLBin execution with suspicious command-line arguments, excluding common benign parent processes.
* **Coverage Check**:
  * HIDS (Sysmon): YES. Processes spawned post-execution are audited.

### 3. Blind Spots & Tuning (The "Problems")

* **Problem 1: Antivirus Signature Updates over DNS**
  * *Issue*: Security products sometimes use highly structured, long TXT DNS queries to perform rapid reputation checks.
  * *Fix*: Whitelist domains associated with legitimate security vendors (e.g. Sophos, McAfee, TrendMicro) from the DNS lookup checks.
* **Problem 2: Reverse Proxy / CDN Resolution**
  * *Issue*: CDNs generate complex subdomain strings for request routing.
  * *Fix*: Tune the threshold in Stage 0 to require a higher frequency of queries (e.g., >20 within 1 minute) or filter by query type (TXT/MX/CNAME).
