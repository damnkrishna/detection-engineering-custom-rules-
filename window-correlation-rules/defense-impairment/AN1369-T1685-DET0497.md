### **1. Technique Breakdown: T1685**

* **What it is:** **Disable or Modify Tools**. Adversaries may disable or modify security tools (AV, EDR, Sysmon, firewalls) to avoid detection. This includes killing processes, stopping services, altering registry keys (like disabling Windows Defender), or tampering with exclusion lists.
* **Log Source Requirements:** Process creation logs (Sysmon Event ID 1), Service logs (System Event ID 7036/7045), and Registry modification logs (Sysmon Event ID 13).
* **Coverage Check:**
    * **HIDS (Sysmon + Wazuh): YES.** Sysmon captures command-line attempts to stop services or kill processes (`net stop`, `taskkill`) and registry changes to security tools.
    * **NIDS (Suricata + Zeek): NO.** Tool modification is a host-centric activity.

---

### **2. Custom Sigma Rule**

This rule utilizes **Sysmon Event ID 1 (Process Creation)** to detect common command-line execution attempting to disable or kill known security services or processes.

```yaml
title: Disable or Modify Tools - Kill Security Process (AN1369)
id: f9dbce1d-6526-4d04-ae6f-0050cd6edc33
status: experimental
description: Detects command-line execution attempting to stop services or kill processes associated with security tools (AV, EDR, Sysmon).
author: Krishna Gupta
date: 2026-06-09
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1 collected via Wazuh
detection:
    selection_tool:
        Image|endswith:
            - '\taskkill.exe'
            - '\net.exe'
            - '\net1.exe'
            - '\sc.exe'
    selection_target:
        CommandLine|contains:
            - 'WinDefend'
            - 'MsMpEng'
            - 'Sysmon'
            - 'Sentinel'
            - 'CrowdStrike'
    condition: selection_tool and selection_target
fields:
    - CommandLine
    - Image
falsepositives:
    - System administrators uninstalling or upgrading endpoint security software.
level: high
tags:
    - attack.defense_evasion
    - attack.t1685
    - analytics.an1369
    - detection.det0497
```

### **3. Blind Spots & Tuning (The "Problems")**

* **Problem 1: Direct API Process Termination**
    * *The Issue:* Attackers can use API calls (`TerminateProcess`) or PowerShell (`Stop-Process`) instead of `taskkill.exe`, evading command-line string matching.
    * *The Fix:* Enable Sysmon Event ID 10 (Process Access) and monitor for suspicious processes requesting `PROCESS_TERMINATE` access to known EDR/AV PIDs.

* **Problem 2: Registry/GPO Disablement**
    * *The Issue:* Attackers disable tools by modifying the registry (e.g., `DisableAntiSpyware`) rather than killing the running process.
    * *The Fix:* Implement a separate Sigma rule monitoring Sysmon Event ID 13 for modifications to `HKLM\SOFTWARE\Policies\Microsoft\Windows Defender`.

* **Problem 3: Driver-Level Termination (BYOVD)**
    * *The Issue:* "Bring Your Own Vulnerable Driver" attacks load a signed but vulnerable driver to kill EDR processes from the kernel level, bypassing user-land protections.
    * *The Fix:* Monitor Driver Load events (Sysmon Event ID 6) for known vulnerable driver hashes and alert on unexpected kernel-level process terminations.
