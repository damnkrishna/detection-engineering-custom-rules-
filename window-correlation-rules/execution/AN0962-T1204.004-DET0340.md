### 1. Technique Breakdown: T1204.004

* What it is: User Execution: Malicious Copy and Paste. Adversaries socially engineer users into copying an obfuscated command from a website, document, or email, and pasting it directly into a terminal interface (like CMD or PowerShell), initiating remote access or payload downloads.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Parent-child process relationships and terminal command-line parameters are tracked.
  - NIDS (Suricata + Zeek): YES. Egress downloads initiated by the terminal can be flagged.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

#### Rule 1 of 2: Command Shell Spawned from User Application Context
Detects command interpreters or script hosts spawned directly by web browsers, email clients, office applications, or PDF readers with execution arguments.

```yaml
title: Command Shell Spawned from User Application Context (AN0962-A)
id: cbdf2001-a189-4db8-bb9a-7c9802cf0014
status: experimental
description: Detects command-line interpreters or script hosts spawned directly by browsers, mail agents, or document viewers.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_parents:
        ParentImage|endswith:
            - '\chrome.exe'
            - '\msedge.exe'
            - '\firefox.exe'
            - '\outlook.exe'
            - '\excel.exe'
            - '\winword.exe'
            - '\acrord32.exe'
    selection_images:
        Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\wscript.exe'
            - '\cscript.exe'
            - '\mshta.exe'
    selection_cli:
        CommandLine|contains:
            - ' -enc '
            - ' -encodedcommand '
            - 'iex'
            - 'downloadstring'
            - 'downloadfile'
            - 'bypass'
            - '-nop'
            - '-w hidden'
    condition: selection_parents and selection_images and selection_cli
fields:
    - Image
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - IT administrators testing script integration or standard software help files opening diagnostic cmd windows.
level: high
tags:
    - attack.execution
    - attack.t1204.004
    - analytic.an0962
    - detection.det0340
```

#### Rule 2 of 2: Download Utility Spawned by User Application
Detects command-line download utilities executed directly from browser, mail, or document contexts, filtering out legitimate software updaters and installers.

```yaml
title: Download Utility Spawned by User Application (AN0962-B)
id: f48debb3-cb3d-4c3e-b8d9-cc90e2cf0015
status: experimental
description: Detects process launches of command-line download engines from user browser, mail, or reader applications.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_parents:
        ParentImage|endswith:
            - '\chrome.exe'
            - '\msedge.exe'
            - '\firefox.exe'
            - '\outlook.exe'
            - '\excel.exe'
            - '\winword.exe'
            - '\acrord32.exe'
    selection_images:
        Image|endswith:
            - '\curl.exe'
            - '\wget.exe'
            - '\certutil.exe'
            - '\bitsadmin.exe'
    filter_updaters:
        CommandLine|contains:
            - '\AppData\Local\Google\Update\'
            - '\AppData\Local\Microsoft\EdgeUpdate\'
            - '\AppData\Local\Temp\'
    filter_installers:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
            - '\update.exe'
    condition: selection_parents and selection_images and not (filter_updaters or filter_installers)
fields:
    - Image
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Software install updates triggered from web interface redirects.
level: medium
tags:
    - attack.execution
    - attack.t1204.004
    - analytic.an0962
    - detection.det0340
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Administrative Help Integration
  * The Issue: Some local administrative dashboards or offline documentation tools spawn browsers that in turn invoke setup tools, triggering false alarms.
  * The Fix: Baseline standard developer tools and exclude legitimate internal build directories from the parent image scope.
* Problem 2: Evasion via Clipboard Monitoring
  * The Issue: If the attacker intercepts clipboard data programmatically using API calls rather than manual copy-paste, this rule will not trigger.
  * The Fix: Monitor unauthorized DLL imports or API hooks targeting user interface text libraries.
