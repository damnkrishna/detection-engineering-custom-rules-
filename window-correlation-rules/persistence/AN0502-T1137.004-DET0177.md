# AN0502 - Office Application Startup: Outlook Home Page (T1137.004)

## Technique Breakdown
Adversaries may abuse Microsoft Outlook's Home Page feature to establish persistence and execute malicious code. Outlook allows assigning a specific URL or local file as a "Home Page" for a folder. If this points to a malicious file, it can execute scripts when the user views the folder. Defenders should monitor registry keys associated with Outlook folder Home Pages (`WebView` settings).

## Blind Spots & Tuning
- Users or corporate IT configuring custom internal web pages for Outlook folder landing views.
- Tune out known corporate URLs and restrict monitoring to file:// protocol additions or highly suspicious domains.
