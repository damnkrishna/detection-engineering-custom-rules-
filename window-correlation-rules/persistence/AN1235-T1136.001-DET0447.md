# AN1235 - Create Account: Local Account (T1136.001)

## Technique Breakdown
Adversaries may create local accounts to maintain access to victim systems. Local accounts bypass domain logging in many scenarios and can provide a fallback if primary backdoors are discovered. Detection relies on monitoring Security Event ID 4720 (A user account was created) or the execution of command-line tools like `net user /add`.

## Custom Sigma Rule
```yaml
title: 'AN1235 - Create Account: Local Account'
id: 'AN1235'
status: experimental
description: 'Detects the creation of a local user account via net.exe or Security Event 4720, indicating potential persistence.'
author: Krishna Gupta
logsource:
  product: windows
  service: security
detection:
  selection_event:
    EventID: 4720
  selection_cmd:
    EventID: 4688
    Image|endswith: '\net.exe'
    CommandLine|contains|all:
      - ' user '
      - ' /add'
  condition: selection_event or selection_cmd
fields:
  - EventID
  - TargetUserName
  - SubjectUserName
  - Image
  - CommandLine
level: high
tags:
  - attack.persistence
  - attack.t1136.001
  - analytic.an1235
```

## Blind Spots & Tuning
- IT staff legitimately creating local administrator or service accounts during provisioning.
- Tune out known administrative users creating accounts, or accounts created that conform to standard naming conventions.
