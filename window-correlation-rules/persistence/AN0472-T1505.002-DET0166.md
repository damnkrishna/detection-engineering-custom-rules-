# AN0472 - Server Software Component: Transport Agent (T1505.002)

## Technique Breakdown
Adversaries may install malicious Transport Agents in Microsoft Exchange Server to establish persistence, intercept emails, or execute code. Transport Agents are managed via PowerShell cmdlets (e.g., `Install-TransportAgent`). Monitoring process creation events for these cmdlets and tracking Exchange configuration files can detect unauthorized agents.

## Custom Sigma Rule
```yaml
title: 'AN0472 - Server Software Component: Transport Agent'
id: 'AN0472'
status: experimental
description: 'Detects the execution of PowerShell commands used to install or enable Exchange Transport Agents, which adversaries abuse for persistence and data theft.'
author: Krishna Gupta
logsource:
  product: windows
  category: process_creation
detection:
  selection:
    CommandLine|contains:
      - 'Install-TransportAgent'
      - 'Enable-TransportAgent'
  condition: selection
fields:
  - EventID
  - Image
  - CommandLine
  - ParentImage
level: critical
tags:
  - attack.persistence
  - attack.t1505.002
  - analytic.an0472
```

## Blind Spots & Tuning
- Legitimate Exchange Server administrators or third-party email security products (e.g. Anti-Spam filters) installing transport agents.
- Tune by whitelisting known administrative jump boxes, expected administrator accounts, and verified product installations.
