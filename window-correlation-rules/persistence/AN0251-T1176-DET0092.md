# AN0251 - Software Extensions (T1176)

## Technique Breakdown
Adversaries may abuse generic software extensions to execute malicious code or maintain persistence. Software extensions, outside of browsers or Office, can include plugins for various locally installed applications. Adversaries may use shell commands to silently install malicious extensions or drop payload files into extension directories. Detection relies on monitoring command-line executions containing extension installation flags.

## Custom Sigma Rule
```yaml
title: 'AN0251 - Generic Software Extensions'
id: 'AN0251'
status: experimental
description: 'Detects the execution of command-line tools attempting to install software extensions or plugins, which could be abused for persistence.'
author: Krishna Gupta
logsource:
  product: windows
  category: process_creation
detection:
  selection_images:
    Image|endswith:
      - '\cmd.exe'
      - '\powershell.exe'
  selection_cmd:
    CommandLine|contains: 'install-extension'
  condition: selection_images and selection_cmd
fields:
  - EventID
  - Image
  - CommandLine
  - ParentImage
level: medium
tags:
  - attack.persistence
  - attack.t1176
  - analytic.an0251
```

### OCSF Normalized Rule
```yaml
title: 'AN0251 - Generic Software Extensions (OCSF)'
id: 'AN0251'
status: experimental
description: 'Detects the execution of command-line tools attempting to install software extensions or plugins, which could be abused for persistence.'
author: Krishna Gupta
logsource:
  product: windows
  category: process_creation
detection:
  selection_signature:
    signature_name|contains:
      - 'Software Extensions'
      - 'DET0092'
  condition: selection_signature
fields:
  - event_id
  - signature_name
  - unmapped.parent_image
  - unmapped.parent_cmd_line
  - actor.user.name
  - unmapped.granted_access
level: medium
tags:
  - attack.persistence
  - attack.t1176
  - analytic.an0251
```

## Blind Spots & Tuning
- Developers installing legitimate extensions via CLI (e.g. VS Code `code --install-extension`) will match this rule.
- Tune by excluding trusted developer machines, expected parent processes, and known good extension IDs.
