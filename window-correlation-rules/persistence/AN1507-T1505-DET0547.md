# AN1507 - Server Software Component (T1505)

## Technique Breakdown
Adversaries may manipulate generic server software components to establish persistence. Instead of standard web shells or SQL procedures, they might replace DLLs loaded by IIS, proxy services, or custom application servers. Monitoring registry paths pointing to these service DLLs (`Parameters\ServiceDll`) and sudden changes to trusted server components can expose this activity.

## Custom Sigma Rule
```yaml
title: 'AN1507 - Generic Server Software Component'
id: 'AN1507'
status: experimental
description: 'Detects registry modifications to ServiceDll parameters, often abused to replace legitimate server software components with malicious DLLs.'
author: Krishna Gupta
logsource:
  product: windows
  category: registry_set
detection:
  selection_registry:
    TargetObject|contains|all:
      - '\System\CurrentControlSet\Services\'
      - '\Parameters\ServiceDll'
  selection_event:
    EventType: 'SetValue'
  filter_trusted:
    Image|endswith:
      - '\svchost.exe'
      - '\msiexec.exe'
      - '\TrustedInstaller.exe'
  condition: selection_registry and selection_event and not filter_trusted
fields:
  - EventID
  - TargetObject
  - Image
  - Details
level: high
tags:
  - attack.persistence
  - attack.t1505
  - analytic.an1507
```

### OCSF Normalized Rule
```yaml
title: 'AN1507 - Generic Server Software Component (OCSF)'
id: 'AN1507'
status: experimental
description: 'Detects registry modifications to ServiceDll parameters, often abused to replace legitimate server software components with malicious DLLs.'
author: Krishna Gupta
logsource:
  product: windows
  category: registry_set
detection:
  selection_signature:
    signature_name|contains:
      - 'Server Software Component'
      - 'DET0547'
  condition: selection_signature
fields:
  - event_id
  - signature_name
  - unmapped.parent_image
  - unmapped.api_operation
  - actor.user.name
  - unmapped.granted_access
level: high
tags:
  - attack.persistence
  - attack.t1505
  - analytic.an1507
```

## Blind Spots & Tuning
- Installation of new legitimate services or updates to existing services via software installers not captured in the `filter_trusted` list.
- Expand the filter list based on specific enterprise application deployment toolsets (e.g., specific agent updaters).
