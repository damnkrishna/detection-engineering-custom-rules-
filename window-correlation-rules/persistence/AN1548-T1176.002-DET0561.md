# AN1548 - Software Extensions: IDE Extensions (T1176.002)

## Technique Breakdown
Adversaries may install malicious IDE (Integrated Development Environment) extensions, such as those for Visual Studio Code. These extensions run with the privileges of the user and have extensive access to the local system and source code, making them excellent persistence and data exfiltration vectors. Detection involves monitoring `code.exe` (or similar IDE binaries) executing with parameters like `--install-extension`.

## Custom Sigma Rule
```yaml
title: 'AN1548 - Software Extensions: IDE Extensions'
id: 'AN1548'
status: experimental
description: 'Detects the execution of command-line tools to forcefully install IDE extensions, a technique potentially used for developer environment compromise.'
author: Krishna Gupta
logsource:
  product: windows
  category: process_creation
detection:
  selection_image:
    Image|endswith:
      - '\code.exe'
      - '\code-insiders.exe'
  selection_cmd:
    CommandLine|contains: '--install-extension'
  condition: selection_image and selection_cmd
fields:
  - EventID
  - Image
  - CommandLine
  - ParentImage
level: medium

  - attack.persistence

  - analytic.an1548
```

## Blind Spots & Tuning
- Developers normally installing extensions via the CLI instead of the GUI.
- Tuning is highly dependent on developer environments. Consider focusing alerts only on specific high-risk servers or restricting to anomalous parent processes (e.g., cmd.exe spawned by a word document attempting to install an extension).
