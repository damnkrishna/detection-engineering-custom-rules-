# AN0123 - Software Extensions: Browser Extensions (T1176.001)

## Technique Breakdown
Adversaries may install malicious browser extensions to establish persistence, steal credentials, or intercept web traffic. This involves modifications to browser extension directories (e.g., AppData\Local\Google\Chrome\User Data\Default\Extensions) or registry keys dictating force-installed extensions by enterprise policy. Defenders should monitor registry keys like `ExtensionInstallForcelist` and process executions involving browser binaries with extension installation flags.

## Custom Sigma Rule
```yaml
title: 'AN0123 - Software Extensions: Browser Extensions'
id: 'AN0123'
status: experimental
description: 'Detects suspicious registry modifications or file drops targeting browser extensions, indicative of persistence or credential theft.'
author: Krishna Gupta
logsource:
  product: windows
  category: registry_set
detection:
  selection_chrome:
    TargetObject|contains: '\Software\Policies\Google\Chrome\ExtensionInstallForcelist'
  selection_edge:
    TargetObject|contains: '\Software\Policies\Microsoft\Edge\ExtensionInstallForcelist'
  selection_event:
    EventType: 'SetValue'
  condition: (selection_chrome or selection_edge) and selection_event
fields:
  - EventID
  - TargetObject
  - Image
  - Details
level: high
tags:
  - attack.persistence
  - attack.t1176.001
  - analytic.an0123
```

## Blind Spots & Tuning
- Corporate IT deploying browser extensions via Group Policy will trigger false positives.
- Tune out known safe extensions using their explicit App IDs and trusted configuration processes (e.g., `gpupdate.exe`).
