# AN1108 - Server Software Component: Web Shell (T1505.003)

## Technique Breakdown
Adversaries may backdoor web servers with web shells to establish persistent access to systems. Web shells provide a web-based interface for remote command execution. Detection commonly involves monitoring the web server process (e.g., `w3wp.exe`, `nginx.exe`, `httpd.exe`) spawning anomalous child processes like `cmd.exe` or `powershell.exe`, or monitoring the creation of new `.aspx`, `.php`, or `.jsp` files within web directories.

## Custom Sigma Rule
```yaml
title: 'AN1108 - Server Software Component: Web Shell'
id: 'AN1108'
status: experimental
description: 'Detects web server processes spawning command shells, which is a strong indicator of web shell execution and persistence.'
author: Krishna Gupta
logsource:
  product: windows
  category: process_creation
detection:
  selection_parent:
    ParentImage|endswith:
      - '\w3wp.exe'
      - '\httpd.exe'
      - '\nginx.exe'
      - '\tomcat.exe'
      - '\php-cgi.exe'
  selection_child:
    Image|endswith:
      - '\cmd.exe'
      - '\powershell.exe'
      - '\pwsh.exe'
      - '\certutil.exe'
  condition: selection_parent and selection_child
fields:
  - EventID
  - ParentImage
  - Image
  - CommandLine
level: critical
tags:
  - attack.persistence
  - attack.privilege-escalation
  - attack.t1505.003
  - analytic.an1108
```

## Blind Spots & Tuning
- Web applications that legitimately spawn shells (e.g. to run backend scheduled tasks or local scripts).
- Tuning is required by whitelisting the specific combinations of web application paths and the exact command line strings they execute.
