# AN1436 - Office Application Startup: Office Template Macros (T1137.001)

## Technique Breakdown
Adversaries may use Office Template Macros (like `Normal.dotm`) to execute malicious code whenever an Office application starts. `Normal.dotm` is the global template for Microsoft Word; replacing or modifying it with a macro-enabled payload ensures the macro executes every time Word is launched. Detection involves monitoring unexpected file modifications or creations targeting `.dotm` files in the user's AppData Office template directories.

## Custom Sigma Rule
```yaml
title: 'AN1436 - Office Application Startup: Office Template Macros'
id: 'AN1436'
status: experimental
description: 'Detects the creation or modification of global Office templates (like Normal.dotm) by suspicious processes, indicating potential macro-based persistence.'
author: Krishna Gupta
logsource:
  product: windows
  category: file_event
detection:
  selection_file:
    TargetFilename|endswith:
      - '\Microsoft\Templates\Normal.dotm'
      - '\Microsoft\Excel\XLSTART\*.xlam'
  selection_event:
    EventType: 'CreateFile'
  filter_office:
    Image|endswith:
      - '\winword.exe'
      - '\excel.exe'
  condition: selection_file and selection_event and not filter_office
fields:
  - EventID
  - TargetFilename
  - Image
  - Details
level: high
tags:
  - attack.persistence
  - attack.t1137.001
  - analytic.an1436
```

### OCSF Normalized Rule
```yaml
title: 'AN1436 - Office Application Startup: Office Template Macros (OCSF)'
id: 'AN1436'

  product: windows
  category: file_event
detection:
  selection_signature:
    signature_name|contains:
      - 'Office Template Macros'
      - 'DET0519'
  condition: selection_signature
fields:
  - event_id
  - signature_name
  - unmapped.parent_image
  - unmapped.api_operation
  - actor.user.name
  - unmapped.granted_access
level: high
tags:
  - attack.persistence
  - attack.t1137.001
  - analytic.an1436
```

## Blind Spots & Tuning
- Users saving custom templates directly from Office applications (filtered out natively via `winword.exe` and `excel.exe`).
- IT Administrators deploying new enterprise templates via scripts or SCCM. Whitelist those deployment paths.
