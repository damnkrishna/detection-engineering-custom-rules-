### 1. Technique Breakdown: T1110.003 & T1021.002

* **Description**: Detects password spraying activity across the network targeting SMB ports, followed by a successful administrative share write (`C$`, `ADMIN$`) from the spraying host within 30 minutes.
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Zeek network connection/SMB authentication failure events.
  * Suricata signatures capturing NIDS authentication failures.
  * Sysmon Event ID 5145 (Share Object Access with write access type) which contains the remote source IP.
* **Coverage Check**:
  * HIDS (Sysmon Event ID 5145): YES. Mapped to host write actions with source IP context.
  * NIDS (Zeek + Suricata): YES. Excellent for tracking network auth sprays and share write transactions.

### 3. Blind Spots & Tuning (The "Problems")

* **Problem 1: Expired Service Account Password**
  * *Issue*: A service account with an expired password running on automated systems might generate dozens of failures before a user logs in and mounts an admin share.
  * *Fix*: Filter out service account user patterns or whitelisted administrative host IPs from triggering the spray stage.
* **Problem 2: Host Event Source IP Context (Sysmon Event ID 11 Exclusion)**
  * *Issue*: Sysmon Event ID 11 (File Create) logs file creation on the local filesystem, but does not carry the remote `source.ip` of the network client. If we correlated on `source.ip` using Event ID 11, the rule would fail to join.
  * *Fix*: We explicitly exclude Event ID 11 from the correlation stage and rely on Sysmon Event ID 5145 (Network Share Object Access), which audits the remote `source.ip` (SourceAddress) natively, allowing clean correlation.
* **Problem 3: Vulnerability Scanners**
  * *Issue*: Internal vulnerability scanners (e.g., Nessus, Qualys) perform active password sprays and check administrative shares as part of credentialed scans.
  * *Fix*: Whitelist designated scanner IP addresses from the Stage 0 source IP evaluation.
