### 1. Technique Breakdown: T1021.002 & T1053.005

* **Description**: Detects lateral movement via SMB share file write (copying execution payloads) followed by scheduled task execution on the target host within 30 minutes.
* **Author**: Krishna Gupta
* **Log Source Requirements**:
  * Suricata network alerts or Windows Event ID 5145 checking writes to administrative SMB shares (`ADMIN$`, `C$`).
  * Sysmon Event ID 1 (Process Create) checking execution of `schtasks.exe` or Event ID 11 (File Create) in `C:\Windows\System32\Tasks`.
* **Coverage Check**:
  * HIDS (Sysmon / Windows Event logs): YES. Logs task execution and creation.
  * NIDS (Suricata): YES. Excellent for tracking initial payload transfer over SMB shares.

### 3. Blind Spots & Tuning (The "Problems")

* **Problem 1: Legitimate Software Installations**
  * *Issue*: Automated systems or application installers pushing software via administrative shares and scheduling installation tasks can trigger the alert.
  * *Fix*: Ignore scheduled task triggers initiated by signed deployment binaries or domain management software service accounts.
* **Problem 2: Domain Controller Task Synchronization**
  * *Issue*: Normal Group Policy updates copy GPO files over SMB shares and automatically update scheduled tasks on active systems.
  * *Fix*: Whitelist DC system source IPs or service accounts from the initial Stage 0 triggers.
