### **1. Technique Breakdown: T1052**

* **What it is:** **Exfiltration Over Physical Medium**. Adversaries copy stolen data directly to removable media devices (such as USB flash drives, external hard drives, or writeable CDs/DVDs) to bypass network filters and perimeter controls. Detections monitor for files being written or created on removable storage drive letters (e.g., E:\, F:\) where the files are archives (zip, rar, 7z), suggesting data staging.
* **Log Source Requirements:** Endpoint logs capturing file creation events (Sysmon Event ID 11 / Windows Security Event ID 4663) containing file paths and extension details.
* **Coverage Check:**
* **HIDS (Sysmon + Wazuh): YES.** Sysmon Event ID 11 logs file creation paths (including drive letters) and process identifiers. Wazuh aggregates these logs.
* **NIDS (Suricata + Zeek): NO.** Physical media exfiltration is entirely local and offline; no network telemetry is generated.

### **2. Custom Sigma Rule**

This rule utilizes **Sysmon Event ID 11 (File Create)** to detect the creation of archive files (e.g., `.zip`, `.rar`, `.7z`) onto typical removable media drive letters.

```yaml
title: Archive File Creation on Removable Media (AN0342)
id: 4164f71c-5b17-43cf-a58f-bd17cf7cc521
status: experimental
description: Detects the creation or writing of compressed archive files (such as .zip, .rar, .7z) onto removable storage drive paths (e.g. D:, E:, F:, G:, H:\), which may indicate staging data for physical exfiltration.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: file_event
    product: windows
    # Relies on Sysmon Event ID 11 collected via Wazuh
detection:
    selection_paths:
        TargetFilename|startswith:
            - 'D:\'
            - 'E:\'
            - 'F:\'
            - 'G:\'
            - 'H:\'
            - 'I:\'
            - 'J:\'
    selection_archives:
        TargetFilename|endswith:
            - '.zip'
            - '.rar'
            - '.7z'
            - '.tar'
            - '.cab'
            - '.tgz'
            - '.iso'
    condition: selection_paths and selection_archives
falsepositives:
    - Legitimate users saving archives or backing up data to USB flash drives or external drives.
level: medium
tags:
    - attack.exfiltration
    - attack.t1052
    - analytics.an0342
    - detection.det0123
```

### **3. Blind Spots & Tuning (The "Problems")**

* **Problem 1: Harddrive/Network Volume Drive Letter Overlaps**
* *The Issue:* Large workstations may contain multiple internal hard disk partitions (such as a second drive `D:\` or `E:\` used for standard applications) or mapped network drives (`G:\`), which will trigger false alerts under simple drive-letter checks.
* *The Fix:* In Sysmon configuration or SIEM parsers, filter out known static internal partitions and network shares, or query Windows Event ID 4663 `AccessMask` attributes to verify device type (`RemovableMedia` flag).


* **Problem 2: Copying raw uncompressed files**
* *The Issue:* Attackers can copy raw documents (e.g. `.pdf`, `.docx`) directly to the USB drive without compressing them first, bypassing the archive file extension check.
* *The Fix:* Implement file copy auditing (Windows Security Event ID 4663) targeting high-risk folders (such as `C:\Users\...\Documents`) and monitor for bulk copy operations to external drives.


* **Problem 3: Standard User USB backups**
* *The Issue:* Users routinely back up files to USB drives for offline work, creating significant noise.
* *The Fix:* Implement Data Loss Prevention (DLP) endpoint agents to block or alert on unauthorized USB storage attachments, and limit alerting to sensitive directories (such as proprietary source code or finance subfolders).
