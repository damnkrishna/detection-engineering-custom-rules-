### 1. Technique Breakdown: T1052

* What it is: Exfiltration Over Physical Medium. Adversaries copy stolen data directly to removable media devices (such as USB flash drives, external hard drives, or writeable CDs/DVDs) to bypass network filters and perimeter controls. Detections monitor for files being written or created on removable storage drive letters (e.g., E:\, F:\) or command-line commands copying files to these drives.
* Log Source Requirements: Endpoint logs capturing file creation events and process creation events.
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 11 (File Event) logs archive file creation paths (including drive letters) and Sysmon Event ID 1 (Process Creation) logs CLI copy commands targeting removable storage.
* NIDS (Suricata + Zeek): NO. Physical media exfiltration is entirely local and offline.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

The detection logic is split into monitoring archive files created on removable media, and command-line copy utilities targeting removable drive letters.

Rule 1 of 2: Archive File Creation on Removable Media (File Event)
```yaml
title: Archive File Creation on Removable Media (AN0342)
id: 4164f71c-5b17-43cf-a58f-bd17cf7cc521
status: experimental
description: Detects the creation or writing of compressed archive files (such as .zip, .rar, .7z) onto removable storage drive paths (e.g. D:, E:, F:, G:, H:\), which may indicate staging data for physical exfiltration.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: file_event
    product: windows
detection:
    selection_paths:
        TargetFilename|startswith:
            - 'D:\'
            - 'E:\'
            - 'F:\'
            - 'G:\'
            - 'H:\'
            - 'I:\'
            - 'J:\'
    selection_archives:
        TargetFilename|endswith:
            - '.zip'
            - '.rar'
            - '.7z'
            - '.tar'
            - '.cab'
            - '.tgz'
            - '.iso'
    condition: selection_paths and selection_archives
fields:
    - Image
    - TargetFilename
    - User
    - LogonId
falsepositives:
    - Legitimate users saving archives or backing up data to USB flash drives or external drives.
level: medium
tags:
    - attack.exfiltration
    - attack.t1052
    - analytic.an0342
    - detection.det0123
```

Rule 2 of 2: CLI Copy to Removable Drive (Process Creation)
```yaml
title: CLI Copy to Removable Drive (AN0342-B)
id: c7e2b1b3-4f9c-4b8a-8742-b6cf716ba388
status: experimental
description: Detects command-line utilities copying files or folders to typical removable storage drive letters (D:, E:, F:, etc.).
author: Krishna Gupta
date: 2026-06-17
logsource:
    category: process_creation
    product: windows
detection:
    selection_binaries:
        - Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\robocopy.exe'
            - '\xcopy.exe'
        - OriginalFileName:
            - 'cmd.exe'
            - 'PowerShell.EXE'
            - 'pwsh.dll'
            - 'robocopy.exe'
            - 'xcopy.exe'
    selection_args:
        CommandLine|contains:
            - ' D:\'
            - ' E:\'
            - ' F:\'
            - ' G:\'
            - ' H:\'
            - ' I:\'
    condition: selection_binaries and selection_args
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Users or administrators performing local manual file backups.
level: medium
tags:
    - attack.exfiltration
    - attack.t1052
    - analytic.an0342
    - detection.det0123
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Legitimate Installer and Backup Noise
  * The Issue: Backup utilities or system installers frequently write archives or stage folders, generating high-volume false positives.
  * The Fix: Define deployment exclusions for installer parents (such as msiexec.exe or setup.exe) and restrict monitoring to user-writable directories.

* Problem 2: Evasive Staging Paths
  * The Issue: Adversaries may write staged files to unusual directories not covered by static path monitors.
  * The Fix: Monitor global file system writes for compressed extensions (.zip, .7z) originating from shell or scripting host parents.

* Problem 3: In-Memory Collection Bypasses
  * The Issue: Malware executing fully in-memory may stream or exfiltrate data without writing staging files to disk, bypassing file event monitoring.
  * The Fix: Complement directory monitoring with host network egress logging and active memory inspection checks.
