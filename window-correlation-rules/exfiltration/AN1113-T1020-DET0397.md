### 1. Technique Breakdown: T1020

* What it is: Automated Exfiltration. Adversaries automate the search, collection, packaging, and transmission of sensitive files using scheduled scripts or custom implants. Once deployed, these scripts execute at set intervals (using scheduled tasks or system daemons), compress targeted file formats (using LOLBins like `tar.exe` or `makecab.exe`), and transmit them to external infrastructure. Detecting automated exfiltration relies on flagging scripting utilities or scheduled tasks spawning archiving tools.
* Log Source Requirements: Endpoint logs capturing process creation and parent-child execution context (Sysmon Event ID 1 / Windows Security Event ID 4688).
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 captures parent process paths, target binaries, and command-line parameters. Wazuh aggregates these activities to detect command-line archiving behavior.
* NIDS (Suricata + Zeek): YES (Partial). Network tools can identify periodic beaconing traffic patterns to external destinations, but host-level context is needed to identify data collection and archiving operations.

### 2. Custom Sigma Rule

This rule utilizes Sysmon Event ID 1 (Process Creation) to detect command-line archiving tools (`7z.exe`, `rar.exe`, `tar.exe`, `makecab.exe`) being spawned by task schedulers or scripting environments.

```yaml
title: Automated Archiving and Staging via CLI (AN1113)
id: 74bde7cd-79fb-44ae-bd48-51829210d551
status: experimental
description: Detects command-line archiving utilities being spawned by command shells or task schedulers, which may indicate automated data harvesting and staging for exfiltration.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_parent:
        ParentImage|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\cmd.exe'
            - '\taskeng.exe'
            - '\svchost.exe'
    selection_archive:
        - Image|endswith:
            - '\7z.exe'
            - '\7za.exe'
            - '\rar.exe'
            - '\zip.exe'
            - '\tar.exe'
            - '\makecab.exe'
        - OriginalFileName:
            - '7z.exe'
            - '7za.exe'
            - 'rar.exe'
            - 'zip.exe'
            - 'tar.exe'
            - 'makecab.exe'
    condition: selection_parent and selection_archive
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate administrative backup scripts, database backups, or software build tools performing automated file archiving.
level: medium
tags:
    - attack.exfiltration
    - attack.t1020
    - analytic.an1113
    - detection.det0397
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Command Line Obfuscation
  * The Issue: Adversaries can obfuscate command-line arguments using environment variables, caret escapes (^), or base64 encoding, evading simple string matching.
  * The Fix: Implement PowerShell Script Block Logging and utilize regex or script-decoding scripts in the SIEM to check arguments.

* Problem 2: Administrative Activity Noise
  * The Issue: IT administrators legitimately run command-line tools or installers that trigger these rules during system maintenance.
  * The Fix: Establish a baseline of legitimate admin tools, whitelisting specific administrative account names or management servers.

* Problem 3: Masquerading via Renamed Binaries
  * The Issue: Attackers rename native Windows utilities (such as net.exe or cmd.exe) to custom filenames to bypass path-based filters.
  * The Fix: Incorporate Masquerade-resistant criteria, matching on OriginalFileName rather than the static Image path in process creation logs.
