### 1. Technique Breakdown: T1011

* What it is: Exfiltration Over Other Network Medium. Adversaries bypass corporate firewall and proxy monitors by exfiltrating data through non-primary network interfaces connected directly to the internet (such as local WiFi hotspots, mobile cellular adapters, or Bluetooth links). Detections focus on identifying command-line configurations of wireless or cellular adapters by execution shells, which indicates out-of-band network preparations.
* Log Source Requirements: Endpoint logs capturing process creation and command line parameters (Sysmon Event ID 1 / Windows Security Event ID 4688).
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 captures execution of `netsh.exe` or PowerShell command lines querying or configuring network interfaces. Wazuh forwards and processes these activities.
* NIDS (Suricata + Zeek): NO. Out-of-band network traffic routed through cellular modems or private hotspots does not pass through the enterprise gateway, making network-level boundary inspection impossible.

### 2. Custom Sigma Rule

This rule utilizes Sysmon Event ID 1 (Process Creation) to detect the execution of `netsh.exe` configuring wireless adapters (WLAN) or PowerShell network adapter cmdlets.

```yaml
title: WiFi or Secondary Network Interface Configuration via CLI (AN0212)
id: fec142f1-c3f4-41db-81ad-e335625fd6d6
status: experimental
description: Detects command-line execution of netsh.exe or PowerShell network cmdlets being used to configure, enable, or connect to wireless (WLAN) or secondary network interfaces, which can be used to bypass corporate network boundaries for exfiltration.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_netsh:
        - Image|endswith: '\netsh.exe'
        - OriginalFileName: 'netsh.exe'
    selection_netsh_args:
        CommandLine|contains:
            - ' wlan '
            - ' wlan'
            - 'wlan '
    selection_powershell:
        - Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
        - OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.dll'
    selection_powershell_cmdlets:
        CommandLine|contains:
            - 'NetAdapter'
            - 'NetRoute'
        CommandLine|contains:
            - 'Set-'
            - 'Enable-'
            - 'New-'
    condition: (selection_netsh and selection_netsh_args) or (selection_powershell and selection_powershell_cmdlets)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - IT administrators or users troubleshooting mobile workstation wireless connections or configuring VPN routing.
level: medium
tags:
    - attack.exfiltration
    - attack.t1011
    - analytic.an0212
    - detection.det0077
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Command Line Obfuscation
  * The Issue: Adversaries can obfuscate command-line arguments using environment variables, caret escapes (^), or base64 encoding, evading simple string matching.
  * The Fix: Implement PowerShell Script Block Logging and utilize regex or script-decoding scripts in the SIEM to check arguments.

* Problem 2: Administrative Activity Noise
  * The Issue: IT administrators legitimately run command-line tools or installers that trigger these rules during system maintenance.
  * The Fix: Establish a baseline of legitimate admin tools, whitelisting specific administrative account names or management servers.

* Problem 3: Masquerading via Renamed Binaries
  * The Issue: Attackers rename native Windows utilities (such as net.exe or cmd.exe) to custom filenames to bypass path-based filters.
  * The Fix: Incorporate Masquerade-resistant criteria, matching on OriginalFileName rather than the static Image path in process creation logs.
