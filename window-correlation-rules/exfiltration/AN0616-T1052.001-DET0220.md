### 1. Technique Breakdown: T1052.001

* What it is: Exfiltration Over Physical Medium: Exfiltration over USB. Adversaries exfiltrate data by writing files directly to USB mass storage devices. To accelerate data collection and minimize interactive steps, they often execute automated command-line copy tools (like `robocopy.exe`, `xcopy.exe`) or custom scripts to scan and copy targeted files directly to plugged-in USB drives. Detections monitor file writes onto removable drive paths by these specific copy utilities.
* Log Source Requirements: Endpoint file creation logs (Sysmon Event ID 11 / Windows Security Event ID 4663) capturing file paths, writing processes, and usernames.
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 11 logs file creation paths (e.g. `E:\Staged\sensitive.zip`) and the writing process (e.g. `robocopy.exe`). Wazuh parses these logs to trigger alerts.
* NIDS (Suricata + Zeek): NO. USB storage exfiltration occurs entirely locally and offline, generating no network traffic.

### 2. Custom Sigma Rule

This rule utilizes Sysmon Event ID 11 (File Create) to detect files being written to removable media drive letters by standard command-line copy tools (`robocopy.exe`, `xcopy.exe`, `cmd.exe`, or `powershell.exe`).

```yaml
title: File Copy to USB Storage via CLI (AN0616)
id: 44e824ce-8c28-4fb8-ba3b-b05838ce6d7d
status: experimental
description: Detects command line execution of file copy utilities (xcopy, robocopy) or scripting engines targeting USB/removable storage drive letters, which may indicate automated data harvesting to USB media.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: file_event
    product: windows
    # Relies on Sysmon Event ID 11
detection:
    selection_process:
        Image|endswith:
            - '\xcopy.exe'
            - '\robocopy.exe'
            - '\powershell.exe'
            - '\cmd.exe'
    selection_paths:
        TargetFilename|startswith:
            - 'D:\'
            - 'E:\'
            - 'F:\'
            - 'G:\'
            - 'H:\'
            - 'I:\'
            - 'J:\'
    condition: selection_process and selection_paths
fields:
    - Image
    - TargetFilename
    - User
    - LogonId
falsepositives:
    - Legitimate IT administration or users manually backing up files using command line copy tools to external media.
level: medium
tags:
    - attack.exfiltration
    - attack.t1052.001
    - analytic.an0616
    - detection.det0220
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Legitimate Installer and Backup Noise
  * The Issue: Backup utilities or system installers frequently write archives or stage folders, generating high-volume false positives.
  * The Fix: Define deployment exclusions for installer parents (such as msiexec.exe or setup.exe) and restrict monitoring to user-writable directories.

* Problem 2: Evasive Staging Paths
  * The Issue: Adversaries may write staged files to unusual directories not covered by static path monitors.
  * The Fix: Monitor global file system writes for compressed extensions (.zip, .7z) originating from shell or scripting host parents.

* Problem 3: In-Memory Collection Bypasses
  * The Issue: Malware executing fully in-memory may stream or exfiltrate data without writing staging files to disk, bypassing file event monitoring.
  * The Fix: Complement directory monitoring with host network egress logging and active memory inspection checks.
