title: Potential MFA Fatigue Attack (AN0451)
id: 5a2c4e6b-1d3f-4a8c-9b7e-0d1f2a3b4c5d
status: experimental
description: Detects a high volume of denied, ignored, or timeout MFA push notifications targeting a single user within a short timeframe, indicating an MFA Fatigue attack (T1621).
author: Krishna Gupta
date: 2026-06-05
logsource:
    category: authentication
    # Note: Requires integration with Azure AD, Okta, Duo, or VPN logs via Wazuh.
detection:
    selection_mfa_events:
        # These fields will need to be mapped to your specific IdP's schema
        action:
            - 'mfa_denied'
            - 'mfa_ignored'
            - 'mfa_timeout'
            - 'push_sent'
    condition: selection_mfa_events | count() >= 5
    timeframe: 10m
falsepositives:
    - Users experiencing genuine connectivity issues with their authenticator app.
    - A user accidentally triggering multiple logins due to a stalled application (like an email client stuck in an auth loop).
level: high
tags:
    - attack.credential_access
    - attack.t1621
    - analytics.an0451
    - detection.det0160
