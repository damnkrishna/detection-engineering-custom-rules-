### 1. Technique Breakdown: T1546.008

* What it is: Event Triggered Execution: Accessibility Features. Windows accessibility tools (e.g., Sticky Keys sethc.exe, Utility Manager utilman.exe, On-Screen Keyboard osk.exe, Magnifier magnify.exe) can be launched using key combinations before a user logs in. Adversaries exploit this behavior by replacing these binary files with a command prompt (cmd.exe) or modifying the Image File Execution Options (IFEO) registry keys to assign a "Debugger" string pointing to a shell.
* Log Source Requirements: Endpoint logs capturing process creation events and registry modifications.
* Coverage Check:
  - HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 captures accessibility binaries spawning command interpreters. Sysmon Event ID 13 (Registry Value Set) tracks direct registry overrides.
  - NIDS (Suricata + Zeek): NO. Host-local logon screen interactions.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 13 (registry_set)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

The detection logic is split into process creation monitoring of accessibility tools spawning shells or CLI tools configuring IFEO keys, and direct registry modifications setting debuggers.

Rule 1 of 2: Accessibility Features Abuse Detection (Process Creation)
```yaml
title: Accessibility Features Abuse Detection (AN0094)
id: 6f7f8d19-1145-45ad-9984-63649b4f8ace
status: experimental
description: Detects command-line execution of registry commands setting debugger options for accessibility binaries (like sethc.exe or utilman.exe), or detects accessibility applications launching shell interpreters.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
detection:
    selection_parent:
        ParentImage|endswith:
            - '\sethc.exe'
            - '\utilman.exe'
            - '\osk.exe'
            - '\magnify.exe'
            - '\narrator.exe'
            - '\displayswitch.exe'
            - '\AtBroker.exe'
        Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
    selection_ifeo:
        CommandLine|contains:
            - 'Image File Execution Options'
        CommandLine|contains:
            - 'debugger'
        CommandLine|contains:
            - 'sethc.exe'
            - 'utilman.exe'
            - 'osk.exe'
            - 'magnify.exe'
            - 'narrator.exe'
            - 'displayswitch.exe'
            - 'AtBroker.exe'
    condition: selection_parent or selection_ifeo
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Highly unlikely. Shell execution by accessibility features is not normal.
level: critical
tags:
    - attack.persistence
    - attack.privilege-escalation
    - attack.t1546.008
    - analytic.an0094
    - detection.det0042
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Command Line Obfuscation
  - The Issue: Adversaries can obfuscate command-line arguments using environment variables, caret escapes, or base64 encoding.
  - The Fix: Implement PowerShell Script Block Logging.

* Problem 2: Administrative Activity Noise
  - The Issue: IT administrators troubleshooting system issues.
  - The Fix: Restrict to non-standard environments.

* Problem 3: Masquerading via Renamed Binaries
  - The Issue: Attackers rename copy or shell binaries to custom filenames.
  - The Fix: Match on OriginalFileName in process creation logs.
