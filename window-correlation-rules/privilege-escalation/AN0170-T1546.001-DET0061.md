### **1. Technique Breakdown: T1546.001**

* **What it is:** **Event Triggered Execution: Change Default File Association**. When a user double-clicks or opens a file, the Windows operating system executes the default application associated with that file extension (e.g., Notepad for `.txt` files). Adversaries modify these default associations (stored in registry hives under `HKLM\SOFTWARE\Classes` or `HKCU\Software\Classes`) using utilities like `assoc.exe` or `ftype.exe`, or registry modifications. This causes a malicious binary to run whenever a specific, commonly-opened file type is loaded.
* **Log Source Requirements:** Endpoint logs capturing process creation and command line arguments (Sysmon Event ID 1 / Windows Security Event ID 4688).
* **Coverage Check:**
* **HIDS (Sysmon + Wazuh): YES.** Sysmon Event ID 1 logs process execution of `assoc.exe`, `ftype.exe`, and registry editing commands. Sysmon Event ID 13 (Registry Value Set) also records specific value modifications.
* **NIDS (Suricata + Zeek): NO.** Changing default file associations is a local configuration task and produces no network-level indicators.

### **2. Custom Sigma Rule**

This rule utilizes **Sysmon Event ID 1 (Process Creation)** to detect the execution of `assoc.exe` or `ftype.exe` command-line tools, or registry modifications targeting default application handlers.

```yaml
title: Change Default File Association via CLI (AN0170)
id: 13284360-c20f-4a2b-8220-0967f42fbd90
status: experimental
description: Detects command-line execution of assoc.exe or ftype.exe, or reg.exe modifications to system file association keys, which can be abused for privilege escalation and persistence.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1 collected via Wazuh
detection:
    selection_tools:
        - Image|endswith:
            - '\assoc.exe'
            - '\ftype.exe'
        - OriginalFileName:
            - 'assoc.exe'
            - 'ftype.exe'
    selection_reg:
        - Image|endswith:
            - '\reg.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
        - OriginalFileName:
            - 'reg.exe'
            - 'PowerShell.EXE'
            - 'pwsh.dll'
    selection_reg_args:
        CommandLine|contains:
            - '\Software\Classes\'
            - 'HKCR\'
        CommandLine|contains:
            - '\shell\open\command'
        CommandLine|contains:
            - 'reg'
            - 'add'
            - 'Set-ItemProperty'
            - 'New-ItemProperty'
    condition: selection_tools or (selection_reg and selection_reg_args)
falsepositives:
    - Legitimate application installers altering default handlers during setup (e.g., PDF readers, web browsers, text editors).
level: medium
tags:
    - attack.persistence
    - attack.privilege_escalation
    - attack.t1546.001
    - analytics.an0170
    - detection.det0061
```

### **3. Blind Spots & Tuning (The "Problems")**

* **Problem 1: Direct Registry API modifications**
* *The Issue:* Attackers can bypass `assoc.exe`/`ftype.exe` or CLI registry commands by writing code that modifies registry hives directly using native Windows APIs.
* *The Fix:* Enable registry auditing (Event ID 4657) and monitor Sysmon Event ID 13 (Registry Value Set) for changes inside `HKLM\SOFTWARE\Classes` or `HKCU\Software\Classes` where the value path ends in `\shell\open\command`.


* **Problem 2: Obfuscation of CLI commands**
* *The Issue:* Attackers can obfuscate command lines (e.g., by executing `reg` command via PowerShell with encoded command or using environment variables like `%COMSPEC%`) to bypass simple command line matches.
* *The Fix:* Implement PowerShell script block logging (Event ID 4104) and normalize CLI strings (such as resolving base64 encoded payloads) before parsing.


* **Problem 3: Installer noise**
* *The Issue:* Legitimate applications (like Google Chrome, Adobe Acrobat, VLC media player) routinely change file associations during installation, causing false positives.
* *The Fix:* Exclude processes signed by reputable authorities executing from standard program directories (like `C:\Program Files\`), or restrict alerting to changes involving highly abused extensions (like `.txt`, `.js`, `.vbs`, `.pdf`).
