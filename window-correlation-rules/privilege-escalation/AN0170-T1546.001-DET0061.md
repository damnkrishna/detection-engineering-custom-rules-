### 1. Technique Breakdown: T1546.001

* What it is: Event Triggered Execution: Change Default File Association. When a user double-clicks or opens a file, the Windows operating system executes the default application associated with that file extension (e.g., Notepad for .txt files). Adversaries modify these default associations (stored under HKLM\SOFTWARE\Classes or HKCU\Software\Classes) using utilities like assoc.exe or ftype.exe. This causes a malicious binary to run whenever a specific, commonly-opened file type is loaded.
* Log Source Requirements: Endpoint logs capturing process creation events and registry modifications.
* Coverage Check:
  - HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 logs process execution of assoc.exe/ftype.exe and registry commands. Sysmon Event ID 13 captures direct registry writes.
  - NIDS (Suricata + Zeek): NO. Local configuration change.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 13 (registry_set)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

The detection logic is split into process creation monitoring of file association utilities and registry command-line arguments, and direct registry modification monitoring of file association keys.

Rule 1 of 2: Change Default File Association via CLI (Process Creation)
```yaml
title: Change Default File Association via CLI (AN0170)
id: 13284360-c20f-4a2b-8220-0967f42fbd90
status: experimental
description: Detects command-line execution of assoc.exe or ftype.exe, or reg.exe modifications to system file association keys, which can be abused for privilege escalation and persistence.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
detection:
    selection_tools:
        - Image|endswith:
            - '\assoc.exe'
            - '\ftype.exe'
        - OriginalFileName:
            - 'assoc.exe'
            - 'ftype.exe'
    selection_reg:
        - Image|endswith:
            - '\reg.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
        - OriginalFileName:
            - 'reg.exe'
            - 'PowerShell.EXE'
            - 'pwsh.dll'
    selection_reg_args:
        CommandLine|contains:
            - '\Software\Classes\'
            - 'HKCR\'
        CommandLine|contains:
            - '\shell\open\command'
        CommandLine|contains:
            - 'reg'
            - 'add'
            - 'Set-ItemProperty'
            - 'New-ItemProperty'
    condition: selection_tools or (selection_reg and selection_reg_args)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate application installers altering default handlers during setup.
level: medium
tags:
    - attack.persistence
    - attack.privilege-escalation
    - attack.t1546.001
    - analytic.an0170
    - detection.det0061
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Command Line Obfuscation
  - The Issue: Adversaries can obfuscate command-line arguments using environment variables, caret escapes, or base64 encoding.
  - The Fix: Implement PowerShell Script Block Logging.

* Problem 2: Administrative Activity Noise
  - The Issue: IT administrators installing tools that register document formats.
  - The Fix: Establish a baseline of approved applications.

* Problem 3: Masquerading via Renamed Binaries
  - The Issue: Attackers rename association tools to bypass path-based filters.
  - The Fix: Match on OriginalFileName in process creation logs.
