### 1. Technique Breakdown: T1078.002

* What it is: Valid Accounts: Domain Accounts. Adversaries compromise domain accounts (specifically Domain Administrators) to move laterally across an Active Directory environment, execute remote commands, and access sensitive resources. Under standard security best practices, Domain Administrator accounts should only log onto Domain Controllers or secure administrative jump boxes. A Domain Admin logging onto standard workstations or member servers suggests lateral movement.
* Log Source Requirements: Windows Security Event Log capturing authentication events, and network connection logs tracking access to authentication services.
* Coverage Check:
  - HIDS (Sysmon + Wazuh): YES. Windows Security Event ID 4624 tracks domain account logon attempts on endpoints. Sysmon Event ID 3 tracks network connection activity.
  - NIDS (Suricata + Zeek): YES (Partial). Network monitoring can capture Kerberos ticket requests or SMB handshakes.
* Log Sources Covered:
  - Security Event ID 4624 (security)
  - Sysmon Event ID 3 (network_connection)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

The detection logic is split into Security logons for Domain Admins on workstations, and network connections made on authentication ports.

Rule 1 of 2: Domain Administrator Logon on Workstation (Security Log)
```yaml
title: Domain Administrator Logon on Workstation (AN0590)
id: 447dcbae-8166-4d6e-9980-8b9914df56b6
status: experimental
description: Detects successful remote network or RDP logons by domain administrator accounts onto standard workstation or member server endpoints, which may indicate lateral movement.
author: Krishna Gupta
date: 2026-06-07
logsource:
    product: windows
    service: security
detection:
    selection_event:
        EventID: 4624
    selection_logon_type:
        LogonType:
            - 3 # Network
            - 10 # Remote Interactive
    selection_domain_admin:
        TargetUserName|contains:
            - 'da_'
            - 'domainadmin'
            - 'domadmin'
    selection_domain:
        TargetDomainName|contains:
            - 'NT AUTHORITY'
            - 'NT Service'
            - 'Window Manager'
    condition: selection_event and selection_logon_type and selection_domain_admin and not selection_domain
fields:
    - EventID
    - LogonType
    - TargetDomainName
    - TargetUserName
falsepositives:
    - Authorized troubleshooting by domain administrators directly on user workstations.
level: high
tags:
    - attack.defense-evasion
    - attack.persistence
    - attack.privilege-escalation
    - attack.t1078.002
    - analytic.an0590
    - detection.det0210
```

Rule 2 of 2: Domain Administrator Network Connection (Network Connection)
```yaml
title: Domain Administrator Network Connection (AN0590-B)
id: 8a33736b-c1ff-4a83-b131-c104fa67c1a0
status: experimental
description: Detects network connections made over Active Directory authentication ports (Kerberos, LDAP, SMB) from standard workstations, indicating domain administrator lateral movement or authentication traffic.
author: Krishna Gupta
date: 2026-06-17
logsource:
    category: network_connection
    product: windows
detection:
    selection_ports:
        DestinationPort:
            - 88   # Kerberos
            - 389  # LDAP
            - 445  # SMB
            - 636  # LDAPS
    selection_image_filter:
        - Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\wscript.exe'
            - '\cscript.exe'
    condition: selection_ports and selection_image_filter
fields:
    - Image
    - SourceIp
    - DestinationIp
    - DestinationPort
    - User
falsepositives:
    - IT admin staff running scripts connecting directly to Domain Controllers.
level: medium
tags:
    - attack.defense-evasion
    - attack.persistence
    - attack.privilege-escalation
    - attack.t1078.002
    - analytic.an0590
    - detection.det0210
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Administrative Action False Positives
  - The Issue: IT personnel performing legitimate maintenance operations.
  - The Fix: Audit and baseline corporate administration accounts, whitelisting specific administrative subnets.

* Problem 2: Command and Execution Obfuscation
  - The Issue: Attackers employ encoding or obfuscated scripting engines.
  - The Fix: Enable deep logging (such as Script Block Logging) and utilize central decoding filters.

* Problem 3: Log Deletion and Modification
  - The Issue: Adversaries can clear security logs to blind defenders.
  - The Fix: Forward all endpoint logs immediately to a centralized write-once SIEM.
