### 1. Technique Breakdown: T1548.002

* What it is: Bypass User Account Control. Windows User Account Control (UAC) allows a program to run with administrative privileges if approved by the user. Adversaries bypass this mechanism by exploiting auto-elevating programs that run with High Integrity without prompting. They do this by modifying registry entries (e.g., isolatedCommand, DelegateExecute, or shell\open\command keys) under the current user hive (HKCU), causing the auto-elevating binary to load a custom command instead of the default.
* Log Source Requirements: Endpoint logs capturing process creation events and registry modifications.
* Coverage Check:
  - HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 captures command line arguments for tools modifying registry keys. Sysmon Event ID 13 (Registry Value Set) tracks direct registry modifications.
  - NIDS (Suricata + Zeek): NO. Registry modifications are internal Windows operating system events.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 13 (registry_set)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

The detection logic is split into process creation monitoring of registry command tools, and direct registry modification monitoring of UAC bypass override paths.

Rule 1 of 2: Registry Modification CLI for UAC Bypass (Process Creation)
```yaml
title: Registry Modification CLI for UAC Bypass (AN1094)
id: f70aef68-a67d-46d0-97bb-8d2d5a5a632a
status: experimental
description: Detects command-line registry modifications targeting UAC auto-elevation registry paths such as isolatedCommand, DelegateExecute, or shell\open\command keys under the user hive.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
detection:
    selection_cmd:
        CommandLine|contains:
            - '\shell\open\command'
            - '\isolatedCommand'
            - '\DelegateExecute'
        CommandLine|contains:
            - 'reg'
            - 'add'
            - 'Set-ItemProperty'
            - 'New-ItemProperty'
            - 'setx'
    condition: selection_cmd
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate installers or administration scripts executing setup tasks.
level: high
tags:
    - attack.privilege-escalation
    - attack.defense-evasion
    - attack.t1548.002
    - analytic.an1094
    - detection.det0388
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Command Line Obfuscation
  - The Issue: Adversaries can obfuscate command-line arguments using environment variables.
  - The Fix: Implement PowerShell Script Block Logging.

* Problem 2: Administrative Activity Noise
  - The Issue: IT administrators run installers that register compatibility settings.
  - The Fix: Establish a baseline of legitimate admin tools and whitelist approved processes.

* Problem 3: Masquerading via Renamed Binaries
  - The Issue: Attackers rename registry modifications utilities to bypass path filters.
  - The Fix: Incorporate Masquerade-resistant criteria, matching on OriginalFileName.
