### **1. Technique Breakdown: T1055.012**

* **What it is:** **Process Injection: Process Hollowing**. Adversaries spawn a legitimate system process (e.g., `svchost.exe`, `explorer.exe`) in a suspended state using the `CREATE_SUSPENDED` flag. They then unmap (hollow out) the original code from memory using `NtUnmapViewOfSection`. Next, they allocate new memory, write their malicious payload into the hollowed process space, modify the thread context to point to the payload, and resume the thread. The malicious code now runs disguised as a trusted system binary.
* **Log Source Requirements:** Sysmon Event ID 1 (Process Creation), Sysmon Event ID 10 (ProcessAccess), EDR telemetry (API hooking for `NtUnmapViewOfSection`).
* **Coverage Check:**
    * **HIDS (Sysmon + Wazuh): YES (Partial).** Sysmon tracks the creation of the suspended process and the subsequent access, but cannot natively log the `NtUnmapViewOfSection` API call.
    * **NIDS (Suricata + Zeek): NO.** Completely in-memory local execution.

### **2. Custom Sigma Rule**

This rule utilizes **Sysmon Event ID 10 (ProcessAccess)** and correlates it with suspicious access masks that are indicative of a process hollowing sequence, particularly when a parent opens a handle to its own child to manipulate its memory.

```yaml
title: Suspicious Process Access indicating Process Hollowing (AN1076)
id: fbbcc3f9-676b-4e6c-a8eb-8b0ab3606f1d
status: experimental
description: Detects adversary use of suspended process creation followed by memory manipulation, indicative of process hollowing.
author: Krishna Gupta
date: 2026-06-09
logsource:
    category: process_access
    product: windows
    # Relies on Sysmon Event ID 10 collected via Wazuh
detection:
    selection_target:
        TargetImage|endswith:
            - '\svchost.exe'
            - '\explorer.exe'
            - '\notepad.exe'
            - '\dllhost.exe'
    selection_access:
        GrantedAccess|contains:
            - '0x1F0FFF' # All Access
            - '0x143A'
    filter_known:
        SourceImage|endswith:
            - '\MsMpEng.exe'
            - '\services.exe'
    condition: selection_target and selection_access and not filter_known
fields:
    - SourceImage
    - TargetImage
    - GrantedAccess
falsepositives:
    - Antivirus solutions sandboxing or inspecting processes.
    - Specialized enterprise application wrappers.
level: high
tags:
    - attack.privilege_escalation
    - attack.defense_evasion
    - attack.t1055.012
    - analytics.an1076
    - detection.det0382
```

### **3. Blind Spots & Tuning (The "Problems")**

* **Problem 1: Sysmon Blindness to Unmapping**
    * *The Issue:* Process hollowing relies heavily on `NtUnmapViewOfSection`. Sysmon does not log this Native API call, making definitive hollowing detection impossible using Sysmon alone.
    * *The Fix:* Rely on an advanced EDR sensor that specifically hooks `NtUnmapViewOfSection` or `ZwUnmapViewOfSection` and flags processes that call this on core Windows binaries.

* **Problem 2: Ghosting vs. Hollowing**
    * *The Issue:* Process Ghosting is a variant where the attacker deletes the payload file *after* mapping it into memory but *before* the process officially executes, bypassing image load callbacks.
    * *The Fix:* Correlate Sysmon Event ID 11 (File Creation), Sysmon Event ID 23 (File Delete), and Sysmon Event ID 1 (Process Creation) occurring within milliseconds of each other by the same parent process.
