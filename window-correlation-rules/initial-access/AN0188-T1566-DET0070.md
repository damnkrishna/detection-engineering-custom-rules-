### **1. Technique Breakdown: T1566**

* **What it is:** **Phishing**. Adversaries send malicious attachments or links through email (e.g., via Outlook) or messaging tools to gain initial access to target environments. When the user opens the attachment, it spawns script interpreters (like PowerShell, cmd, or mshta) or launching programs to run external code.
* **Log Source Requirements:** Sysmon process creation logs (Event ID 1) capturing parent-child process execution patterns.
* **Coverage Check:**
    * **HIDS (Sysmon + Wazuh): YES.** Sysmon Event ID 1 captures email clients spawning scripting tools or office productivity suites. Wazuh agents process these events to trigger alerts.
    * **NIDS (Suricata + Zeek): YES.** Network logs can flag SMTP/IMAP attachments with suspicious extensions or connections to known phishing domains.

### **2. Custom Sigma Rule**

This rule utilizes **Sysmon Event ID 1 (Process Creation)** to detect email client software (like Microsoft Outlook) or office productivity software spawning shell environments, scripting engines, or remote utilities, indicating immediate payload execution from phishing.

```yaml
title: Phishing - Suspicious Child Process Spawned by Mail Client (AN0188)
id: 485fdf8f-9d6c-4b43-aeb2-a0083bb94ad6
status: experimental
description: Detects suspicious child processes spawned by Microsoft Outlook or other common email clients, which indicates potential user execution of a malicious phishing attachment.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1 collected via Wazuh
detection:
    selection_parent:
        ParentImage|endswith:
            - '\outlook.exe'
            - '\thunderbird.exe'
            - '\foxmail.exe'
    selection_child:
        - Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\wscript.exe'
            - '\cscript.exe'
            - '\mshta.exe'
            - '\rundll32.exe'
            - '\regsvr32.exe'
            - '\hh.exe'
            - '\bitsadmin.exe'
            - '\curl.exe'
        - OriginalFileName:
            - 'Cmd.Exe'
            - 'PowerShell.EXE'
            - 'wscript.exe'
            - 'cscript.exe'
            - 'mshta.exe'
            - 'rundll32.exe'
            - 'regsvr32.exe'
            - 'bitsadmin.exe'
            - 'curl.exe'
    condition: selection_parent and selection_child
fields:
    - Image
    - OriginalFileName
    - ParentImage
falsepositives:
    - Office extensions or administrative tools executing command scripts for mail configuration or updates.
level: high
tags:
    - attack.initial-access
    - attack.t1566
    - analytics.an0188
    - detection.det0070
```

### **3. Blind Spots & Tuning (The "Problems")**

* **Problem 1: Phishing via Hyperlinks (Indirect Execution)**
    * *The Issue:* If a user clicks a phishing link that triggers a browser download, the browser downloads the payload. When the user launches the payload, the parent process is `explorer.exe` or `browser.exe`, not `outlook.exe`.
    * *The Fix:* Correlate browser file writes to the downloads path with process executions in a tight time frame, and monitor browser child processes.

* **Problem 2: Office Document Intermediate (Phishing attachments that spawn word first)**
    * *The Issue:* Phishing attachments are often document templates (`.docx`, `.xlsm`). In this case, `outlook.exe` spawns `winword.exe`, which then spawns `powershell.exe`. The parent of the malicious shell is Word, not Outlook, bypassing a direct parent-child check.
    * *The Fix:* Add a rule checking for office application parent images (`winword.exe`, `excel.exe`, `powerpnt.exe`) spawning shell/scripting executables.

* **Problem 3: Standard Mail Integrations / Add-Ins**
    * *The Issue:* Legitimate mail encryption or calendar add-ins may spawn cmd scripts to perform key decryption or sync configurations, generating false positives.
    * *The Fix:* Create specific exclusions based on command-line argument signatures or code signature validation for known business add-ins.
