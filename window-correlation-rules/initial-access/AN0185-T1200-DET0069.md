### 1. Technique Breakdown: T1200

* What it is: Hardware Additions. Adversaries introduce physical computer components (such as USB keystroke injection dongles, rogue Wi-Fi/network cards, or custom hardware expansion boards) directly into endpoints to bypass local policy restrictions or establish out-of-band communication.
* Log Source Requirements: Windows System Event logs (PnP Events EID 20001), which is not an allowed log source.
* Coverage Check:
  * HIDS (Sysmon + Windows Defender): NO. Sysmon and Microsoft Defender cannot see the physical hardware addition itself.
  * Windows Security Logs: NO. Standard Windows Security Logs (service: security) do not capture plug-and-play hardware additions or driver installation events (which are logged in the System or UserPnp logs).
* Conclusion: This technique is not detectable from Sysmon, Windows Security, or Defender logs.
