### 1. Technique Breakdown: T1565.001

* What it is: Stored Data Manipulation. Adversaries modify business-critical stored data (such as Office documents, PDF sheets, or text databases) to disrupt operations, alter business communications, or plant malicious macros/payloads. Under Windows, they use command-line shells or scripting engines to scan directories and modify file contents. Detections monitor local file modification events targeting document formats (.docx, .xlsx, .pdf) by execution shells, as well as command-line configurations referencing these extensions by scripting hosts.
* Log Source Requirements: Endpoint logs capturing file creation, modification, or write events (Sysmon Event ID 11 / Windows Security Event ID 4663) and process creation logs (Sysmon Event ID 1 / Windows Security Event ID 4688).
* Coverage Check:
  * HIDS (Sysmon + Windows Defender): YES. Sysmon Event ID 11 logs file path names, extensions, and writing processes. Sysmon Event ID 1 captures command-line parameters containing document extensions executed by scripting interpreters.
  * Windows Security Logs: YES. Standard Security Logs track process execution (Event ID 4688) containing the command line arguments.
* Log Sources Covered:
  - Sysmon Event ID 11 (file_event)
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.
* Conclusion: Stored office document modification activity can be detected using file event and process creation logs.

### 2. Custom Sigma Rule

The detection logic is split into file modification monitoring and command-line execution monitoring.

Rule 1 of 2: Stored Office Document Modification by Scripting Host via File Event (File Event)
```yaml
title: Stored Office Document Modification by Scripting Host via File Event (AN0555-A)
id: cc64d033-ce6a-4013-9aea-ac2a69e251ed
status: experimental
description: Detects command-line interpreters or scripting hosts creating or modifying business-critical office documents (e.g. .docx, .xlsx, .pdf), which can indicate unauthorized stored data manipulation.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: file_event
    product: windows
detection:
    selection_process:
        Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\cmd.exe'
            - '\wscript.exe'
            - '\cscript.exe'
            - '\mshta.exe'
    selection_files:
        TargetFilename|endswith:
            - '.docx'
            - '.xlsx'
            - '.pptx'
            - '.pdf'
            - '.odt'
            - '.ods'
    condition: selection_process and selection_files
fields:
    - Image
    - TargetFilename
falsepositives:
    - Legitimate enterprise automation scripts performing automated report compilation, PDF generation, or document migration.
level: medium
tags:
    - attack.impact
    - attack.t1565.001
    - analytic.an0555
    - detection.det0555
```

Rule 2 of 2: Stored Office Document Modification by Scripting Host via CLI (Process Creation)
```yaml
title: Stored Office Document Modification by Scripting Host via CLI (AN0555-B)
id: c7abc145-4d43-4735-ac76-ca50d56073fe
status: experimental
description: Detects command-line processes of scripting hosts referencing common office document extensions in their parameters, indicating script-based file modifications.
author: Krishna Gupta
date: 2026-06-16
logsource:
    category: process_creation
    product: windows
detection:
    selection_process:
        - Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\cmd.exe'
            - '\wscript.exe'
            - '\cscript.exe'
            - '\mshta.exe'
        - OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.dll'
            - 'Cmd.Exe'
            - 'wscript.exe'
            - 'cscript.exe'
            - 'mshta.exe'
    selection_extensions:
        CommandLine|contains:
            - '.docx'
            - '.xlsx'
            - '.pptx'
            - '.pdf'
            - '.odt'
            - '.ods'
    condition: selection_process and selection_extensions
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Legitimate administration scripts generating or compiling files.
level: medium
tags:
    - attack.impact
    - attack.t1565.001
    - analytic.an0555
    - detection.det0555
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Bulk Encryption (Ransomware) Detection Overlaps
  * The Issue: Ransomware encrypts documents in bulk, generating high volume alerts.
  * The Fix: Implement rate-limiting thresholds to alert if a process changes more than 20 unique documents within 10 seconds.

* Problem 2: MS Office VBA Macros
  * The Issue: Attackers executing file manipulation via winword.exe/excel.exe VBA macro engines bypass shell interpreter filters.
  * The Fix: Enable VBA macro logging and monitor internet-downloaded templates.

* Problem 3: Standard Reporting Services
  * The Issue: Corporate SQL services exporting spreadsheets legitimately will trigger false alerts.
  * The Fix: Whitelist known report-generation service accounts and restrict target directories.
