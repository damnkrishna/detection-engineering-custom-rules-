### 1. Technique Breakdown: T1485

* What it is: Data Destruction. Adversaries permanently delete or overwrite sensitive files, directories, or backups on host machines to cause operational disruption or to cover evidence of intrusion. To ensure files cannot be recovered, they employ file wiping utilities (such as sdelete.exe or cipher.exe /w) or delete Windows Volume Shadow Copies (vssadmin.exe delete shadows, wmic shadowcopy delete) to remove local system backup states. They may also use PowerShell script commands targeting shadow copy management namespaces.
* Log Source Requirements: Host process creation and command line logs (Sysmon Event ID 1 / Windows Security Event ID 4688) tracking execution, and PowerShell script block logs (Sysmon Event ID 4104).
* Coverage Check:
  * HIDS (Sysmon + Windows Defender): YES. Sysmon Event ID 1 logs parent processes, target processes, and command line parameters for shadow copy management or wiper tools. Sysmon Event ID 4104 (Script Block) captures script-based shadow copy deletions.
  * Windows Security Logs: YES. Standard Security Logs track process execution (Event ID 4688) containing the command line arguments.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 4104 (ps_script)
* Log Sources Missing / Unused:
  - None.
* Conclusion: File wiping and volume shadow copy deletion activity can be detected using process creation and PowerShell script block logs.

### 2. Custom Sigma Rule

The detection logic is split into utility execution monitoring and script block content monitoring.

Rule 1 of 2: File Wiping or Volume Shadow Copy Deletion via CLI (Process Creation)
```yaml
title: File Wiping or Volume Shadow Copy Deletion via CLI (AN0411-A)
id: 6fcfff22-6761-4c74-9049-cd66a7daa6cd
status: experimental
description: Detects command-line execution of tools used for data destruction, such as sdelete, cipher /w, or commands deleting Volume Shadow Copies (vssadmin, wmic).
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
detection:
    selection_shadow:
        CommandLine|contains:
            - 'delete shadows'
            - 'shadowcopy delete'
            - 'delete catalog'
            - 'resize shadowstorage'
    selection_wipers:
        - Image|endswith:
            - '\sdelete.exe'
        - CommandLine|contains:
            - 'cipher.exe /w'
            - 'cipher /w'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_shadow or selection_wipers) and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate administrative scripts purging old backup catalogs or system shadow storages during system upgrades.
level: high
tags:
    - attack.impact
    - attack.t1485
    - analytic.an0411
    - detection.det0146
```

Rule 2 of 2: File Wiping or Volume Shadow Copy Deletion via PowerShell Script Block (Script Block)
```yaml
title: File Wiping or Volume Shadow Copy Deletion via PowerShell Script Block (AN0411-B)
id: 4abae01c-cce6-4014-b64d-4ba200c8a728

author: Krishna Gupta
date: 2026-06-16
logsource:
    category: ps_script
    product: windows
detection:
    selection_keywords:
        ScriptBlockText|contains:
            - 'Win32_ShadowCopy'
            - 'delete shadows'
            - 'shadowcopy delete'
            - 'vssadmin'
            - 'sdelete'
            - 'cipher'
    condition: selection_keywords
fields:
    - ScriptBlockText
falsepositives:
    - Legitimate administrative scripting for backup management.
level: high
tags:
    - attack.impact
    - attack.t1485
    - analytic.an0411
    - detection.det0146
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Raw Disk Access API Wiping
  * The Issue: Attackers can write custom malware that bypasses command line utilities entirely, writing zeros directly to raw physical disk sectors.
  * The Fix: Enable auditing for raw block access (Sysmon Event ID 9) and block non-system processes accessing local drives.

* Problem 2: PowerShell API Shadow Deletions
  * The Issue: Instead of using vssadmin or wmic command lines, attackers can invoke WMI or CIM classes in PowerShell directly, which bypasses simple CLI string checks.
  * The Fix: Enable PowerShell Script Block Logging (Event ID 4104) and monitor scripts using Rule 2.

* Problem 3: Standard IT Disk Cleanup Noise
  * The Issue: Automated disk space reclaim scripts or Microsoft SCCM software deployment agents may resize shadow storage, causing false positives.
  * The Fix: Whitelist approved backup service accounts and check parent process signatures.
