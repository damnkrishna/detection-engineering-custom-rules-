### 1. Technique Breakdown: T1025

* What it is: Data from Removable Media. Adversaries search for and collect sensitive data stored on removable media devices (such as USB flash drives, external hard drives, or portable media) connected to the compromised host. They utilize scripting engines, command-line utilities (like `xcopy.exe` or `robocopy.exe`), or compression software to automate copying files from these mounted volumes (typically assigned letters like `D:\`, `E:\`, `F:\`, or `G:\` on Windows systems) to local staging folders before exfiltration.
* Log Source Requirements: Windows Security Event Log Event ID 4688 or Sysmon process creation logs (Event ID 1) capturing copy utility execution targeting removable drive letters.
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 logs process details, capturing command lines copying or compressing files from non-system partition drive letters.
    * NIDS (Suricata + Zeek): NO. Removable media access is a local hardware and file-system operation.

### 2. Custom Sigma Rule

This rule utilizes Sysmon Event ID 1 (Process Creation) to detect command line utilities or scripts targeting common removable media drive letters (`D:\`, `E:\`, `F:\`, `G:\`) to copy or compress files.

```yaml
title: Collection - Data Access and Copy from Removable Media (AN1410)
id: 303d498e-8b55-40be-9148-e3bf8fe22803
status: experimental
description: Detects command-line copy utilities, compression engines, or scripting environments targeting files stored on removable media drive letters, indicating unauthorized data collection.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_utilities:
        - Image|endswith:
            - '\xcopy.exe'
            - '\robocopy.exe'
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\7z.exe'
            - '\tar.exe'
        - OriginalFileName:
            - 'xcopy.exe'
            - 'robocopy.exe'
            - 'cmd.exe'
            - 'PowerShell.EXE'
            - 'pwsh.dll'
            - '7z.exe'
            - 'tar.exe'
    selection_removable_drives:
        CommandLine|contains:
            - ' D:\'
            - ' E:\'
            - ' F:\'
            - ' G:\'
            - ' H:\'
    condition: selection_utilities and selection_removable_drives
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - administrators or users copying personal files or running local script backups from their authorized external drives.
level: medium
tags:
    - attack.collection
    - attack.t1025
    - analytic.an1410
    - detection.det0511
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Command Line Obfuscation
  * The Issue: Adversaries can obfuscate command-line arguments using environment variables, caret escapes (^), or base64 encoding, evading simple string matching.
  * The Fix: Implement PowerShell Script Block Logging and utilize regex or script-decoding scripts in the SIEM to check arguments.

* Problem 2: Administrative Activity Noise
  * The Issue: IT administrators legitimately run command-line tools or installers that trigger these rules during system maintenance.
  * The Fix: Establish a baseline of legitimate admin tools, whitelisting specific administrative account names or management servers.

* Problem 3: Masquerading via Renamed Binaries
  * The Issue: Attackers rename native Windows utilities (such as net.exe or cmd.exe) to custom filenames to bypass path-based filters.
  * The Fix: Incorporate Masquerade-resistant criteria, matching on OriginalFileName rather than the static Image path in process creation logs.
