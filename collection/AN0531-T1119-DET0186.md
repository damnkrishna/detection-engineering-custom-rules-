### 1. Technique Breakdown: T1119

* What it is: Automated Collection. Adversaries use scripts or utilities to automatically discover and collect files, clipboard content, or system information at scale. Rather than manually browsing and copying individual files, they run automated commands that recursively search for target file types (e.g., dir /s /b *.docx, Get-ChildItem -Recurse -Filter "*.pdf"), copy matching files to a staging location, and sometimes capture clipboard data in a loop. Detections monitor recursive CLI searches targeting sensitive document types, or automated staging drops of these files in temp folders.
* Log Source Requirements: Endpoint logs capturing process creation events and file creation events.
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 (Process Creation) logs recursive command-line directory searches targeting document files, and Event ID 11 (File Event) logs bulk file creation/drops in temp staging folders.
* NIDS (Suricata + Zeek): NO. Offline, local host actions.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

The detection logic is split into process creation monitoring of CLI tools executing recursive file searches for sensitive document extensions, and file event monitoring of document extensions dropped in staging paths.

Rule 1 of 2: Automated File Collection via Recursive Enumeration (Process Creation)
```yaml
title: Automated File Collection via Recursive Enumeration (AN0531)
id: 19266e2c-9b15-4491-ba75-ba2c7f46320f
status: experimental
description: Detects automated collection behavior — recursive directory searches targeting sensitive file extensions (documents, credentials, archives) via cmd.exe or PowerShell — indicative of scripted bulk data collection.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
detection:
    selection_cmd_recursive:
        - Image|endswith: '\cmd.exe'
        - OriginalFileName: 'Cmd.Exe'
    selection_cmd_args:
        CommandLine|contains:
            - ' /s '
            - ' /S '
    selection_cmd_extensions:
        CommandLine|contains:
            - '*.docx'
            - '*.xlsx'
            - '*.pdf'
            - '*.pst'
            - '*.kdbx'
            - '*.txt'
            - '*.csv'
            - '*.conf'
    selection_powershell:
        - Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
        - OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.dll'
    selection_ps_recursive:
        CommandLine|contains:
            - '-Recurse'
            - 'Get-ChildItem'
            - 'gci '
            - 'ls -r'
    selection_ps_extensions:
        CommandLine|contains:
            - '*.docx'
            - '*.pdf'
            - '*.pst'
            - '*.kdbx'
            - '*.xlsx'
            - '*.csv'
    condition: (selection_cmd_recursive and selection_cmd_args and selection_cmd_extensions) or (selection_powershell and selection_ps_recursive and selection_ps_extensions)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Administrators running inventory scripts to locate and report on document types for compliance or data governance purposes.
level: medium
tags:
    - attack.collection
    - attack.t1119
    - analytic.an0531
    - detection.det0186
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Command Line Obfuscation
  * The Issue: Adversaries can obfuscate command-line arguments using environment variables, caret escapes (^), or base64 encoding, evading simple string matching.
  * The Fix: Implement PowerShell Script Block Logging and utilize regex or script-decoding scripts in the SIEM to check arguments.

* Problem 2: Administrative Activity Noise
  * The Issue: IT administrators legitimately run command-line tools or installers that trigger these rules during system maintenance.
  * The Fix: Establish a baseline of legitimate admin tools, whitelisting specific administrative account names or management servers.

* Problem 3: Masquerading via Renamed Binaries
  * The Issue: Attackers rename native Windows utilities (such as net.exe or cmd.exe) to custom filenames to bypass path-based filters.
  * The Fix: Incorporate Masquerade-resistant criteria, matching on OriginalFileName rather than the static Image path in process creation logs.
