### 1. Technique Breakdown: T1560

* What it is: Archive Collected Data. Adversaries compress or encrypt collected data before exfiltration to minimize network bandwidth usage, speed up transfer times, and hide the contents of the files being stolen. They utilize standard administrative or packaging utilities (like `makecab.exe`, `7z.exe`, `rar.exe`, `tar.exe`) or built-in PowerShell commands. Host-based detection looks for command-line arguments specifying creation switches (e.g. `a`, `-cf`, `-p` for password protection) or using staging output directories.
* Log Source Requirements: Sysmon process creation logs (Event ID 1) or Windows Security Event ID 4688 capturing command-line parameters of archiving utilities.
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 logs process details, capturing command-line switches denoting archive creation and encryption (like adding passwords).
    * NIDS (Suricata + Zeek): NO. Local file archiving is a host-only filesystem operation.

### 2. Custom Sigma Rule

This rule utilizes Sysmon Event ID 1 (Process Creation) to detect the execution of archiving tools or system utilities (`makecab.exe`, `7z.exe`, `rar.exe`, `tar.exe`) running with specific archive creation or password switches.

```yaml
title: Collection - Archiving and Encryption of Data via Utility (AN1458)
id: 6b73e685-e7ab-405d-a698-2acf95c6eb52
status: experimental
description: Detects compression utilities or native tools executing with specific command-line parameters used to create archives or encrypt files (like password switches), suggesting staging before exfiltration.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_makecab:
        - Image|endswith: '\makecab.exe'
        - OriginalFileName: 'makecab.exe'
    selection_utilities:
        - Image|endswith:
            - '\7z.exe'
            - '\rar.exe'
            - '\tar.exe'
            - '\zip.exe'
        - OriginalFileName:
            - '7z.exe'
            - 'rar.exe'
            - 'tar.exe'
            - 'zip.exe'
    selection_switches:
        CommandLine|contains:
            - ' a '       # Add to archive (7z, rar)
            - ' -p'       # Password protection/encryption (7z, rar)
            - ' -cf'      # Create file (tar)
            - ' -cz'      # Compress gzip (tar)
            - 'Compress-Archive'
    condition: selection_makecab or (selection_utilities and selection_switches)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - backup scripts, installer deployment tasks, or manual developer archiving.
level: medium
tags:
    - attack.collection
    - attack.t1560
    - analytic.an1458
    - detection.det0526
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Command Line Obfuscation
  * The Issue: Adversaries can obfuscate command-line arguments using environment variables, caret escapes (^), or base64 encoding, evading simple string matching.
  * The Fix: Implement PowerShell Script Block Logging and utilize regex or script-decoding scripts in the SIEM to check arguments.

* Problem 2: Administrative Activity Noise
  * The Issue: IT administrators legitimately run command-line tools or installers that trigger these rules during system maintenance.
  * The Fix: Establish a baseline of legitimate admin tools, whitelisting specific administrative account names or management servers.

* Problem 3: Masquerading via Renamed Binaries
  * The Issue: Attackers rename native Windows utilities (such as net.exe or cmd.exe) to custom filenames to bypass path-based filters.
  * The Fix: Incorporate Masquerade-resistant criteria, matching on OriginalFileName rather than the static Image path in process creation logs.
