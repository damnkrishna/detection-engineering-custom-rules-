### 1. Technique Breakdown: T1039

* What it is: Data from Network Shared Drive. Adversaries search and collect sensitive files (like spreadsheets, text documents, or databases) stored on remote network shared drives rather than on the local host. They copy these remote files to a local directory or local staging area prior to exfiltration. Detection focuses on identifying copy utilities (like `xcopy.exe`, `robocopy.exe`, `copy`) or compression tools executing commands targeting remote UNC paths.
* Log Source Requirements: Sysmon process creation logs (Event ID 1) capturing copy utility command parameters.
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 captures command-line parameters, letting security tools look for copy tools referencing network UNC paths (`\\`).
    * NIDS (Suricata + Zeek): YES. Network logs capture SMB file read queries, but host logs confirm the local copy/destination.

### 2. Custom Sigma Rule

This rule utilizes Sysmon Event ID 1 (Process Creation) to detect the execution of copy utilities or compression engines targeting remote UNC share directories.

```yaml
title: Collection - Copy of Data from Remote UNC Share (AN1145)
id: 95595801-451a-49c7-abcf-9468c52cdd82
status: experimental
description: Detects command-line utilities (robocopy, xcopy, copy) or compression tools targeting remote network shares (UNC paths) to copy files locally, suggesting data harvesting.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_utilities:
        - Image|endswith:
            - '\robocopy.exe'
            - '\xcopy.exe'
            - '\cmd.exe'
            - '\powershell.exe'
            - '\7z.exe'
            - '\tar.exe'
        - OriginalFileName:
            - 'robocopy.exe'
            - 'xcopy.exe'
            - '7z.exe'
            - 'tar.exe'
    selection_unc:
        CommandLine|contains:
            - ' \\' # Space followed by UNC double backslash (denotes target)
    selection_copy_commands:
        CommandLine|contains:
            - 'copy '
            - ' cp '
            - ' -cf '
            - ' a '
    condition: selection_utilities and selection_unc and selection_copy_commands
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - administrators running standard network backup sync jobs or deploying software updates from server shares.
level: medium
tags:
    - attack.collection
    - attack.t1039
    - analytic.an1145
    - detection.det0410
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Command Line Obfuscation
  * The Issue: Adversaries can obfuscate command-line arguments using environment variables, caret escapes (^), or base64 encoding, evading simple string matching.
  * The Fix: Implement PowerShell Script Block Logging and utilize regex or script-decoding scripts in the SIEM to check arguments.

* Problem 2: Administrative Activity Noise
  * The Issue: IT administrators legitimately run command-line tools or installers that trigger these rules during system maintenance.
  * The Fix: Establish a baseline of legitimate admin tools, whitelisting specific administrative account names or management servers.

* Problem 3: Masquerading via Renamed Binaries
  * The Issue: Attackers rename native Windows utilities (such as net.exe or cmd.exe) to custom filenames to bypass path-based filters.
  * The Fix: Incorporate Masquerade-resistant criteria, matching on OriginalFileName rather than the static Image path in process creation logs.
