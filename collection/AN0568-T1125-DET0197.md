### 1. Technique Breakdown: T1125

* What it is: Video Capture. Adversaries record video from the host webcam or screen using built-in software or custom malware commands. The collected video can be used to gather credentials, observe user actions, or perform espionage. On Windows endpoints, this is typically done by loading video capture libraries (like `avicap32.dll`, `capwin.dll`, or DirectShow/Media Foundation `mf.dll` wrappers) or executing CLI-based media tools (like `ffmpeg.exe`) targeting local camera devices.
* Log Source Requirements: Sysmon Library Load logs (Event ID 7) or process creation logs (Event ID 1).
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 7 records process library loads, enabling detection when an unsigned application loads `avicap32.dll`. Sysmon Event ID 1 tracks command line execution.
    * NIDS (Suricata + Zeek): NO. Network sensors have no visibility into local system driver initialization or camera hardware actions.

### 2. Custom Sigma Rule

```yaml
title: Collection - Anomaly Video Capture Library Load (AN0568)
id: 23d8f5e5-56b8-43fd-95c6-070ded03c274
status: experimental
description: Detects unsigned or non-standard executables loading the Windows video capture DLL (avicap32.dll), suggesting unauthorized webcam recording or capture.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: image_load
    product: windows
    # Relies on Sysmon Event ID 7
detection:
    selection_dll:
        ImageLoaded|endswith: '\avicap32.dll'
    filter_signed:
 # Exclude standard web-meeting and system binaries (e.g. Teams, Chrome, Zoom, Camera App)
        Image|endswith:
            - '\chrome.exe'
            - '\msedge.exe'
            - '\teams.exe'
            - '\zoom.exe'
            - '\skype.exe'
            - '\WindowsCamera.exe'
            - '\obs64.exe'
    condition: selection_dll and not filter_signed
fields:
    - Image
    - ImageLoaded
    - Signed
    - SignatureStatus
falsepositives:
    - Legitimate corporate web collaboration tools or third-party camera management utilities not covered in the static exclusion list.
level: high
tags:
    - attack.collection
    - attack.t1125
    - analytic.an0568
    - detection.det0197
```
