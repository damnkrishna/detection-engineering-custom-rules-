### 1. Technique Breakdown: T1557
* What it is: Adversary-in-the-Middle. Adversaries position themselves between two or more networked devices to capture, modify, or inject traffic. This is typically used to harvest credentials or session tokens passing over the network.
* Log Source Requirements: Sysmon Process Creation logs (Event ID 1).
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process creation command lines capture the invocation of scripting interpreters with proxy listener flags.
  - NIDS (Suricata + Zeek): YES. Can detect network-level AiTM redirects via unexpected gateway changes.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

#### Rule 1 of 2: AiTM Tool Execution
Detects the execution of binaries or tools commonly used to perform Adversary-in-the-Middle interception.

```yaml
title: AiTM Interception Tool Execution (AN0823-A)
id: e31724af-96d1-4bbd-bc0c-579e800002f4
status: experimental
description: Detects command-line execution of tools like Bettercap, Ettercap, or mitmproxy.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\bettercap.exe'
            - '\ettercap.exe'
            - '\mitmproxy.exe'
            - '\mitmdump.exe'
            - '\burpsuite.exe'
        OriginalFileName:
            - 'bettercap.exe'
            - 'ettercap.exe'
            - 'mitmproxy.exe'
            - 'mitmdump.exe'
            - 'burpsuite.exe'
    selection_cli:
        CommandLine|contains:
            - 'bettercap'
            - 'ettercap'
            - 'mitmproxy'
            - 'arp.spoof'
            - 'dns.spoof'
    filter_installers:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_images or selection_cli) and not filter_installers
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Authorized network diagnostics or application security penetration testing.
level: high
tags:
    - attack.collection
    - attack.t1557
    - analytic.an0823
    - detection.det0296
```

#### Rule 2 of 2: Scripting Process Invoked as Proxy Listener
Detects scripting interpreters launched with command-line arguments explicitly configuring them as a local network proxy listener — the actual signal of a local AiTM setup, as opposed to an outbound connection which would only capture the client side.

```yaml
title: Scripting Process Invoked as Proxy Listener (AN0823-B)
id: 44b8766b-080d-4d8b-92e1-cfeb74990ac7
status: experimental
description: Detects Python, PowerShell, or Go binaries launched with flags that configure a local proxy listener (e.g. --listen-port, -p 8080, --mode reverse), indicating a potential local AiTM interceptor being stood up.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_interpreters:
        Image|endswith:
            - '\python.exe'
            - '\python3.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\go.exe'
    selection_proxy_flags:
        CommandLine|contains:
            - '--listen-port'
            - '--mode reverse'
            - '--mode transparent'
            - '-p 8080'
            - '-p 8443'
            - '-p 9090'
            - 'http.server'
            - 'mitmproxy'
            - 'mitmdump'
            - 'mitmweb'
    filter_installers:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: selection_interpreters and selection_proxy_flags and not filter_installers
fields:
    - Image
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Developers running local debug proxy servers (e.g. mitmproxy for API testing) or running simple HTTP servers for local file serving.
level: medium
tags:
    - attack.collection
    - attack.t1557
    - analytic.an0823
    - detection.det0296
```

            - 'bettercap'

            - '\msiexec.exe'

    - process.file.path
    - unmapped.OriginalFileName

    - actor.process.file.path

falsepositives:
    - Authorized network diagnostics or application security penetration testing.

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Developer Workstations Noise
  * The Issue: Developers running mitmproxy, mitmdump, or simple HTTP servers locally for API debugging will trigger Rule 2.
  * The Fix: Exclude specific developer workstation hostnames, user groups, or signed developer tools using a `filter_developer_hosts` block scoped to approved machines.
* Problem 2: Obfuscated Scripting Interpreters
  * The Issue: Scripting binaries can be renamed (e.g. `python.exe` copied to `helper.exe`), bypassing the `Image|endswith` filter in both rules.
  * The Fix: Combine Rule 2 with hash baselines or `OriginalFileName` matching on the interpreter executable.
