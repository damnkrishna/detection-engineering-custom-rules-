### 1. Technique Breakdown: T1213.006

* What it is: Databases. Adversaries target database systems to collect sensitive information stored in structured data stores — such as customer records, financial data, credentials, or intellectual property. On Windows, they use database client tools (sqlcmd.exe, isql.exe, osql.exe, bcp.exe, mysql.exe) to query databases and export results, often initiated from unexpected parent processes like cmd.exe, powershell.exe, or explorer.exe. The exported data is typically written to .csv, .sql, or .bak dump files in user temp directories.
* Log Source Requirements: Endpoint logs capturing process creation events and network connection events.
* Coverage Check:
  - HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 (Process Creation) logs database client tool execution. Sysmon Event ID 3 (Network Connection) logs database connection attempts.
  - NIDS (Suricata + Zeek): YES. Database connections to local or remote servers can be identified.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 3 (network_connection)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Suspicious Database Client Execution for Data Collection (AN0677)
id: a101c2ec-d38f-4b32-8240-eecfec02baad
status: experimental
description: Detects database client tools (sqlcmd, bcp, osql, mysql) launched by unexpected parent processes or with output directed to temp/user directories, indicating adversarial database collection.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
detection:
    selection_db_clients:
        - Image|endswith:
            - '\sqlcmd.exe'
            - '\bcp.exe'
            - '\osql.exe'
            - '\isql.exe'
            - '\mysql.exe'
            - '\mysqldump.exe'
        - OriginalFileName:
            - 'sqlcmd.exe'
            - 'bcp.exe'
            - 'osql.exe'
            - 'isql.exe'
            - 'mysql.exe'
            - 'mysqldump.exe'
    selection_suspicious_parent:
        ParentImage|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\wscript.exe'
            - '\cscript.exe'
            - '\mshta.exe'
            - '\explorer.exe'
    selection_output_to_temp:
        CommandLine|contains:
            - '\Windows\Temp\'
            - '\AppData\Local\Temp\'
            - '\Users\Public\'
            - ' -o '
            - ' /o '
            - ' > '
    condition: selection_db_clients and (selection_suspicious_parent or selection_output_to_temp)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - DBA or developer scripts using sqlcmd.exe from PowerShell or cmd.exe for authorized database queries.
level: high
tags:
    - attack.collection
    - attack.t1213.006
    - analytic.an0677
    - detection.det0242
```
