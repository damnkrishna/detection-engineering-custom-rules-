### 1. Technique Breakdown: T1123

* What it is: Audio Capture. Adversaries capture audio from the host microphone using local APIs or recording tools. They use this capability for room monitoring or industrial espionage. On Windows endpoints, audio recording requires interacting with the Windows Multimedia API or DirectSound, which involves loading libraries like `winmm.dll` or `dsound.dll`. Identifying unsigned or anomalous processes loading these DLLs is a primary host-based detection approach.
* Log Source Requirements: Sysmon Library Load logs (Event ID 7) or process creation logs (Event ID 1).
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 7 logs when applications load `winmm.dll` or `dsound.dll`. Wazuh correlates these to trigger alerts.
    * NIDS (Suricata + Zeek): NO. Network sensors monitor IP streams and cannot track physical audio card capture states.

### 2. Custom Sigma Rule

```yaml
title: Collection - Anomaly Audio Capture Library Load (AN0619)
id: 67879061-32be-4edb-83c3-66c3d77a1a5c
status: experimental
description: Detects unsigned or non-standard executables loading Windows multimedia and audio recording DLLs (winmm.dll, dsound.dll), indicating potential unauthorized microphone recording.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: image_load
    product: windows
    # Relies on Sysmon Event ID 7
detection:
    selection_dll:
        ImageLoaded|endswith:
            - '\winmm.dll'
            - '\dsound.dll'
    filter_signed:
 # Exclude known web conferencing and system media programs
        Image|endswith:
            - '\chrome.exe'
            - '\msedge.exe'
            - '\teams.exe'
            - '\zoom.exe'
            - '\skype.exe'
            - '\slack.exe'
            - '\discord.exe'
            - '\audacity.exe'
            - '\obs64.exe'
            - '\SoundRecorder.exe'
    condition: selection_dll and not filter_signed
fields:
    - Image
    - ImageLoaded
    - Signed
    - SignatureStatus
falsepositives:
    - Authorized corporate meeting applications or screen recording packages not covered in the static exclusion list.
level: high
tags:
    - attack.collection
    - attack.t1123
    - analytic.an0619
    - detection.det0221
```
