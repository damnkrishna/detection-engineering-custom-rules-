### 1. Technique Breakdown: T1114.001

* What it is: Local Email Collection. Adversaries access locally stored email data files to harvest communications, credentials, or sensitive business information. On Windows, Microsoft Outlook stores email locally in Personal Storage Table files (.pst) and Offline Storage Table files (.ost) within the user's profile directory (%USERPROFILE%\Documents\Outlook Files\ or %LOCALAPPDATA%\Microsoft\Outlook\). Adversaries use shell commands, PowerShell, or custom tools to locate and copy these large data files.
* Log Source Requirements: Endpoint logs capturing file creation events and process creation events.
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 11 (File Event) captures file creation events for .pst/.ost files being copied or opened by non-Outlook processes. Sysmon Event ID 1 (Process Creation) logs command-line searches or file copy commands referencing Outlook files.
* NIDS (Suricata + Zeek): NO. Staging/access of email archives is host-local.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Local Outlook Email Archive Access by Non-Outlook Process (AN0130)
id: 4f27f01e-e996-4a38-82ab-2c7e5974a24c
status: experimental
description: Detects non-Outlook processes accessing or copying local Outlook PST or OST email data files, which may indicate adversarial email collection for intelligence gathering or credential harvesting.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: file_event
    product: windows
detection:
    selection_pst_ost:
        TargetFilename|endswith:
            - '.pst'
            - '.ost'
    selection_outlook_paths:
        TargetFilename|contains:
            - '\Microsoft\Outlook\'
            - '\Outlook Files\'
            - '\Documents\Outlook'
    filter_outlook:
        Image|endswith:
            - '\OUTLOOK.EXE'
            - '\outlook.exe'
    condition: (selection_pst_ost or selection_outlook_paths) and not filter_outlook
fields:
    - Image
    - TargetFilename
    - User
    - LogonId
falsepositives:
    - software copying Outlook PST files as part of user profile backups. Email archival tools like Mimecast or Barracuda that access local PST files.
level: high
tags:
    - attack.collection
    - attack.t1114.001
    - analytic.an0130
    - detection.det0047
```

```yaml
title: Local Outlook Email Archive CLI Search (AN0130-B)
id: e5ef5cbd-9945-4dea-9c20-a2f525ac96ef
status: experimental
description: Detects command-line tool execution attempting to locate, list, or copy local Outlook PST or OST data files.
author: Krishna Gupta
date: 2026-06-17
logsource:
    category: process_creation
    product: windows
detection:
    selection_process:
        - Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\findstr.exe'
            - '\robocopy.exe'
            - '\xcopy.exe'
        - OriginalFileName:
            - 'cmd.exe'
            - 'PowerShell.EXE'
            - 'pwsh.dll'
            - 'findstr.exe'
            - 'robocopy.exe'
            - 'xcopy.exe'
    selection_args:
        CommandLine|contains:
            - '.pst'
            - '.ost'
    condition: selection_process and selection_args
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Administrative backup tasks or file migration scripts targeting user profile mail archives.
level: medium
tags:
    - attack.collection
    - attack.t1114.001
    - analytic.an0130
    - detection.det0047
```
