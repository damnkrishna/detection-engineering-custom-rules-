# MANUALLY UPDATE: AN2070

**CHANGES TO MAKE:**
1. Removed `orig_h: '*'` and `resp_h: '*'` wildcard matchers from the detection blocks as they act as no-ops.
2. Refactored the invalid inline aggregation by splitting the logic into one base Sigma event rule and explicit `event_count` correlation rules (Fast Scan, Slow Scan, and Distributed Scan).
3. Split the invalid `filter_legitimate` block into `filter_legitimate_cidr` and `filter_legitimate_ua` to ensure pySigma can parse the filters correctly.
4. Updated the `AN2070-Correlation` rule to use valid UUID references for its component rules.
5. All rules have been assigned fresh, truly random UUIDs.
6. The `nmap` global whitelist entry remains removed.
7. **Added UDP support:** The base rule now explicitly includes `udp` alongside `tcp`, and a new `AN2070-UDP` correlation rule has been added to detect UDP-based scanning like `masscan`.

8. **Added `AN2070-PostScan-Connection`:** Created the missing dependency rule for `AN2070-Correlation` with UUID `9e8d7c6b...` to complete the scan-to-connection chain.

title: External Port Scanning Detection (AN2070)
id: c454ff9b-0ef8-4973-95dc-0976d38644ae
