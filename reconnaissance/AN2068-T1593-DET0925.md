### 1. Technique Breakdown: T1593
* What it is: Search Open Websites/Domains. Adversaries search open web sources (e.g. search engines, domains directories, public forums) to gather intelligence about target web profiles and assets.
* Log Source Requirements: Log sources capturing external web queries.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): NO. Performed externally on third-party sites.
  - NIDS (Suricata + Zeek): NO. Off-network OSINT.
* Log Sources Covered:
  - None.
* Log Sources Missing / Unused:
  - None.
* Conclusion: This technique is not detectable from Sysmon, Windows Security, or Defender logs.

---

### 2. Custom Sigma Rule

This technique is passive OSINT. Attacker searches open portals. Detection is not possible via local logs.

---

### 3. Blind Spots & Tuning (The "Problems")
* Problem 1: OSINT Searching
  * The Issue: Attacker gathers domain data via search engine dorks.
  * The Fix: Monitor public search results for exposed internal documents or data leaks.
* Problem 2: Domain Directories
  * The Issue: Public directories map organizational structures.
  * The Fix: Minimize public employee domain listings.
* Problem 3: Social Media Mining
  * The Issue: Corporate posts expose technology structures.
  * The Fix: Train staff on social media hygiene regarding work environments.
