### 1. Technique Breakdown: T1596
* What it is: Search Open Technical Databases. Adversaries query public technical repositories (such as certificate transparency logs, WHOIS registers, DNS records, and Shodan) to profile target domains and networks.
* Log Source Requirements: Log sources capturing boundary lookups.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): NO. Performed externally on public databases.
  - NIDS (Suricata + Zeek): NO. Attacker does not connect to target interfaces.
* Log Sources Covered:
  - None.
* Log Sources Missing / Unused:
  - None.
* Conclusion: This technique is not detectable from Sysmon, Windows Security, or Defender logs.

### 2. Custom Sigma Rule

This technique is passive OSINT. Attacker queries public registers. Detection is not possible via local logs.

### 3. Blind Spots & Tuning (The "Problems")
* Problem 1: DNS Zone Transfer Lookups
  * The Issue: Attackers query public DNS servers for zone transfers.
  * The Fix: Configure authoritative DNS servers to refuse zone transfer (AXFR) requests.
* Problem 2: Certificate Monitoring
  * The Issue: SSL/TLS certificate transparency logs are public.
  * The Fix: Monitor CT logs using brand monitoring services to alert on new certificates registered under your name.
* Problem 3: WHOIS Database Lookups
  * The Issue: WHOIS record queries are public.
  * The Fix: Use domain proxy registration to mask corporate admin emails.
