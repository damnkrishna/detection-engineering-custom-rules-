### 1. Technique Breakdown: T1592
* What it is: Gather Victim Host Information. Adversaries query endpoints to discover host details, including operating system versions, patch levels, software versions, system configurations, and host names. Once a foothold is achieved, the Red Team executes system discovery commands to identify the host properties.
* Log Source Requirements: Endpoint process logs capturing command-line arguments.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Sysmon Event ID 1 logs process creation and CLI arguments.
  - NIDS (Suricata + Zeek): NO. Host-local commands.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Suspicious System Information Gathering (AN2067)
id: 5a8a1b24-9b2f-4c8d-8d4e-b5c6d7e8f9a0
status: experimental
description: Detects the execution of utilities like systeminfo, dxdiag, and gpresult to discover system specifications, filtering out benign local interactive admin executions unless suspicious remote query parameters are used.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_utilities:
        Image|endswith:
            - '\systeminfo.exe'
            - '\dxdiag.exe'
            - '\gpresult.exe'
        OriginalFileName:
            - 'systeminfo.exe'
            - 'dxdiag.exe'
            - 'gpres.exe'
    selection_suspicious_cli:
        CommandLine|contains:
            - '/S'  # Remote system query — suspicious
            - '/U'  # Remote credentials — suspicious
    filter_admin:
        ParentImage|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\explorer.exe'
            - '\mmc.exe'
    filter_approved_scripts:
        ParentCommandLine|contains:
            - 'C:\Program Files\Diagnostic Tools\'
            - 'C:\Windows\System32\drivers\etc\'
    condition: ((selection_utilities and selection_suspicious_cli) or (selection_utilities and not filter_admin)) and not filter_approved_scripts
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Administrative diagnostics or inventory software updates.
    - Approved diagnostic scripts running from whitelisted paths (e.g. C:\Program Files\Diagnostic Tools\).
level: medium
tags:
    - attack.reconnaissance
    - attack.t1592
    - analytic.an2067
    - detection.det0924
```
