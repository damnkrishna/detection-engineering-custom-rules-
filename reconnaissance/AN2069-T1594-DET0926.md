### 1. Technique Breakdown: T1594
* What it is: Search Victim-Owned Websites. Adversaries crawl, scrape, or scan public-facing websites owned by the target organization to discover information. This includes looking for exposed directories, configuration files, site metadata, backup folders, or administrative interfaces.
* Log Source Requirements: Web application and proxy firewall logs.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): NO. Telemetry is collected in web application logs.
  - NIDS (Suricata + Zeek): YES. Web application access requests.
* Log Sources Covered:
  - Web Proxy & Firewall logs (category: web_server)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

Detects anomalous bursts of web requests targeting directory discovery paths (wp-admin, .git, .env, .aws) returning 403 Forbidden status codes from a single source IP within a short timeframe.

```yaml
title: Rapid Web Path Discovery from Single Source (AN2069)
id: f1a2b3c4-d5e6-4f7a-8b9c-0d1e2f3a4b5c
status: experimental
description: Detects when a single source IP performs rapid or low-and-slow scan queries on sensitive paths returning 403 Forbidden status codes, indicating directory brute force scanning.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: webserver
    product: windows
detection:
    selection:
        http_request_path|re:
            - '^\/.git\/.*'
            - '^\/.env$'
            - '^\/wp-admin\/.*'
            - '^\/.aws(?:/|$)'
        http_status: 403
    filter_crawler:
        user_agent|contains:
            - 'Googlebot'
            - 'Bingbot'
    filter_auth:
        http_auth_user: '-'
    timeframe: 1m
    condition: selection and not filter_crawler and filter_auth | count() by src_ip > 5
fields:
    - src_ip
    - http_request_path
    - http_status
    - user_agent
falsepositives:
    - Authorized automated vulnerability scanners or penetration testing tools.
level: high
tags:
    - attack.reconnaissance
    - attack.t1594
    - analytic.an2069
    - detection.det0926
```

### 2.1 Companion Sigma Rule: Suspicious Process Spawning from Web Server Parent

This companion rule detects command shells and other interpreter processes spawned by web server processes, which is a key indicator of web shell exploitation.

```yaml
title: Suspicious Process Spawning from Web Server Parent (AN2069-WebShell-Spawning)
id: b2c3d4e5-f6a7-4b8c-9d0e-1a2b3c4d5e6f
status: experimental
description: Detects suspicious command shells (cmd, powershell, bash) spawned by web server processes.
logsource:
    category: process_creation
    product: windows
detection:
    selection:
        ParentImage|endswith:
            - '\w3wp.exe'
            - '\httpd.exe'
            - '\nginx.exe'
            - '\apache2.exe'
            - '\tomcat.exe'
        Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\bash.exe'
            - '\sh.exe'
    filter_apppool:
        User|re: 'NETWORK SERVICE|IIS AppPool'
    filter_legitimate:
        CommandLine|contains:
            - 'iisreset'
            - 'logrotate'
            - 'systemctl'
    condition: selection and not filter_apppool and not filter_legitimate
level: high
tags:
    - attack.execution
    - attack.t1505.003
```

### 2.1a Companion Sigma Rule: Web Shell File Creation

This companion rule detects the creation of web shell files (ASPX, PHP, JSP) inside standard webroot directories (e.g. wwwroot, htdocs) by web server processes.

```yaml
title: Web Shell File Creation (AN2069-WebShell-Files)
id: c3d4e5f6-a7b8-4c9d-8e0f-1a2b3c4d5e6f
status: experimental
description: Detects the creation of web shell files in web directories by web server processes.
logsource:
    category: file_event
    product: windows
detection:
    selection:
        Image|endswith:
            - '\w3wp.exe'
            - '\httpd.exe'
            - '\nginx.exe'
            - '\apache2.exe'
            - '\tomcat.exe'
        TargetFilename|re:
            - '.*\.(asp|aspx|jsp|php|phtml)$'
        TargetFilename|contains:
            - '\wwwroot\'
            - '\htdocs\'
            - '\html\'
    condition: selection
level: high
tags:
    - attack.persistence
    - attack.t1505.003
```

### 2.1b Companion Sigma Rule: Web Path Discovery in CDN Access Logs

This companion rule maps the path discovery detection to CDN-terminated proxy traffic logs (e.g., Cloudflare Access Logs), targeting unauthenticated requests seeking sensitive repositories or admin paths.

```yaml
title: Web Path Discovery in CDN Access Logs (AN2069-CDN-Logs)
id: d4e5f6a7-b8c9-4d0e-9f0a-1b2c3d4e5f6a
status: experimental
description: Detects web path discovery scans in CDN access logs (Cloudflare).
logsource:
    product: cloudflare
detection:
    selection_paths:
        request_uri|re:
            - '^\/.git\/.*'
            - '^\/.env$'
            - '^\/wp-admin\/.*'
            - '^\/.aws(?:/|$)'
    selection_status:
        status_code: 403
    filter_auth:
        http_auth_user: '-'
    timeframe: 1m
    condition: selection_paths and selection_status and filter_auth | count() by client_ip > 5
level: medium
tags:
    - attack.reconnaissance
    - attack.t1594
```

    - attack.reconnaissance

### 2.2 Multi-Stage Correlation Rule: Web Reconnaissance to Post-Exploitation Execution

This correlation rule tracks when an external IP address performs web reconnaissance (scanning sensitive paths) and is followed by web server process anomalies or file writes on the target web server within a 15-minute window.

```yaml
title: Web Reconnaissance Followed by Web Shell Execution (AN2069-Correlation)
id: f2b3c4d5-e6f7-4a8b-9c0d-1e2f3a4b5c6d
status: experimental
description: Correlates web scanning (AN2069) from an external IP with a subsequent web shell file creation (AN2069-WebShell-Files) or suspicious process creation spawned by web server processes (AN2069-WebShell-Spawning) targeting the same host within 15 minutes.
correlation:
    type: temporal
    rules:
        - rule_1: Rapid Web Path Discovery from Single Source (AN2069)
        - rule_2: Suspicious Process Spawning from Web Server Parent (AN2069-WebShell-Spawning)
        - rule_3: Web Shell File Creation (AN2069-WebShell-Files)
    group-by:
        - src_ip
        - host
    timespan: 15m
    condition: rule_1 then (rule_2 or rule_3) and rule_1.host == (rule_2.host or rule_3.host)
level: critical
tags:
    - attack.reconnaissance
    - attack.t1594
    - attack.execution
    - attack.t1505.003
```

### 3. Blind Spots & Tuning (The "Problems")
* Problem 1: Legitimate Web Crawler Noise
  * The Issue: Search engine indexes index paths causing false alerts.
  * The Fix: Whitelist known legitimate User-Agents or verify DNS reverse lookups of search bots.
* Problem 2: Slow Crawlers
  * The Issue: Red Teams scan paths slowly to avoid volume thresholds.
  * The Fix: Rely on signature-based path checks (like matching .git or etc/passwd) rather than status code counts.
* Problem 3: CDN Encrypted Traffic
  * The Issue: Traffic is encrypted and terminated on CDNs (Cloudflare), bypassing local NIDS.
  * The Fix: Feed CDN access logs directly into the SIEM analyzer.
