# AN1604 - Create Account (T1136)

## Technique Breakdown
Adversaries may generically create accounts (local, domain, or cloud) to ensure redundant access to a network. In a Windows environment, this is most broadly detected by observing command-line tools like `net.exe` or `net1.exe` being used with the `/add` parameter, irrespective of whether it's local or domain targeted.

### 2. Custom Sigma Rule

```yaml
title: 'AN1604 - Generic Create Account'
id: d76fac61-f3b9-4f70-a71b-259decdf1f4e
status: experimental
description: 'Detects the usage of net.exe to add a new user account, which may indicate an adversary establishing persistence.'
author: Krishna Gupta
logsource:
  product: windows
  category: process_creation
detection:
  selection_image:
    Image|endswith:
      - '\net.exe'
      - '\net1.exe'
  selection_cmd:
    CommandLine|contains|all:
      - ' user '
      - ' /add'
  condition: selection_image and selection_cmd
fields:
  - EventID
  - Image
  - CommandLine
  - ParentImage
level: high
tags:
  - attack.persistence
  - attack.t1136
  - analytic.an1604
```
