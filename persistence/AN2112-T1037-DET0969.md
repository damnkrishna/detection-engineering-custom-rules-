### 1. Technique Breakdown: T1037

* What it is: Boot or Logon Initialization Scripts. Adversaries may use boot or logon initialization scripts to automatically execute malicious payloads during system startup or user logon. For example, attackers can write command strings to registry paths like `HKCU\Environment\UserInitMprLoopbackScript` or alter the `Userinit` registry key, which the system executes during the initialization process before showing the user desktop.
* Log Source Requirements:
  * Sysmon Registry Value Set (Event ID 13) capturing modifications to logon script registry paths.
* Coverage Check:
  * HIDS (Sysmon): YES. Registry writes to the Environment or Winlogon logon script keys generate Event ID 13.
  * NIDS (Zeek/Suricata): NO. Registry manipulation is a local endpoint activity.
* Log Sources Covered:
  * Sysmon Event ID 13 (registry_event)
* Log Sources Missing / Unused:
  * None.

### 2. Custom Sigma Rule

```yaml
title: User Logon Initialization Script Registry Modification (AN2112)
id: 2dacd2c9-3245-4243-91ea-cb9f7bc89562
status: experimental
description: "Detects modifications to Windows registry keys that configure user logon or initialization scripts (such as UserInitMprLoopbackScript or Userinit parameters), which can be abused by adversaries to achieve persistent execution during user logon."
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: registry_set
    product: windows
detection:
    selection_registry_paths:
        TargetObject|contains:
            - '\Environment\UserInitMprLoopbackScript'
            - '\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon\Userinit'
            - '\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon\VMApplet'
    filter_legitimate_userinit:
        # Default Windows userinit path is normal
        Details: 'C:\Windows\system32\userinit.exe,'
    condition: selection_registry_paths and not filter_legitimate_userinit
fields:
    - TargetObject
    - Details
    - Image
    - User
falsepositives:
    - Group policy updates or domain administrators legitimately deploying logon scripts for user mappings or login notices.
level: high
tags:
    - attack.persistence
    - attack.t1037
    - analytic.an2112
    - detection.det0969
```
