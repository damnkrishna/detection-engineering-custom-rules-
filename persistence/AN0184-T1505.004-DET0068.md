### 1. Technique Breakdown: T1505.004

* What it is: IIS Components. Adversaries install malicious Internet Information Services (IIS) components — including ISAPI filters, ISAPI extensions, or IIS native modules — to achieve persistent code execution on Windows web servers. These components are DLLs that the IIS worker process (w3wp.exe) loads automatically, intercepting or manipulating HTTP requests and responses. Adversaries use the IIS administration tool appcmd.exe to register the DLL, or directly modify IIS configuration files (applicationHost.config).
* Log Source Requirements: Endpoint logs capturing process creation events and file creation events in web server directories.
* Coverage Check:
  - HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 captures appcmd.exe or PowerShell module registrations. Event ID 11 captures DLL file drops in system folders.
  - NIDS (Suricata + Zeek): NO. Host-local configuration changes.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Malicious IIS Module or ISAPI Filter Installation (AN0184)
id: 67145796-ad3c-459b-aa04-a821af14396b
status: experimental
description: Detects adversarial installation of malicious IIS components (native modules, ISAPI filters/extensions) via appcmd.exe or PowerShell web configuration cmdlets.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
detection:
    selection_appcmd:
        - Image|endswith: '\appcmd.exe'
        - OriginalFileName: 'appcmd.exe'
    selection_appcmd_install:
        CommandLine|contains:
            - ' install '
            - ' add '
            - 'module'
            - 'isapi'
            - 'filter'
            - 'handler'
    selection_powershell:
        - Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
        - OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.dll'
    selection_ps_iis:
        CommandLine|contains:
            - 'New-WebConfiguration'
            - 'Add-WebConfiguration'
            - 'isapi'
            - 'GlobalModules'
            - 'system.webServer/modules'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: ((selection_appcmd and selection_appcmd_install) or (selection_powershell and selection_ps_iis)) and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate IIS module installation by administrators during upgrades.
level: high
tags:
    - attack.persistence
    - attack.t1505.004
    - analytic.an0184
    - detection.det0068
```

```yaml
title: Malicious IIS Component File Drop (AN0184-B)
id: ad6cb72e-8c2b-4e0b-8d7a-b5da38cf7ba8
status: experimental
description: Detects drops of new DLL or config files to IIS system directories, representing the dropping phase of a malicious IIS native module or filter.
author: Krishna Gupta
date: 2026-06-17
logsource:
    category: file_event
    product: windows
detection:
    selection_paths:
        TargetFilename|contains:
            - '\System32\inetsrv\'
            - '\inetsrv\config\'
    selection_extensions:
        TargetFilename|endswith:
            - '.dll'
            - '.config'
    condition: selection_paths and selection_extensions
fields:
    - TargetFilename
    - Image
    - User
falsepositives:
    - Software updates or deployment scripts updating IIS configuration files.
level: high
tags:
    - attack.persistence
    - attack.t1505.004
    - analytic.an0184
    - detection.det0068
```
