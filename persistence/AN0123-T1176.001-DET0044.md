# AN0123 - Software Extensions: Browser Extensions (T1176.001)

## Technique Breakdown
Adversaries may install malicious browser extensions to establish persistence, steal credentials, or intercept web traffic. This involves modifications to browser extension directories (e.g., AppData\Local\Google\Chrome\User Data\Default\Extensions) or registry keys dictating force-installed extensions by enterprise policy. Defenders should monitor registry keys like `ExtensionInstallForcelist` and process executions involving browser binaries with extension installation flags.
