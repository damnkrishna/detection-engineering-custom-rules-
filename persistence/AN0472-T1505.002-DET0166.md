# AN0472 - Server Software Component: Transport Agent (T1505.002)

## Technique Breakdown
Adversaries may install malicious Transport Agents in Microsoft Exchange Server to establish persistence, intercept emails, or execute code. Transport Agents are managed via PowerShell cmdlets (e.g., `Install-TransportAgent`). Monitoring process creation events for these cmdlets and tracking Exchange configuration files can detect unauthorized agents.
