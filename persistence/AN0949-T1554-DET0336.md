# AN0949 - Compromise Host Software Binary (T1554)

## Technique Breakdown
Adversaries may modify legitimate host software binaries to establish persistence or execute payloads. By replacing or patching files like `svchost.exe`, `explorer.exe`, or WMI providers, attackers hide their code within trusted processes. Detection involves monitoring unexpected file modifications to critical system binaries, or tracking process executions of these binaries originating from non-standard directories or parent processes.

## Custom Sigma Rule
```yaml
title: 'AN0949 - Compromise Host Software Binary'
id: 'AN0949'
status: experimental
description: 'Detects suspicious file modifications to critical Windows system binaries, which may indicate binary patching or replacement for persistence.'
author: Krishna Gupta
logsource:
  product: windows
  category: file_event
detection:
  selection_targets:
    TargetFilename|endswith:
      - '\wbem\WmiPrvSE.exe'
      - '\System32\svchost.exe'
      - '\System32\explorer.exe'
      - '\System32\lsass.exe'
  selection_event:
    EventType: 'CreateFile'
  filter_trusted:
    Image|startswith: 'C:\Windows\System32\'
    Image|endswith:
      - '\msiexec.exe'
      - '\TrustedInstaller.exe'
      - '\poqexec.exe'
  condition: selection_targets and selection_event and not filter_trusted
fields:
  - EventID
  - TargetFilename
  - Image
  - Details
level: high
tags:
  - attack.persistence
  - attack.t1554
  - analytic.an0949
```

### OCSF Normalized Rule
```yaml
title: 'AN0949 - Compromise Host Software Binary (OCSF)'
id: 'AN0949'
status: experimental
description: 'Detects suspicious file modifications to critical Windows system binaries, which may indicate binary patching or replacement for persistence.'
author: Krishna Gupta
logsource:
  product: windows
  category: file_event
detection:
  selection_signature:
    signature_name|contains:
      - 'Compromise Host Software Binary'
      - 'DET0336'
  condition: selection_signature
fields:
  - event_id
  - signature_name
  - unmapped.parent_image
  - unmapped.api_operation
  - actor.user.name
  - unmapped.granted_access
level: high
tags:
  - attack.persistence
  - attack.t1554
  - analytic.an0949
```

## Blind Spots & Tuning
- Windows updates natively replace these files. The rule filters `TrustedInstaller` and `msiexec`, but other endpoint management tools (e.g. SCCM, third-party patch management) may trigger false positives.
- Tuning should strictly whitelist the hashes and certificates of authorized patch management solutions.
