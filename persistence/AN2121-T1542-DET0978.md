### 1. Technique Breakdown: T1542

* What it is: Pre-OS Boot. Adversaries may manipulate boot logs or system firmware (e.g. BIOS/UEFI) to establish persistence that survives operating system reinstallation, driver loading checks, and hard drive wiping. This is detected by monitoring the execution of firmware flash utilities or low-level disk access tools that interact with motherboard ROM chips.
* Log Source Requirements:
  * Sysmon Process Creation (Event ID 1) auditing low-level firmware manipulation commands and vendor bios utilities.
* Coverage Check:
  * HIDS (Sysmon): YES. Processes launched to perform bios updates generate telemetry.
  * NIDS (Zeek/Suricata): NO. Firmware modification is entirely local to the endpoint hardware.
* Log Sources Covered:
  * Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  * None.

### 2. Custom Sigma Rule

```yaml
title: System Firmware or BIOS Flash Utility Execution (AN2121)
id: 90e756bf-f5f4-49a4-b70b-5eee7262c142
status: experimental
description: "Detects the execution of known bios flash utilities, motherboard firmware tools (e.g. flashrom, HpBiosUpdate, WinFlash, ASUS WinFlash), or command lines modifying UEFI settings, indicating potential pre-OS boot persistent modification."
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\flashrom.exe'
            - '\winflash.exe'
            - '\HpBiosUpdate.exe'
            - '\fwupd.exe'
    selection_ofn:
        OriginalFileName:
            - 'flashrom.exe'
            - 'WinFlash.exe'
            - 'HpBiosUpdate.exe'
            - 'fwupd.exe'
    selection_cli:
        CommandLine|contains:
            - 'bios'
            - 'firmware'
            - 'uefi'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    filter_vendor:
        ParentImage|endswith:
            - '\HPSupportSolutionsFramework.exe'
            - '\AsusSystemControl.exe'
    condition: (selection_images or selection_ofn) and selection_cli and not (filter_installer or filter_vendor)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - IT support personnel or automated system update software executing BIOS/firmware update scripts during maintenance routines.
level: high
tags:
    - attack.persistence
    - attack.t1542
    - analytic.an2121
    - detection.det0978
```

### 3. OCSF Normalized Rule

```yaml
title: 'System Firmware or BIOS Flash Utility Execution (AN2121) (OCSF-Normalized)'
id: '90e756bf-f5f4-49a4-b70b-5eee7262c142'
status: experimental
description: 'OCSF Normalized rule for System Firmware or BIOS Flash Utility Execution (AN2121)'
author: Krishna Gupta
logsource:
    product: ocsf
    class: process_activity
detection:
    selection_images:
        process.file.path|endswith:
            - '\flashrom.exe'
            - '\winflash.exe'
            - '\HpBiosUpdate.exe'
            - '\fwupd.exe'
    selection_ofn:
        process.file.name:
            - 'flashrom.exe'
            - 'WinFlash.exe'
            - 'HpBiosUpdate.exe'
            - 'fwupd.exe'
    selection_cli:
        process.cmd_line|contains:
            - 'bios'
            - 'firmware'
            - 'uefi'
    filter_installer:
        unmapped.parent_image|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    filter_vendor:
        unmapped.parent_image|endswith:
            - '\HPSupportSolutionsFramework.exe'
            - '\AsusSystemControl.exe'
    condition: (selection_images or selection_ofn) and selection_cli and not (filter_installer or filter_vendor)
fields:
    - time
level: high
tags:
    - attack.persistence
    - attack.t1542
    - analytic.an2121
    - detection.det0978
```
