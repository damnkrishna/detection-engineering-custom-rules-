# AN0085 - Office Application Startup: Outlook Forms (T1137.003)

## Technique Breakdown
Adversaries may abuse Microsoft Outlook forms to establish persistence or execute arbitrary code. Outlook forms can contain VBScript that executes when a specific event occurs, such as opening a custom form. This requires modifications to specific Outlook registry keys or the drop of malicious `.fdm` / `.oft` form files. Defenders should monitor file creations in Outlook app data directories and registry modifications under `Software\Microsoft\Office\Outlook\Addins` and `FormRegions`.

### 2. Custom Sigma Rule

```yaml
title: 'AN0085 - Office Application Startup: Outlook Forms'
id: 'AN0085'
status: experimental
description: 'Detects suspicious registry modifications targeting Outlook Forms, which may indicate an adversary establishing persistence via malicious VBScript within custom Outlook forms.'
author: Krishna Gupta
logsource:
  product: windows
  category: registry_set
detection:
  selection_forms:
    TargetObject|contains: '\Software\Microsoft\Office\Outlook\Addins'
    EventType: 'SetValue'
  selection_regions:
    TargetObject|contains: '\FormRegions\'
  condition: selection_forms or selection_regions
fields:
  - EventID
  - TargetObject
  - Image
  - Details
level: high
tags:
  - attack.persistence
  - attack.t1137.003
  - analytic.an0085
```
