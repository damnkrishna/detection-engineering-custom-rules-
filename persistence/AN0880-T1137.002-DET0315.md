# AN0880 - Office Application Startup: Office Test (T1137.002)

## Technique Breakdown
Adversaries can achieve persistence by modifying the `Office Test` registry key. When an Office application starts, it checks this key, and if configured, it will load the specified DLL. This allows attackers to silently load a malicious payload whenever a user opens an Office application like Word or Excel. Detection focuses on monitoring the creation or modification of the `Office Test` key.
