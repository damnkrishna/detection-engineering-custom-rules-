# AN0511 - Server Software Component: SQL Stored Procedures (T1505.001)

## Technique Breakdown
Adversaries may abuse SQL Server stored procedures (like `xp_cmdshell` or `sp_OACreate`) to establish persistence or execute arbitrary OS commands. By modifying or creating malicious stored procedures, attackers maintain access even if OS-level backdoors are removed. Detection involves monitoring `sqlservr.exe` for child process creations or command-line executions containing these specific stored procedure invocations.

id: ad845d30-19bd-47e5-b140-a62a9e5b1fea
status: experimental
description: 'Detects process execution originating from SQL Server involving dangerous stored procedures (xp_cmdshell, sp_OACreate), typically used for code execution or persistence.'

  product: windows
  category: process_creation
detection:
  selection_parent:
    ParentImage|endswith: '\sqlservr.exe'
  selection_cmd:
    CommandLine|contains:
      - 'xp_cmdshell'
      - 'sp_OACreate'
      - 'sp_OAMethod'
  condition: selection_parent and selection_cmd

  - EventID
  - Image
  - CommandLine
  - ParentImage
