# AN1174 - Power Settings (T1653)

## Technique Breakdown
Adversaries may modify system power settings (e.g., disabling sleep, hibernation, or automatic screen lock) to ensure their persistent payloads remain active and network connections do not drop when the user is away. This is commonly done using the built-in `powercfg.exe` utility. Detection relies on monitoring command-line executions of `powercfg` modifying these parameters.

### 2. Custom Sigma Rule

```yaml
title: 'AN1174 - Power Settings'
id: 6ea85653-8ec3-4977-84e1-917479b28931
status: experimental
description: 'Detects the use of powercfg.exe to disable sleep or hibernation settings, a common tactic to maintain persistent network connections.'
author: Krishna Gupta
logsource:
  product: windows
  category: process_creation
detection:
  selection_image:
    Image|endswith: '\powercfg.exe'
    OriginalFileName: 'powercfg.exe'
  selection_args:
    CommandLine|contains:
      - ' -x '
      - ' /x '
      - ' -hibernate '
      - ' /hibernate '
      - ' -standby-timeout '
      - ' /standby-timeout '
  condition: selection_image and selection_args
fields:
  - EventID
  - Image
  - CommandLine
  - ParentImage
level: medium

  - attack.persistence
```
