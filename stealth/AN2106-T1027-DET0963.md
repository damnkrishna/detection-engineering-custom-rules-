### 1. Technique Breakdown: T1027

* What it is: Obfuscated Files or Information. Adversaries may attempt to make an executable or file difficult to discover or analyze by encoding, encrypting, or otherwise obfuscating its contents — most commonly via PowerShell Base64 encoded commands.
* Log Source Requirements: Sysmon Process Creation (Event ID 1) / Windows Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. PowerShell -EncodedCommand and similar flags are captured.
  - NIDS (Suricata + Zeek): NO. Host-local obfuscation.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

#### Rule 1 of 1: PowerShell Encoded Command or Heavy Obfuscation Execution
Detects PowerShell launched with encoded command flags or deeply nested string obfuscation patterns.

```yaml
title: PowerShell Encoded Command or Heavy Obfuscation Execution (AN2106)
id: 6e2d4b87-9f1a-4c53-b8d2-3a7c1e56f948
status: experimental
description: Detects PowerShell launched with -EncodedCommand or common obfuscation flags (e.g. -Enc, -ec, -e), used by adversaries to hide malicious commands from command-line logging. Includes OriginalFileName to resist binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
    selection_ofn:
        OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.exe'
    selection_encoded:
        CommandLine|re:
            - '(?i)\s+-e(nc(odedcommand)?)?\s+[A-Za-z0-9+/=]{20,}'
            - '(?i)\s+-ec\s+[A-Za-z0-9+/=]{20,}'
    filter_known_tools:
        ParentImage|endswith:
            - '\vscode\Code.exe'
            - '\WindowsPowerShell\v1.0\powershell.exe'
        CommandLine|contains:
            - 'Import-Module'
    condition: (selection_images or selection_ofn) and selection_encoded and not filter_known_tools
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Legitimate software deployment tools (SCCM, Ansible) that encode PowerShell commands for safe transmission.
level: high
tags:
    - attack.defense_evasion
    - attack.t1027
    - analytic.an2106
    - detection.det0963
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Script Block Obfuscation
  * The Issue: Obfuscation techniques like string concatenation, character substitution, or SecureString encoding are not caught by this command-line rule.
  * The Fix: Enable PowerShell Script Block Logging (Event ID 4104) — deobfuscated code is logged after execution before it runs.
* Problem 2: Invoke-Obfuscation Variants
  * The Issue: The Invoke-Obfuscation framework produces hundreds of obfuscation variants that may not use -EncodedCommand at all.
  * The Fix: Combine with AMSI (Antimalware Scan Interface) monitoring for runtime deobfuscation detection.
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present when PE metadata is intact.
  * The Fix: Treat Image and OriginalFileName as complementary — either match alone is sufficient.
