### 1. Technique Breakdown: T1027

* What it is: Obfuscated Files or Information. Adversaries may attempt to make an executable or file difficult to discover or analyze by encoding, encrypting, or otherwise obfuscating its contents — most commonly via PowerShell Base64 encoded commands.
* Log Source Requirements: Sysmon Process Creation (Event ID 1) / Windows Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. PowerShell -EncodedCommand and similar flags are captured.
  - NIDS (Suricata + Zeek): NO. Host-local obfuscation.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: PowerShell Encoded Command or Heavy Obfuscation Execution (AN2106)
id: 7324ee0e-6f15-4585-b49d-096fcc912980
status: experimental
description: Detects PowerShell launched with -EncodedCommand or common obfuscation flags (e.g. -Enc, -ec, -e), used by adversaries to hide malicious commands from command-line logging. Includes OriginalFileName to resist binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
    selection_ofn:
        OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.exe'
    selection_encoded:
        CommandLine|re:
            - '(?i)\s+-e(nc(odedcommand)?)?\s+[A-Za-z0-9+/=]{20,}'
            - '(?i)\s+-ec\s+[A-Za-z0-9+/=]{20,}'
    filter_known_tools:
        ParentImage|endswith:
            - '\vscode\Code.exe'
            - '\WindowsPowerShell\v1.0\powershell.exe'
        CommandLine|contains:
            - 'Import-Module'
    condition: (selection_images or selection_ofn) and selection_encoded and not filter_known_tools
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Legitimate software deployment tools (SCCM, Ansible) that encode PowerShell commands for safe transmission.
level: high
tags:
    - attack.defense_evasion
    - attack.t1027
    - analytic.an2106
    - detection.det0963
```

### 3. OCSF Normalized Rule

```yaml
title: 'PowerShell Encoded Command or Heavy Obfuscation Execution (AN2106) (OCSF-Normalized)'
id: '7324ee0e-6f15-4585-b49d-096fcc912980'
status: experimental
description: 'OCSF Normalized rule for PowerShell Encoded Command or Heavy Obfuscation Execution (AN2106)'
author: Krishna Gupta
logsource:
    product: ocsf
    class: process_activity
detection:
    selection_images:
        process.file.path|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
    selection_ofn:
        process.file.name:
            - 'PowerShell.EXE'
            - 'pwsh.exe'
    selection_encoded:
        process.cmd_line|re:
            - '(?i)\s+-e(nc(odedcommand)?)?\s+[A-Za-z0-9+/=]{20,}'
            - '(?i)\s+-ec\s+[A-Za-z0-9+/=]{20,}'
    filter_known_tools:
        unmapped.parent_image|endswith:
            - '\vscode\Code.exe'
            - '\WindowsPowerShell\v1.0\powershell.exe'
        process.cmd_line|contains:
            - 'Import-Module'
    condition: (selection_images or selection_ofn) and selection_encoded and not filter_known_tools
fields:
    - time
level: high
tags:
    - attack.defense_evasion
    - attack.t1027
    - analytic.an2106
    - detection.det0963
```
