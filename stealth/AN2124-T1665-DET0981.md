### 1. Technique Breakdown: T1665

* What it is: Hide Infrastructure. Adversaries may manipulate local networking configurations to hide or obscure their command and control infrastructure or routing paths. This includes editing the hosts file to prevent security tools from connecting to update domains, or changing DNS resolver client parameters using utility flags (like `netsh` or `Set-DnsClientServerAddress`) to route traffic to malicious DNS nodes.
* Log Source Requirements:
  * Sysmon Process Creation (Event ID 1) capturing command line arguments that alter local DNS server records or route configurations.
* Coverage Check:
  * HIDS (Sysmon): YES. Processes run to alter DNS parameters leave process telemetry.
  * NIDS (Zeek/Suricata): NO. local system modifications occur at the host layer before any network traffic is initiated.
* Log Sources Covered:
  * Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  * None.

### 2. Custom Sigma Rule

```yaml
title: Network DNS Resolver or Interface Routing Hijack (AN2124)
id: 2021a088-8d8c-422d-a75a-bdb9ee3b6fcd
status: experimental
description: "Detects the execution of commands (using netsh, PowerShell Set-DnsClientServerAddress, or host-file updates) attempting to alter system DNS servers or route maps, which is commonly used to hijack traffic or hide C2 nodes."
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\netsh.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
    selection_ofn:
        OriginalFileName:
            - 'netsh.exe'
            - 'PowerShell.EXE'
            - 'pwsh.exe'
    selection_cli:
        CommandLine|re:
            - '(?i)netsh\s+interface\s+(ip|ipv4|ipv6)\s+set\s+dns'
        CommandLine|contains:
            - 'Set-DnsClientServerAddress'
            - 'drivers\etc\hosts'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    filter_vpn:
        ParentImage|endswith:
            - '\vpnagent.exe'
            - '\pangps.exe'
    condition: (selection_images or selection_ofn) and selection_cli and not (filter_installer or filter_vpn)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Network diagnostic tools, VPN client setup agents, or system administrators configuring network adapters during system setup.
level: high
tags:
    - attack.defense_evasion
    - attack.t1665
    - analytic.an2124
    - detection.det0981
```
