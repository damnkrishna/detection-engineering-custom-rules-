### 1. Technique Breakdown: T1014

* What it is: Rootkit. Adversaries may install rootkits to hide files, processes, network connections, registry keys, or drivers from operating system APIs. On Windows systems, this is typically achieved by installing custom kernel-mode drivers (SYS files) or exploiting/loading vulnerable signed drivers (BYOVD) to disable Driver Signature Enforcement (DSE) and hook system routines.
* Log Source Requirements:
  * Sysmon Process Creation (Event ID 1) to detect rootkit inspection/installation tools or driver configuration parameters.
* Coverage Check:
  * HIDS (Sysmon): YES. Executing driver loading scripts or anti-rootkit tools generated telemetry.
  * NIDS (Zeek/Suricata): NO. Rootkit operations are completely local to the kernel.
* Log Sources Covered:
  * Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  * None.

### 2. Custom Sigma Rule

```yaml
title: Rootkit Installation or Kernel Driver Bypass Tool Execution (AN2111)
id: 2a19f2ad-a77c-4821-acd2-67ce2f45e694
status: experimental
description: "Detects the execution of known kernel driver loaders, driver signature enforcement bypass tools (e.g., dsefix, kdu, DSE-Bypass), or anti-rootkit forensic utilities (gmer, pchunter) commonly abused by attackers to inspect or disable kernel protection systems."
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\dsefix.exe'
            - '\kdu.exe'
            - '\gmer.exe'
            - '\pchunter.exe'
            - '\pchunter64.exe'
            - '\hacker.exe'
    selection_ofn:
        OriginalFileName:
            - 'dsefix.exe'
            - 'kdu.exe'
            - 'gmer.exe'
            - 'PCHunter'
            - 'PCHunter64'
            - 'ProcessHacker.exe'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_images or selection_ofn) and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Incident response analysts or malware researchers running kernel inspection tools during forensic investigation.
level: critical
tags:
    - attack.defense_evasion
    - attack.t1014
    - analytic.an2111
    - detection.det0968
```
