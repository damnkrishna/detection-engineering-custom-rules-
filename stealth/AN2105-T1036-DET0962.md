### 1. Technique Breakdown: T1036

* What it is: Masquerading. Adversaries may attempt to manipulate features of their artifacts to make them appear legitimate or benign — e.g., naming a malicious binary svchost.exe or placing it in an unexpected path.
* Log Source Requirements: Sysmon Process Creation (Event ID 1) / Windows Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process image path and OriginalFileName are captured.
  - NIDS (Suricata + Zeek): NO. Host-level process metadata required.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: System Binary Name Used from Non-Standard Path (AN2105)
id: 4c1a9f53-8b2e-4d67-a3c7-9f5b8e24c719
status: experimental
description: Detects well-known Windows system binary names (svchost, lsass, explorer, csrss) executing from paths outside %SystemRoot% or %SystemRoot%\System32, indicating masquerading. Does NOT use OriginalFileName as the attack is specifically about abusing a trusted binary name.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_suspicious_names:
        Image|endswith:
            - '\svchost.exe'
            - '\lsass.exe'
            - '\explorer.exe'
            - '\csrss.exe'
            - '\winlogon.exe'
            - '\services.exe'
            - '\smss.exe'
    filter_legitimate_paths:
        Image|re: '(?i)^C:\\Windows\\'
    condition: selection_suspicious_names and not filter_legitimate_paths
fields:
    - Image
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Security tools or application sandboxes that legitimately run renamed copies of Windows binaries for testing.
level: critical
tags:
    - attack.defense_evasion
    - attack.t1036
    - analytic.an2105
    - detection.det0962
```
