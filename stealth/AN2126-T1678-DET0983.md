### 1. Technique Breakdown: T1678

* What it is: Delay Execution. Adversaries may employ execution delay (sleeping) techniques to bypass automated sandbox analysis environments. By inserting delay cycles (e.g., using `ping` to localhost, `timeout`, `choice`, or PowerShell `Start-Sleep`) before launching their primary payload, malware can evade sandboxes that only monitor process behavior for a brief initial window (typically 1-2 minutes).
* Log Source Requirements:
  * Sysmon Process Creation (Event ID 1) capturing command line delay flags and loop intervals.
* Coverage Check:
  * HIDS (Sysmon): YES. Spawning delays via CLI commands generates process creation logs.
  * NIDS (Zeek/Suricata): NO. local timer delays do not trigger network metadata.
* Log Sources Covered:
  * Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  * None.

### 2. Custom Sigma Rule

```yaml
title: Artificial Execution Delay or Anti-Sandbox Sleep (AN2126)
id: 10024e48-126c-4aa3-a962-4c6d724af3de
status: experimental
description: "Detects command-line execution parameters that execute artificial delays or sleeping patterns (such as pinging 127.0.0.1 a large number of times, using timeout, choice with short defaults, or PowerShell Start-Sleep) commonly used to evade sandbox analysis."
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_ping:
        Image|endswith:
            - '\ping.exe'
        CommandLine|re: '(?i)ping.*(127\.0\.0\.1|localhost).*-n\s+(\d{3,})'
    selection_ping_ofn:
        OriginalFileName: 'ping.exe'
        CommandLine|re: '(?i)ping.*(127\.0\.0\.1|localhost).*-n\s+(\d{3,})'
    selection_ps_sleep:
        Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
        CommandLine|re: '(?i)Start-Sleep\s+-s(econds)?\s+(\d{3,})'
    selection_ps_sleep_ofn:
        OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.exe'
        CommandLine|re: '(?i)Start-Sleep\s+-s(econds)?\s+(\d{3,})'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_ping or selection_ping_ofn or selection_ps_sleep or selection_ps_sleep_ofn) and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Administrative scripts that use timeout or choice to wait for a service to start, or ping loops to verify connection status before proceeding.
level: medium
tags:
    - attack.defense_evasion
    - attack.t1678
    - analytic.an2126
    - detection.det0983
```
