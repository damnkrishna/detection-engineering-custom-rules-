### 1. Technique Breakdown: T1620

* What it is: Reflective Code Loading. Adversaries may reflectively load code in-memory to execute malicious binaries, scripts, or DLLs without writing them to disk. This is typically done to evade signature-based detection on local storage. It is commonly achieved by using PowerShell to invoke assembly reflective load methods (e.g. `[System.Reflection.Assembly]::Load`) or memory copy APIs.
* Log Source Requirements:
  * PowerShell Script Block Logging (Event ID 4104) capturing the full code blocks compiled at runtime.
* Coverage Check:
  * HIDS (PowerShell Operational Logs): YES. Script Block Logging records full script strings regardless of command-line obfuscation.
  * NIDS (Zeek/Suricata): NO. PowerShell execution is entirely local to the endpoint.
* Log Sources Covered:
  * PowerShell Operational Event ID 4104 (Script Block Logging)
* Log Sources Missing / Unused:
  * Sysmon Event ID 1 (cannot trace reflective APIs invoked within scripts).

### 2. Custom Sigma Rule

```yaml
title: PowerShell Reflective Code Loading API Call (AN2122)
id: f1a2b3c4-e5f6-7a8b-9c0d-1e2f3a4b5c83
status: experimental
description: "Detects PowerShell execution invoking APIs used for reflective code loading (such as [System.Reflection.Assembly]::Load, Marshal.Copy, or GetDelegateForFunctionPointer) to execute payloads in memory without writing files to disk."
author: Krishna Gupta
date: 2026-07-01
logsource:
    product: windows
    service: powershell
detection:
    selection_high_signal:
        ScriptBlockText|contains:
            - 'GetDelegateForFunctionPointer'
            - 'VirtualAlloc'
    selection_medium_signal:
        ScriptBlockText|contains:
            - 'System.Reflection.Assembly'
            - 'Reflection.Assembly'
            - '[Assembly]::Load'
            - 'Marshal.Copy'
    selection_obfuscation:
        # Base64 allocations or memory streams typical of assembly loads
        ScriptBlockText|contains|all:
            - '[System.Convert]::FromBase64String'
            - 'IO.MemoryStream'
    condition: selection_high_signal or (selection_medium_signal and selection_obfuscation)
fields:
    - ScriptBlockText
    - User
    - ComputerName
falsepositives:
    - Specialized administrative scripts, deployment tools, or security agents that dynamically load modules in memory during startup or module import.
level: high
tags:
    - attack.defense_evasion
    - attack.t1620
    - analytic.an2122
    - detection.det0979
```
