### 1. Technique Breakdown: T1006

* What it is: Direct Volume Access. Adversaries may bypass host-based file access controls and auditing mechanisms by directly accessing and reading/writing to the raw logical or physical disk volume. This is typically done to extract protected system files (like the SAM registry hive or NTDS.dit database) or to overwrite disk sectors.
* Log Source Requirements:
  * Sysmon Process Creation (Event ID 1) capturing process command-lines attempting to read raw device paths.
* Coverage Check:
  * HIDS (Sysmon): YES. Processes attempting direct volume access via CLI parameters leave traces.
  * NIDS (Zeek/Suricata): NO. Host-level raw disk access is entirely local.
* Log Sources Covered:
  * Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  * Standard Windows file system audit logs (since direct volume access bypasses standard NTFS file access audits).

### 2. Custom Sigma Rule

```yaml
title: Direct Volume Access Command Line Detection (AN2109)
id: f173cf38-c0ed-4229-b698-3f442c46cd9b
status: experimental
description: "Detects process execution command-line parameters attempting direct access to raw physical drives, logical drives, or volume shadow copies (e.g., using physical drive paths like \\\\.\\PhysicalDrive or raw logical paths). This is commonly used to bypass OS file lock/permission security controls."
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\dd.exe'
            - '\vshadow.exe'
            - '\rawcopy.exe'
            - '\ninja.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\cmd.exe'
    selection_ofn:
        OriginalFileName:
            - 'dd.exe'
            - 'vshadow.exe'
            - 'rawcopy.exe'
            - 'PowerShell.EXE'
            - 'pwsh.exe'
            - 'Cmd.Exe'
    selection_cli:
        CommandLine|contains:
            - '\\.\PhysicalDrive'
            - '\\.\Volume'
            - '\\.\c:'
            - '\\.\d:'
            - '\\.\e:'
            - '\\.\f:'
    filter_legitimate:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_images or selection_ofn) and selection_cli and not filter_legitimate
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Backup software or disk imaging utilities legitimately reading raw volumes to create system backups.
    - Disk checking tools (chkdsk) run by administrators.
level: high
tags:
    - attack.defense_evasion
    - attack.t1006
    - analytic.an2109
    - detection.det0966
```

### 3. OCSF Normalized Rule

```yaml
title: 'Direct Volume Access Command Line Detection (AN2109) (OCSF-Normalized)'
id: 'f173cf38-c0ed-4229-b698-3f442c46cd9b'
status: experimental
description: 'OCSF Normalized rule for Direct Volume Access Command Line Detection (AN2109)'
author: Krishna Gupta
logsource:
    product: ocsf
    class: process_activity
detection:
    selection_images:
        process.file.path|endswith:
            - '\dd.exe'
            - '\vshadow.exe'
            - '\rawcopy.exe'
            - '\ninja.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\cmd.exe'
    selection_ofn:
        process.file.name:
            - 'dd.exe'
            - 'vshadow.exe'
            - 'rawcopy.exe'
            - 'PowerShell.EXE'
            - 'pwsh.exe'
            - 'Cmd.Exe'
    selection_cli:
        process.cmd_line|contains:
            - '\\.\PhysicalDrive'
            - '\\.\Volume'
            - '\\.\c:'
            - '\\.\d:'
            - '\\.\e:'
            - '\\.\f:'
    filter_legitimate:
        unmapped.parent_image|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_images or selection_ofn) and selection_cli and not filter_legitimate
fields:
    - time
level: high
tags:
    - attack.defense_evasion
    - attack.t1006
    - analytic.an2109
    - detection.det0966
```
