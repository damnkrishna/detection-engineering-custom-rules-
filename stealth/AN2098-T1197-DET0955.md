### 1. Technique Breakdown: T1197

* What it is: BITS Jobs. Adversaries may abuse Windows Background Intelligent Transfer Service (BITS) to download, upload, or execute files while bypassing common defenses — BITS traffic blends with normal Windows Update traffic.
* Log Source Requirements: Sysmon Process Creation (Event ID 1) / Windows Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. bitsadmin.exe and PowerShell BITS cmdlets produce command-line artifacts.
  - NIDS (Suricata + Zeek): PARTIAL. Outbound HTTP/S BITS traffic can be seen but is indistinguishable from Windows Update without context.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - Windows Event ID 59/60/61 (BITS transfer operational logs) could add coverage but are rarely forwarded.

### 2. Custom Sigma Rule

```yaml
title: BITS Job Transfer or Notification Command Abuse (AN2098)
id: 9733aa2f-b50a-4c2c-93b7-19ce699587d2
status: experimental
description: Detects bitsadmin.exe creating BITS jobs to transfer files or setting notification commands for persistence. Also covers PowerShell BITS abuse. Includes OriginalFileName to resist binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_bitsadmin:
        Image|endswith:
            - '\bitsadmin.exe'
    selection_bitsadmin_ofn:
        OriginalFileName: 'bitsadmin.exe'
    selection_bitsadmin_cli:
        CommandLine|contains:
            - '/transfer'
            - '/addfile'
            - '/setnotifycmdline'
            - '/resume'
    selection_ps:
        Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
    selection_ps_ofn:
        OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.exe'
    selection_ps_cli:
        CommandLine|contains:
            - 'Start-BitsTransfer'
            - 'Add-BitsFile'
    filter_wsus:
        ParentImage|endswith:
            - '\svchost.exe'
        CommandLine|contains|all:
            - 'bits'
            - 'WUAgent'
    condition: (((selection_bitsadmin or selection_bitsadmin_ofn) and selection_bitsadmin_cli) or ((selection_ps or selection_ps_ofn) and selection_ps_cli)) and not filter_wsus
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Windows Update and WSUS clients using BITS for legitimate software downloads.
level: medium
tags:
    - attack.defense_evasion
    - attack.persistence
    - attack.t1197
    - analytic.an2098
    - detection.det0955
```
