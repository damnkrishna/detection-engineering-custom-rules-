### 1. Technique Breakdown: T1674

* What it is: Input Injection. Adversaries may inject inputs into systems to bypass security controls or automate interactions (such as clicking warning popups, executing payloads via UI fields, or simulating keystrokes). This can be done by running keystroke automation engines (like AutoIt, AutoHotkey) or using scripting classes (like WScript.Shell SendKeys) to send keystrokes to target windows.
* Log Source Requirements:
  * Sysmon Process Creation (Event ID 1) capturing command line keywords related to input injection/automation execution.
* Coverage Check:
  * HIDS (Sysmon): YES. Spawning automation scripting engines generates process log traces.
  * NIDS (Zeek/Suricata): NO. Keystroke simulation is entirely local to the host desktop session.
* Log Sources Covered:
  * Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  * None.

### 2. Custom Sigma Rule

```yaml
title: Input Keystroke Automation or Injection Tool Execution (AN2125)
id: e98aa08b-517c-4671-8c73-1582608fcd89
status: experimental
description: "Detects the execution of input injection/automation engines (such as AutoIt3, AutoHotkey) or command line calls executing SendKeys routines to automate keystrokes or UI interactions to bypass warning boxes."
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_autoit_images:
        Image|endswith:
            - '\autoit3.exe'
            - '\autohotkey.exe'
    selection_autoit_ofn:
        OriginalFileName:
            - 'AutoIt3.exe'
            - 'AutoHotkey.exe'
    selection_ps:
        Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
    selection_ps_ofn:
        OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.exe'
    selection_ps_cli:
        CommandLine|contains:
            - 'SendKeys'
            - 'SendInput'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_autoit_images or selection_autoit_ofn or ((selection_ps or selection_ps_ofn) and selection_ps_cli)) and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Legitimate administrative script macros that automate software installation inputs or test execution scripts.
level: medium
tags:
    - attack.defense_evasion
    - attack.t1674
    - analytic.an2125
    - detection.det0982
```

### 3. OCSF Normalized Rule

```yaml
title: 'Input Keystroke Automation or Injection Tool Execution (AN2125) (OCSF-Normalized)'
id: 'e98aa08b-517c-4671-8c73-1582608fcd89'
status: experimental
description: 'OCSF Normalized rule for Input Keystroke Automation or Injection Tool Execution (AN2125)'
author: Krishna Gupta
logsource:
    product: ocsf
    class: process_activity
detection:
    selection_autoit_images:
        process.file.path|endswith:
            - '\autoit3.exe'
            - '\autohotkey.exe'
    selection_autoit_ofn:
        process.file.name:
            - 'AutoIt3.exe'
            - 'AutoHotkey.exe'
    selection_ps:
        process.file.path|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
    selection_ps_ofn:
        process.file.name:
            - 'PowerShell.EXE'
            - 'pwsh.exe'
    selection_ps_cli:
        process.cmd_line|contains:
            - 'SendKeys'
            - 'SendInput'
    filter_installer:
        unmapped.parent_image|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_autoit_images or selection_autoit_ofn or ((selection_ps or selection_ps_ofn) and selection_ps_cli)) and not filter_installer
fields:
    - time
level: high
tags:
    - attack.defense_evasion
    - attack.t1674
    - analytic.an2125
    - detection.det0982
```
