### 1. Technique Breakdown: T1216

* What it is: System Script Proxy Execution. Adversaries may use trusted scripts signed by Microsoft (e.g., pubprn.vbs, manage-bde.wsf) to proxy execution of malicious code, bypassing application control policies that trust Microsoft-signed scripts.
* Log Source Requirements: Sysmon Process Creation (Event ID 1) / Windows Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Command lines for script proxy execution are captured.
  - NIDS (Suricata + Zeek): NO. Host-local execution.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

#### Rule 1 of 1: Microsoft-Signed Script Proxy Execution
Detects cscript.exe or wscript.exe executing known Microsoft-signed scripts abused for proxy execution.

```yaml
title: Microsoft-Signed Script Proxy Execution (AN2101)
id: 9e6b3a47-2d1f-4c85-b7e8-4f9a2c63d817
status: experimental
description: Detects cscript.exe or wscript.exe executing known Microsoft-signed scripts commonly abused to bypass application control (pubprn.vbs, manage-bde.wsf, SyncAppvPublishingServer.vbs). Includes OriginalFileName to resist binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\cscript.exe'
            - '\wscript.exe'
    selection_ofn:
        OriginalFileName:
            - 'cscript.exe'
            - 'wscript.exe'
    selection_scripts:
        CommandLine|contains:
            - 'pubprn.vbs'
            - 'manage-bde.wsf'
            - 'SyncAppvPublishingServer.vbs'
            - 'winrm.vbs'
            - 'slmgr.vbs'
    filter_legitimate:
        CommandLine|contains:
            - 'slmgr.vbs /ato'
            - 'slmgr.vbs /dlv'
            - 'slmgr.vbs /xpr'
            - 'slmgr.vbs /dli'
            - 'winrm.vbs quickconfig'
    condition: (selection_images or selection_ofn) and selection_scripts and not filter_legitimate
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Legitimate license activation using slmgr.vbs on Windows activations (filtered above).
level: high
tags:
    - attack.defense_evasion
    - attack.t1216
    - analytic.an2101
    - detection.det0958
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Unlisted Signed Scripts
  * The Issue: New Microsoft-signed scripts are discovered regularly as proxy execution vectors (e.g., LOLBAS additions). This rule only covers known, documented ones.
  * The Fix: Periodically update the script list from the LOLBAS project.
* Problem 2: WSH Configuration
  * The Issue: If Windows Script Host is disabled via Group Policy, wscript/cscript execution will fail — but attackers may re-enable it first.
  * The Fix: Monitor for WSH re-enablement registry changes (`HKLM\Software\Microsoft\Windows Script Host\Settings\Enabled`).
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present when PE metadata is intact.
  * The Fix: Treat Image and OriginalFileName as complementary — either match alone is sufficient.
