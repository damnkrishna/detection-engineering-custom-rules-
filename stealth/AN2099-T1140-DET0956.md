### 1. Technique Breakdown: T1140

* What it is: Deobfuscate/Decode Files or Information. Adversaries may use obfuscated files or information to hide artifacts of an intrusion, and may need to decode/deobfuscate them before execution. Common tools include certutil, expand, and copy /b.
* Log Source Requirements: Sysmon Process Creation (Event ID 1) / Windows Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines for decode operations are captured.
  - NIDS (Suricata + Zeek): NO. Host-local file operation.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

#### Rule 1 of 1: File Decode or Deobfuscation via Living-off-the-Land Binaries
Detects certutil, expand, or copy being used to decode or concatenate binary payloads on disk.

```yaml
title: File Decode or Deobfuscation via LOLBins (AN2099)
id: 7b2e4f16-9a3c-4d58-ae12-81f7c3b52e90
status: experimental
description: Detects certutil.exe -decode/-decodehex, expand.exe, or cmd copy /b being used to decode obfuscated payloads. Includes OriginalFileName to resist binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_certutil:
        Image|endswith:
            - '\certutil.exe'
    selection_certutil_ofn:
        OriginalFileName: 'CertUtil.exe'
    selection_certutil_cli:
        CommandLine|contains:
            - '-decode'
            - '-decodehex'
            - '-urlcache'
    selection_expand:
        Image|endswith:
            - '\expand.exe'
    selection_expand_ofn:
        OriginalFileName: 'expand.exe'
    selection_expand_cli:
        CommandLine|re:
            - '(?i)expand\s+.+\.(cab|zip|b64|enc)'
    selection_copy_b:
        Image|endswith:
            - '\cmd.exe'
    selection_copy_b_ofn:
        OriginalFileName: 'Cmd.Exe'
    selection_copy_b_cli:
        CommandLine|contains:
            - 'copy /b'
            - 'copy/b'
    filter_pki:
        ParentImage|endswith:
            - '\mmc.exe'
            - '\certsrv.exe'
    condition: (((selection_certutil or selection_certutil_ofn) and selection_certutil_cli) or ((selection_expand or selection_expand_ofn) and selection_expand_cli) or ((selection_copy_b or selection_copy_b_ofn) and selection_copy_b_cli)) and not filter_pki
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Certificate management tools using certutil for legitimate certificate import/export.
    - Build pipelines using copy /b to concatenate binary files.
level: medium
tags:
    - attack.defense_evasion
    - attack.t1140
    - analytic.an2099
    - detection.det0956
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: PowerShell Decode
  * The Issue: Attackers using `[System.Convert]::FromBase64String()` in PowerShell bypass certutil detection entirely.
  * The Fix: Monitor PowerShell Script Block Logging (Event ID 4104) for Base64 decode patterns.
* Problem 2: Custom Decoder Binaries
  * The Issue: Attackers may ship their own XOR decoder or base64 utility to avoid LOLBin detection.
  * The Fix: Detect execution of unsigned, recently-dropped binaries in temp paths via Sysmon Event ID 11 + 1.
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present when PE metadata is intact.
  * The Fix: Treat Image and OriginalFileName as complementary — either match alone is sufficient.
