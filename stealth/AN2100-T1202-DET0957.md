### 1. Technique Breakdown: T1202

* What it is: Indirect Command Execution. Adversaries may abuse Windows utilities to proxy execution of malicious commands or payloads through trusted, signed Windows binaries (LOLBins), bypassing application control solutions.
* Log Source Requirements: Sysmon Process Creation (Event ID 1) / Windows Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Process command lines are captured.
  - NIDS (Suricata + Zeek): NO. Host-local execution.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

---

### 2. Custom Sigma Rule

#### Rule 1 of 1: Indirect Command Execution via Trusted Windows Utilities
Detects forfiles.exe, pcalua.exe, or other trusted Windows binaries being used to indirectly execute commands or payloads.

```yaml
title: Indirect Command Execution via Trusted Windows Utilities (AN2100)
id: 1c4d8e29-5f7a-4b83-9c16-d2e3f5a87b31
status: experimental
description: Detects LOLBin abuse where forfiles.exe, pcalua.exe, or similar trusted binaries are used to proxy execution of commands or payloads, bypassing application control. Includes OriginalFileName to resist binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_forfiles:
        Image|endswith:
            - '\forfiles.exe'
    selection_forfiles_ofn:
        OriginalFileName: 'forfiles.exe'
    selection_forfiles_cli:
        CommandLine|contains:
            - '/c '
    selection_pcalua:
        Image|endswith:
            - '\pcalua.exe'
    selection_pcalua_ofn:
        OriginalFileName: 'pcalua.exe'
    selection_pcalua_cli:
        CommandLine|contains:
            - ' -a '
    filter_scheduled:
        ParentImage|endswith:
            - '\taskeng.exe'
            - '\svchost.exe'
    filter_file_ops:
        CommandLine|contains:
            - 'cmd /c del'
            - 'cmd /c type'
            - 'cmd /c move'
    condition: (((selection_forfiles or selection_forfiles_ofn) and selection_forfiles_cli) or ((selection_pcalua or selection_pcalua_ofn) and selection_pcalua_cli)) and not (filter_scheduled or filter_file_ops)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Legitimate batch scripts using forfiles.exe to operate on files older than a certain date.
level: medium
tags:
    - attack.defense_evasion
    - attack.t1202
    - analytic.an2100
    - detection.det0957
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Other LOLBins
  * The Issue: There are dozens of additional trusted binaries (msiexec /q, mavinject, cmstp, etc.) that achieve indirect execution. This rule only covers forfiles and pcalua.
  * The Fix: Supplement with dedicated rules for each high-priority LOLBin (e.g., LOLBAS project list).
* Problem 2: Child Process Relationship
  * The Issue: The real detection value is in the child process spawned by forfiles — the command after /c is what executes the payload.
  * The Fix: Use Sysmon Event ID 1 ParentImage/ParentCommandLine fields to detect unexpected processes spawned by forfiles.exe.
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present when PE metadata is intact.
  * The Fix: Treat Image and OriginalFileName as complementary — either match alone is sufficient.
