### 1. Technique Breakdown: T1564.001

* What it is: Hidden Files and Directories. Adversaries set the hidden attribute on files or directories to conceal their malicious artifacts from casual inspection by users or administrators. On Windows, this is done using `attrib.exe +H` (to set the hidden attribute) or `attrib.exe +H +S` (to set both hidden and system attributes, making files invisible in default Explorer views). Alternatively, adversaries create files in Alternate Data Streams (ADS) using the `filename:streamname` notation, hiding payloads inside what appears to be a legitimate file.
* Log Source Requirements: Sysmon process creation logs (Event ID 1) for `attrib.exe` and PowerShell invocations, and Sysmon file event logs (Event ID 11) for ADS file creation.
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 captures `attrib.exe +H` commands with file targets. Sysmon Event ID 11 logs file creation events, and the `TargetFilename` field includes the ADS stream notation (`:streamname`) which can be used to detect ADS writes.
    * NIDS (Suricata + Zeek): NO. Setting file attributes or writing ADS streams are host-local filesystem operations.
* Log Sources Covered:
    - Sysmon Event ID 1 (process_creation)
    - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
    - None.

### 2. Custom Sigma Rule

The detection logic is split into two rules to target attribute modification via process creation and Alternate Data Stream (ADS) file writes separately.

Rule 1 of 2: Hidden File or Directory Attribute Setting (Process Creation)
```yaml
title: Hidden File or Directory Attribute Setting (AN0091-A)
id: a2486d94-ef51-4bbd-9ca9-adfc0157cf85
status: experimental
description: Detects adversarial use of attrib.exe or PowerShell to set hidden and system attributes on files or directories, concealing malicious artifacts from user and administrator inspection.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_attrib:
        - Image|endswith: '\attrib.exe'
        - OriginalFileName: 'attrib.exe'
    selection_attrib_args:
        CommandLine|contains:
            - ' +H '
            - ' +h '
            - ' +S '
            - ' +s '
            - '+H+S'
            - '+hs'
    selection_powershell:
        - Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
        - OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.dll'
    selection_powershell_args:
        CommandLine|contains:
            - 'Hidden'
            - 'System'
            - 'SetAttributes'
            - '[System.IO.File]::SetAttributes'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: ((selection_attrib and selection_attrib_args) or (selection_powershell and selection_powershell_args)) and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - System utilities or software installers that legitimately hide configuration directories (e.g., git, VS Code, or language runtime installers creating .dotfiles).
level: medium
tags:
    - attack.defense-evasion
    - attack.t1564.001
    - analytic.an0091
    - detection.det0032
```

Rule 2 of 2: Alternate Data Stream (ADS) File Creation (File Event)
```yaml

id: a93fdf91-cb32-4e9b-8fbf-40df22336a18

    category: file_event
    product: windows
    # Relies on Sysmon Event ID 11

    selection_ads:
        TargetFilename|contains:
            - '.exe:'
            - '.dll:'
            - '.bat:'
            - '.cmd:'
            - '.vbs:'
            - '.vbe:'
            - '.js:'
            - '.jse:'
            - '.ps1:'
            - '.lnk:'
            - '.sct:'
            - '.hta:'
            - ':$DATA'
    filter_zone:
        TargetFilename|contains: ':Zone.Identifier'
    condition: selection_ads and not filter_zone
fields:
    - Image
    - TargetFilename
    - User
falsepositives:
    - Legitimate software installers or applications using ADS for database storage or metadata (excluding Zone.Identifier).
level: high
tags:
    - attack.defense-evasion
    - attack.t1564.001
    - analytic.an0091
    - detection.det0032
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Dotfile Conventions Creating Noise
  * The Issue: Many legitimate developer tools (git, Node.js, Python, VS Code) create hidden directories (.git, .vscode, .npm) using attrib +H or the hidden attribute via filesystem APIs. This is especially common on systems with WSL or development environments.
  * The Fix: Scope the alert by excluding known developer tool processes (e.g., git.exe, npm.cmd, node.exe) from the attrib +H rule. Also exclude well-known hidden directory names (\.git, \.vscode, \.npm) from the alert.

* Problem 2: Alternate Data Stream (ADS) Writes Not Captured by Process Creation
  * The Issue: Writing a malicious payload into an ADS (e.g. type malware.exe > legitimate.txt:hidden) is done via redirection in cmd.exe or PowerShell and may not clearly show the ADS destination in the command line. Sysmon Event ID 11 with ADS stream notation in the filename is the proper detector.
  * The Fix: Supplement this rule with a Sysmon file event rule that alerts on TargetFilename containing : in a non-drive-letter position (indicating an ADS write), particularly for executable file extensions within the stream.

* Problem 3: Native API Hidden Attribute Setting
  * The Issue: Malware can call SetFileAttributes() directly using Win32 API without spawning attrib.exe, making process-based detection insufficient.
  * The Fix: Use EDR solutions capable of monitoring Win32 API calls, or monitor Sysmon's file attribute change events if enabled in the Sysmon configuration for key directories (e.g., %TEMP%, %APPDATA%, C:\Windows\Temp).
