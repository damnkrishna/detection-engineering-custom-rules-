title: Microsoft Office Application Spawning Script Interpreter (AN2119)
id: f1a2b3c4-e5f6-7a8b-9c0d-1e2f3a4b5c80
status: experimental
description: "Detects command-line script interpreters or shell utilities (cmd.exe, powershell.exe, mshta.exe, wscript.exe, cscript.exe) running as child processes of Microsoft Office applications (Word, Excel, PowerPoint), which is a common indicator of remote template injection or macro-based execution."
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_parent:
        ParentImage|endswith:
            - '\winword.exe'
            - '\excel.exe'
            - '\powerpnt.exe'
            - '\outlook.exe'
    selection_child_images:
        Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\wscript.exe'
            - '\cscript.exe'
            - '\mshta.exe'
            - '\rundll32.exe'
            - '\regsvr32.exe'
    selection_child_ofn:
        OriginalFileName:
            - 'Cmd.Exe'
            - 'PowerShell.EXE'
            - 'pwsh.exe'
            - 'wscript.exe'
            - 'cscript.exe'
            - 'mshta.exe'
            - 'rundll32.exe'
            - 'regsvr32.exe'
    filter_legitimate_child:
        Image|endswith: '\rundll32.exe'
        CommandLine|contains: 'shell32.dll'
    condition: selection_parent and (selection_child_images or selection_child_ofn) and not filter_legitimate_child
fields:
    - ParentImage
    - Image
    - CommandLine
    - User
falsepositives:
    - Legitimate enterprise add-ins or custom office extensions that launch scripting interpreters to generate reports or integrate with database backends.
level: high
tags:
    - attack.defense_evasion
    - attack.t1221
    - analytic.an2119
    - detection.det0976

title: PowerShell Reflective Code Loading API Call (AN2122)
id: f1a2b3c4-e5f6-7a8b-9c0d-1e2f3a4b5c83
status: experimental
description: "Detects PowerShell execution invoking APIs used for reflective code loading (such as [System.Reflection.Assembly]::Load, Marshal.Copy, or GetDelegateForFunctionPointer) to execute payloads in memory without writing files to disk."
author: Krishna Gupta
date: 2026-07-01
logsource:
    product: windows
    service: powershell
detection:
    selection_high_signal:
        ScriptBlockText|contains:
            - 'GetDelegateForFunctionPointer'
            - 'VirtualAlloc'
    selection_medium_signal:
        ScriptBlockText|contains:
            - 'System.Reflection.Assembly'
            - 'Reflection.Assembly'
            - '[Assembly]::Load'
            - 'Marshal.Copy'
    selection_obfuscation:
        # Base64 allocations or memory streams typical of assembly loads
        ScriptBlockText|contains|all:
            - '[System.Convert]::FromBase64String'
            - 'IO.MemoryStream'
    condition: selection_high_signal or (selection_medium_signal and selection_obfuscation)
fields:
    - ScriptBlockText
    - User
    - ComputerName
falsepositives:
    - Specialized administrative scripts, deployment tools, or security agents that dynamically load modules in memory during startup or module import.
level: high
tags:
    - attack.defense_evasion
    - attack.t1620
    - analytic.an2122
    - detection.det0979

        ParentImage|endswith:

fields:

    - User
