### 1. Technique Breakdown: T1134.002

* What it is: Access Token Manipulation: Create Process with Token. Adversaries may create a new process with an elevated token to escalate privileges. They typically steal a token from a high-privilege process (like `winlogon.exe` running as `SYSTEM`) using `DuplicateTokenEx`, and then use APIs like `CreateProcessWithTokenW` or `CreateProcessAsUserW` to launch their payload (e.g., `cmd.exe`) under that duplicated, highly-privileged security context. 
* Log Source Requirements: Process creation logs (Sysmon Event ID 1 / Windows Security 4688), Windows Security Event Log (Event ID 4624 - Logon).
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES. Sysmon logs the creation of the new process. If a standard user process spawns a child process running as `SYSTEM`, it clearly indicates context switching.
    * NIDS (Suricata + Zeek): NO. Token manipulation is a local OS mechanism.

### 2. Custom Sigma Rule

```yaml
title: Privilege Escalation via CreateProcessWithToken (AN1253)
id: 962fc194-2806-4a70-8402-55b0e61e4b4d
status: experimental
description: Detects a process spawning a new process whose security context (User) differs from its parent (ParentUser), indicating token duplication/impersonation.
author: Krishna Gupta
date: 2026-06-09
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_child_user:
        User|contains: 'NT AUTHORITY\SYSTEM'
    selection_parent_user:
        ParentUser|exclude: 
            - 'NT AUTHORITY\SYSTEM'
            - 'NT AUTHORITY\NETWORK SERVICE'
            - 'NT AUTHORITY\LOCAL SERVICE'
    selection_child_image:
        Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
    filter_known_elevators:
        ParentImage|endswith:
            - '\services.exe'
            - '\svchost.exe'
            - '\winlogon.exe'
    condition: selection_child_user and selection_parent_user and selection_child_image and not filter_known_elevators
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Approved enterprise elevation solutions (e.g., CyberArk EPM, BeyondTrust).
level: critical
tags:
    - attack.privilege-escalation
    - attack.t1134.002
    - analytic.an1253
    - detection.det0456
```
