### 1. Technique Breakdown: T1546.011

* What it is: Event Triggered Execution: Application Shimming. The Microsoft Application Compatibility Infrastructure (shims) provides compatibility fixes for legacy programs. Adversaries exploit shims by creating custom shim databases (.sdb files) and installing them using the built-in command-line tool sdbinst.exe. Once registered, the compatibility database can be triggered when a specific application executes, allowing the attacker to inject malicious DLLs, bypass User Account Control (UAC), or hook APIs under a privileged execution context.
* Log Source Requirements: Endpoint logs capturing process creation events and file creation events.
* Coverage Check:
  - HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 logs the execution of sdbinst.exe. Sysmon Event ID 11 (File Create) captures the creation of .sdb files under the AppPatch directory.
  - NIDS (Suricata + Zeek): NO. Application shimming is a local OS mechanism.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Application Shim Database Installation (AN0051)
id: 19bdd3e0-ad95-40c5-9a35-ff6008893eab
status: experimental
description: Detects the execution of sdbinst.exe used to install custom application shim databases (.sdb), which can be abused for persistence and privilege escalation.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
detection:
    selection:
        - Image|endswith: '\sdbinst.exe'
        - OriginalFileName: 'sdbinst.exe'
    condition: selection
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legacy enterprise applications running compatibility compatibility shims.
level: high
tags:
    - attack.persistence
    - attack.privilege-escalation
    - attack.t1546.011
    - analytic.an0051
    - detection.det0017
```

```yaml
title: Application Shim Database File Creation (AN0051-B)
id: 0a22a0da-99b8-4ad5-b5f1-04c8cea12829
status: experimental
description: Detects creation or modification of custom shim database (.sdb) files in the AppPatch directory.
author: Krishna Gupta
date: 2026-06-17
logsource:
    category: file_event
    product: windows
detection:
    selection_path:
        TargetFilename|contains:
            - '\Windows\AppPatch\'
            - '\AppPatch\Custom\'
    selection_ext:
        TargetFilename|endswith: '.sdb'
    condition: selection_path and selection_ext
fields:
    - TargetFilename
    - Image
    - User
falsepositives:
    - Installation of compatibility databases by legitimate applications.
level: high
tags:
    - attack.persistence
    - attack.privilege-escalation
    - attack.t1546.011
    - analytic.an0051
    - detection.det0017
```
