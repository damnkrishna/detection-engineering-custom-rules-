### 1. Technique Breakdown: T1055.012

* What it is: Process Injection: Process Hollowing. Adversaries spawn a legitimate system process (e.g., `svchost.exe`, `explorer.exe`) in a suspended state using the `CREATE_SUSPENDED` flag. They then unmap (hollow out) the original code from memory using `NtUnmapViewOfSection`. Next, they allocate new memory, write their malicious payload into the hollowed process space, modify the thread context to point to the payload, and resume the thread. The malicious code now runs disguised as a trusted system binary.
* Log Source Requirements: Sysmon Event ID 1 (Process Creation), Sysmon Event ID 10 (ProcessAccess), EDR telemetry (API hooking for `NtUnmapViewOfSection`).
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES (Partial). Sysmon tracks the creation of the suspended process and the subsequent access, but cannot natively log the `NtUnmapViewOfSection` API call.
    * NIDS (Suricata + Zeek): NO. Completely in-memory local execution.

### 2. Custom Sigma Rule

```yaml
title: Suspicious Process Access indicating Process Hollowing (AN1076)
id: 7d6b030f-2465-44ef-8ee8-fe4342e00789
status: experimental
description: Detects adversary use of suspended process creation followed by memory manipulation, indicative of process hollowing.
author: Krishna Gupta
date: 2026-06-09
logsource:
    category: process_access
    product: windows
    # Relies on Sysmon Event ID 10
detection:
    selection_target:
        TargetImage|endswith:
            - '\svchost.exe'
            - '\explorer.exe'
            - '\notepad.exe'
            - '\dllhost.exe'
    selection_access:
        GrantedAccess|contains:
            - '0x1F0FFF' # All Access
            - '0x143A'
    filter_known:
        SourceImage|endswith:
            - '\MsMpEng.exe'
            - '\services.exe'
    condition: selection_target and selection_access and not filter_known
fields:
    - SourceImage
    - TargetImage
    - GrantedAccess
falsepositives:
    - Antivirus solutions sandboxing or inspecting processes.
    - Specialized enterprise application wrappers.
level: high
tags:
    - attack.privilege-escalation
    - attack.defense-evasion
    - attack.t1055.012
    - analytic.an1076
    - detection.det0382
```
