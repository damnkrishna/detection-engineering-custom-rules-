### 1. Technique Breakdown: T1055.013

* What it is: Process Injection: Process Doppelgänging. Adversaries abuse Transactional NTFS (TxF) to create a hollowed process. They create a transaction, overwrite a legitimate executable file (e.g., `svchost.exe`) with a malicious payload, create a memory section from the transacted file, and then *rollback* the transaction. The malicious file never officially touches the disk. They then use undocumented APIs like `NtCreateProcessEx` to create a process from the tainted memory section, and `NtCreateThreadEx` to execute it. This bypasses AV scanners that rely on file-to-disk callbacks.
* Log Source Requirements: EDR telemetry (API hooking for TxF functions and undocumented process creation APIs), Sysmon Event ID 1 (Process Creation).
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES (Partial). Sysmon logs the final process execution (Event ID 1), but lacks visibility into the TxF rollback and native API calls (`NtCreateProcessEx`).
    * NIDS (Suricata + Zeek): NO. Completely local filesystem and memory manipulation.

### 2. Custom Sigma Rule

```yaml
title: Suspicious Process Creation indicating Process Doppelgänging (AN1501)
id: fbbcc3f9-676b-4e6c-a8eb-8b0ab3606f1d
status: experimental
description: Detects anomalies indicative of Process Doppelgänging, such as processes executing with missing file hashes or mismatched image metadata.
author: Krishna Gupta
date: 2026-06-09
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_target:
        Image|endswith:
            - '\svchost.exe'
            - '\explorer.exe'
            - '\lsass.exe'
    selection_anomaly:
 # A missing hash in Sysmon Event ID 1 often indicates the file could not be read from disk
 # because the transaction was rolled back or locked
        Hashes: '-' 
    selection_anomaly_alt:
 # Or the process image is empty
        Image: ''
    condition: selection_target and (selection_anomaly or selection_anomaly_alt)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Extreme system load causing Sysmon hashing to time out.
    - Highly specific DRM protections.
level: critical
tags:
    - attack.privilege-escalation
    - attack.defense-evasion
    - attack.t1055.013
    - analytic.an1501
    - detection.det0544
```
