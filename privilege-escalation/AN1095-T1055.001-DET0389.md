### 1. Technique Breakdown: T1055.001

* What it is: Process Injection: Dynamic-link Library Injection. Adversaries inject a path to a malicious DLL into the memory space of a remote process and force that process to load the DLL. This is commonly done by allocating memory (`VirtualAllocEx`), writing the DLL path string (`WriteProcessMemory`), and then calling `CreateRemoteThread` passing the address of `LoadLibraryA` (or `LoadLibraryW`) as the thread's start routine. This forces the target process to load and execute the attacker's DLL.
* Log Source Requirements: Sysmon Event ID 8 (CreateRemoteThread), Sysmon Event ID 7 (Image Loaded).
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 8 captures the remote thread creation, and the `StartAddress` often points directly to `LoadLibrary`.
    * NIDS (Suricata + Zeek): NO. Local memory execution.

### 2. Custom Sigma Rule

```yaml
title: Suspicious Remote Thread Creation (LoadLibrary Injection) (AN1095)
id: ea635e81-d147-44b6-9dd0-23830fff5d8e
status: experimental
description: Detects DLL injection by monitoring CreateRemoteThread events where the StartAddress points to LoadLibrary functions.
author: Krishna Gupta
date: 2026-06-09
logsource:
    category: create_remote_thread
    product: windows
    # Relies on Sysmon Event ID 8
detection:
    selection_target:
        TargetImage|endswith:
            - '\explorer.exe'
            - '\svchost.exe'
            - '\lsass.exe'
    selection_start_function:
        StartFunction:
            - 'LoadLibraryA'
            - 'LoadLibraryW'
            - 'LoadLibraryExA'
            - 'LoadLibraryExW'
            - 'LdrLoadDll'
    filter_known:
        SourceImage|endswith:
            - '\MsMpEng.exe'
    condition: selection_target and selection_start_function and not filter_known
fields:
    - SourceImage
    - TargetImage
    - StartFunction
falsepositives:
    - EDR agents injecting introspection DLLs into processes.
    - Some legacy video game anti-cheat engines.
level: critical
tags:
    - attack.privilege-escalation
    - attack.defense-evasion
    - attack.t1055.001
    - analytic.an1095
    - detection.det0389
```
