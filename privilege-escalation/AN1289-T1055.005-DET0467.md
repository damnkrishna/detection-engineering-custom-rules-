### 1. Technique Breakdown: T1055.005

* What it is: Process Injection: Thread Local Storage. Adversaries may inject malicious code by manipulating the Thread Local Storage (TLS) callbacks of a Portable Executable (PE). Before the main entry point (`main()` or `DllMain()`) of a Windows executable is reached, the OS executes TLS callbacks to initialize thread-specific data. Attackers can hijack these callbacks in a suspended process (often combined with Process Hollowing) to execute their payload prior to the primary application logic, effectively evading security products that hook the main entry point.
* Log Source Requirements: Advanced EDR telemetry (API hooking, memory scanning), Sysmon Event ID 10 (ProcessAccess).
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES (Partial). Sysmon logs `ProcessAccess` (Event ID 10) to the target process. It does not native log PE header modifications or TLS callback executions.
    * NIDS (Suricata + Zeek): NO. Local memory execution.

### 2. Custom Sigma Rule

```yaml
title: Suspicious Process Access indicating TLS Callback Injection (AN1289)
id: 99a79616-33e1-4a73-89c9-bb09138ee7cd
status: experimental
description: Detects process access indicative of memory modifications to PE headers and TLS directory structures for injection.
author: Krishna Gupta
date: 2026-06-09
logsource:
    category: process_access
    product: windows
    # Relies on Sysmon Event ID 10
detection:
    selection_target:
        TargetImage|endswith:
            - '\svchost.exe'
            - '\explorer.exe'
            - '\dllhost.exe'
            - '\notepad.exe'
    selection_access:
        GrantedAccess|contains:
            - '0x1F0FFF' # All Access
            - '0x143A'   # VM Write
    filter_known:
        SourceImage|endswith:
            - '\MsMpEng.exe'
            - '\csrss.exe'
            - '\services.exe'
    condition: selection_target and selection_access and not filter_known
fields:
    - SourceImage
    - TargetImage
    - GrantedAccess
falsepositives:
    - Debugging software attaching to processes to read/write memory.
    - Security products scanning memory.
level: high
tags:
    - attack.privilege-escalation
    - attack.defense-evasion
    - attack.t1055.005
    - analytic.an1289
    - detection.det0467
```
