### 1. Technique Breakdown: T1055

* What it is: Process Injection. This is the parent technique for all forms of process injection. Adversaries inject malicious code into the address space of another running process. This masks the execution under a legitimate process (evading process-based detections) and may also grant access to the memory, network connections, and privileges of the target process. Methods include DLL injection, PE injection, Thread Execution Hijacking, and Process Hollowing.
* Log Source Requirements: Process creation logs (Sysmon Event ID 1), Remote Thread Creation logs (Sysmon Event ID 8), Process Access logs (Sysmon Event ID 10), Image Load logs (Sysmon Event ID 7).
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES. Sysmon Event IDs 8 and 10 provide broad, generic coverage for most forms of process injection by monitoring handles opened to remote processes and remote threads created.
    * NIDS (Suricata + Zeek): NO. Local memory manipulation.

### 2. Custom Sigma Rule

This rule utilizes Sysmon Event ID 8 (CreateRemoteThread) to generically detect the final stage of most traditional process injection techniques: creating a thread in another process.

```yaml
title: Generic Process Injection (Remote Thread Creation) (AN1399)
id: fbbcc3f9-676b-4e6c-a8eb-8b0ab3606f1d
status: experimental
description: Detects generic process injection by correlating remote thread creation (CreateRemoteThread) into common target processes.
author: Krishna Gupta
date: 2026-06-09
logsource:
    category: create_remote_thread
    product: windows
    # Relies on Sysmon Event ID 8
detection:
    selection_target:
        TargetImage|endswith:
            - '\explorer.exe'
            - '\svchost.exe'
            - '\lsass.exe'
            - '\winlogon.exe'
            - '\spoolsv.exe'
            - '\services.exe'
            - '\taskhostw.exe'
    filter_known_injectors:
        SourceImage|endswith:
            - '\MsMpEng.exe'
            - '\csrss.exe'
            - '\wbemprox.exe'
            - '\WmiPrvSE.exe'
            - '\taskmgr.exe'
    condition: selection_target and not filter_known_injectors
fields:
    - SourceImage
    - TargetImage
falsepositives:
    - Antivirus and EDR software.
    - Advanced system monitoring tools (e.g., Process Hacker, Sysinternals).
level: high
tags:
    - attack.privilege-escalation
    - attack.defense-evasion
    - attack.t1055
    - analytic.an1399
    - detection.det0508
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Administrative Action False Positives
  * The Issue: IT personnel performing legitimate maintenance operations can invoke techniques that mirror adversarial persistence or evasion.
  * The Fix: Audit and baseline corporate administration accounts, whitelisting specific approved service accounts and administrative subnets.

* Problem 2: Command and Execution Obfuscation
  * The Issue: Attackers employ encoding, environment variables, or caret insertions to bypass keyword-based detection filters.
  * The Fix: Enable deep logging (such as Script Block Logging) and apply normalization or regex decoding inside the SIEM parsing pipeline.

* Problem 3: Log Deletion and Modification
  * The Issue: Adversaries can clear security logs or stop monitoring agents (like Wazuh or Sysmon) to blind defensive operations.
  * The Fix: Forward all endpoint logs immediately to a centralized write-once SIEM and alert on service stoppage or log clearing events.
