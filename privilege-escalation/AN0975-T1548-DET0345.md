### 1. Technique Breakdown: T1548

* What it is: Abuse Elevation Control Mechanism. User Account Control (UAC) is a key Windows security feature that limits application privileges to standard user levels until an administrator authorizes an elevation. Adversaries bypass UAC by hijacking auto-elevated system binaries or hijacking COM objects and Registry paths to execute command payloads at High Integrity without triggering consent dialogs.
* Log Source Requirements: Endpoint logs capturing process creation events and registry modification events.
* Coverage Check:
  - HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 captures parent process paths, target process paths, and command-line arguments. Sysmon Event ID 13 captures direct registry writes targeting bypass keys.
  - NIDS (Suricata + Zeek): NO. Elevation of privileges is entirely a local operating system event.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 13 (registry_set)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

The detection logic is split into process creation monitoring of auto-elevated parent processes spawning shell interpreters, and registry modifications targeting command override paths.

Rule 1 of 2: Abuse of UAC Elevation Control Mechanisms (Process Creation)
```yaml
title: Abuse of UAC Elevation Control Mechanisms (AN0975)
id: 6a088cec-84e0-4bfe-aedf-a07307bcccba
status: experimental
description: Detects bypass of User Account Control (UAC) by monitoring auto-elevating Windows binaries spawning shell utilities.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
detection:
    selection_parent:
        ParentImage|endswith:
            - '\control.exe'
            - '\sdclt.exe'
            - '\fodhelper.exe'
            - '\eventvwr.exe'
            - '\computerdefaults.exe'
        Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\wscript.exe'
            - '\cscript.exe'
    condition: selection_parent
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Administrative maintenance or backup tools using auto-elevating scripts.
level: high
tags:
    - attack.privilege-escalation
    - attack.defense-evasion
    - attack.t1548
    - analytic.an0975
    - detection.det0345
```

Rule 2 of 2: UAC Bypass Registry Key Modification (Registry Set)
```yaml
title: UAC Bypass Registry Key Modification (AN0975-B)
id: 8cc39a60-47b2-4ded-b2ba-7797ea3f63a6
status: experimental
description: Detects registry modifications to command overrides under the User classes hive used in UAC bypass methods.
author: Krishna Gupta
date: 2026-06-17
logsource:
    category: registry_set
    product: windows
detection:
    selection_registry:
        TargetObject|contains:
            - '\Software\Classes\ms-settings\shell\open\command'
            - '\Software\Classes\mscfile\shell\open\command'
            - '\Software\Classes\exefile\shell\runas\command'
    condition: selection_registry
fields:
    - TargetObject
    - Image
    - User
    - Details
falsepositives:
    - Legitimate installers registering shell commands under standard file associations.
level: high
tags:
    - attack.privilege-escalation
    - attack.defense-evasion
    - attack.t1548
    - analytic.an0975
    - detection.det0345
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Command Line Obfuscation
  - The Issue: Adversaries can obfuscate command-line arguments using environment variables.
  - The Fix: Implement PowerShell Script Block Logging.

* Problem 2: Administrative Activity Noise
  - The Issue: IT administrators legitimately run setup routines that invoke elevated tasks.
  - The Fix: Establish a baseline of approved management servers and accounts.

* Problem 3: Masquerading via Renamed Binaries
  - The Issue: Attackers rename native shell utilities to bypass filters.
  - The Fix: Incorporate Masquerade-resistant criteria, matching on OriginalFileName.
