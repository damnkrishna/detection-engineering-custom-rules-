### 1. Technique Breakdown: T1134.001

* What it is: Access Token Manipulation: Token Impersonation/Theft. Adversaries duplicate an access token belonging to a highly privileged user (like `SYSTEM` or an administrator) and impersonate that user. This is often accomplished using Windows APIs like `DuplicateToken`, `DuplicateTokenEx`, `ImpersonateLoggedOnUser`, or `SetThreadToken`. This allows a standard process or thread to execute actions with the permissions of the stolen token without needing the user's password.
* Log Source Requirements: Process creation logs (Sysmon Event ID 1), Windows Security Event Log (Event ID 4624 - Logon, Event ID 4672 - Special Privileges Assigned).
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES (Partial). Sysmon tracks command-line utilities (like `runas`) that perform impersonation natively. However, API-level impersonation is best caught via Windows Security Event Logs.
    * NIDS (Suricata + Zeek): NO. Token impersonation happens entirely within the local OS kernel.

### 2. Custom Sigma Rule

```yaml
title: Token Impersonation / Theft (AN1324)
id: 83e0f115-525d-4bf4-8f60-88d93dc4d6d8
status: experimental
description: Detects token duplication and impersonation attempts by correlating suspicious command-line executions (e.g., runas) or anomalous NewCredentials logons.
author: Krishna Gupta
date: 2026-06-09
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_runas:
        Image|endswith: '\runas.exe'
    selection_args:
        CommandLine|contains:
            - '/savecred'
            - '/user:NT AUTHORITY\SYSTEM'
            - '/user:Administrator'
    filter_known:
        ParentImage|endswith:
            - '\explorer.exe' # Legitimate user typing runas
    condition: selection_runas and selection_args and not filter_known
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - System administrators running scripts that explicitly elevate via runas.
level: high
tags:
    - attack.privilege-escalation
    - attack.t1134.001
    - analytic.an1324
    - detection.det0482
```
