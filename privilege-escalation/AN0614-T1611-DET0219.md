### 1. Technique Breakdown: T1611

* What it is: Escape to Host. Adversaries may break out of a container to gain access to the underlying host. This can involve exploiting vulnerabilities in the container runtime, abusing excessive privileges, or mounting host file systems inside the container.
* Log Source Requirements: Linux Audit logs (auditd) or eBPF-based container security tools, which are not allowed log sources.
* Coverage Check:
  * HIDS (Sysmon + Windows Defender): NO. Standard Windows Sysmon and Defender logs do not monitor Linux container environments or container runtime socket modifications.
  * Windows Security Logs: NO. Standard Windows Security Logs (service: security) have zero visibility into Linux hosts or container engine escape attempts.
* Conclusion: This technique is not detectable from Sysmon, Windows Security, or Defender logs.
