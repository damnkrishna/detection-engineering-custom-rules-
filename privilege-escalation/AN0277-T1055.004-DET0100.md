### 1. Technique Breakdown: T1055.004

* What it is: Process Injection: Asynchronous Procedure Call (APC). Adversaries may inject malicious code into a legitimate process by attaching the code to the APC queue of a thread within that process. When the thread enters an alterable state, it executes the queued APC (the malicious payload). This is often achieved via `QueueUserAPC` or `NtQueueApcThread` APIs.
* Log Source Requirements: Sysmon Event ID 8 (CreateRemoteThread), Sysmon Event ID 10 (ProcessAccess), or EDR memory telemetry.
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES (Partial). Sysmon does not natively log `QueueUserAPC` directly. However, it logs `ProcessAccess` (Event ID 10) when the injecting process opens a handle to the target, and `CreateRemoteThread` (Event ID 8) if a thread is explicitly created.
    * NIDS (Suricata + Zeek): NO. Memory injection is strictly a local host activity.

### 2. Custom Sigma Rule

```yaml
title: Suspicious Process Access for Memory Injection (AN0277)
id: 0dcee7e8-4177-4961-bed8-bded28a68f66
status: experimental
description: Detects malicious injection behavior involving memory allocation and altered thread context by monitoring suspicious ProcessAccess requests (e.g., 0x1F0FFF or specific VM Write access) to common target processes.
author: Krishna Gupta
date: 2026-06-09
logsource:
    category: process_access
    product: windows
    # Relies on Sysmon Event ID 10
detection:
    selection_access:
 # 0x1F0FFF is PROCESS_ALL_ACCESS
 # 0x1438 is PROCESS_VM_OPERATION | PROCESS_VM_READ | PROCESS_VM_WRITE | PROCESS_QUERY_INFORMATION
        GrantedAccess:
            - '0x1f0fff'
            - '0x1438'
            - '0x143a'
    selection_targets:
        TargetImage|endswith:
            - '\explorer.exe'
            - '\svchost.exe'
            - '\lsass.exe'
            - '\winlogon.exe'
            - '\spoolsv.exe'
    filter_known_apps:
        SourceImage|endswith:
            - '\MsMpEng.exe' # Windows Defender
            - '\taskmgr.exe'
    condition: selection_access and selection_targets and not filter_known_apps
fields:
    - SourceImage
    - TargetImage
    - GrantedAccess
falsepositives:
    - Legitimate debugging tools or EDR agents opening processes with high privileges.
    - Software installers injecting helper DLLs into explorer.exe.
level: high
tags:
    - attack.privilege-escalation
    - attack.defense-evasion
    - attack.t1055.004
    - analytic.an0277
    - detection.det0100
```
