### 1. Technique Breakdown: T1105

* What it is: Ingress Tool Transfer. Adversaries transfer files (tools, exploits, payloads, or scripts) from external systems into a compromised corporate host. They abuse native Windows utilities (LOLBins) like certutil.exe, bitsadmin.exe, curl.exe, or scripting environments like PowerShell to connect to their external infrastructure and download malicious files onto the filesystem.
* Log Source Requirements: Host process creation and command line logs (Sysmon Event ID 1 / Windows Security Event ID 4688), PowerShell Script Block Logs (Event ID 4104), and Network Connection logs (Sysmon Event ID 3).
* Coverage Check:
    * HIDS (Sysmon + Windows Defender): YES. Sysmon Event ID 1 captures command lines. Event ID 4104 captures PowerShell scripts. Event ID 3 captures network activity.
    * Windows Security Logs: PARTIAL. Security logs EID 4688 captures command lines if enabled.
* Log Sources Covered:
    - Sysmon Event ID 1 (process_creation)
    - PowerShell Event ID 4104 (ps_script)
    - Sysmon Event ID 3 (network_connection)
* Log Sources Missing / Unused:
    - None.

### 2. Custom Sigma Rule

```yaml
title: Ingress Tool Transfer via CLI (AN0165-A)
id: 5582cab9-6beb-4350-93bd-3c30186bb094
status: experimental
description: Detects command-line execution of tools (like certutil, bitsadmin, curl, or powershell) performing ingress tool transfers from external locations.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_certutil:
        - Image|endswith: '\certutil.exe'
        - OriginalFileName: 'certutil.exe'
    selection_certutil_args:
        CommandLine|contains:
            - 'urlcache'
            - 'split'
    selection_bitsadmin:
        - Image|endswith: '\bitsadmin.exe'
        - OriginalFileName: 'bitsadmin.exe'
    selection_bitsadmin_args:
        CommandLine|contains:
            - 'transfer'
            - 'download'
    selection_curl:
        - Image|endswith:
            - '\curl.exe'
            - '\wget.exe'
        - OriginalFileName:
            - 'curl.exe'
            - 'wget.exe'
    selection_curl_args:
        CommandLine|contains:
            - 'http://'
            - 'https://'
    selection_powershell:
        - Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
        - OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.dll'
    selection_powershell_args:
        CommandLine|contains:
            - 'DownloadFile'
            - 'DownloadString'
            - 'Invoke-WebRequest'
            - 'iwr'
            - 'wget'
            - 'curl'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: ((selection_certutil and selection_certutil_args) or (selection_bitsadmin and selection_bitsadmin_args) or (selection_curl and selection_curl_args) or (selection_powershell and selection_powershell_args)) and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate administration scripts downloading program updates or installing software dependencies.
level: high
tags:
    - attack.command-and-control
    - attack.t1105
    - analytic.an0165
    - detection.det0060
```
