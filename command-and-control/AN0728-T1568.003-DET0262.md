### 1. Technique Breakdown: T1568.003

* What it is: Dynamic Resolution: DNS Calculation. Adversaries derive dynamic command and control ports or IPs mathematically from DNS queries. This is often done by querying DNS TXT records, which can contain base64 encoded payloads or configuration data, or using specific octets from a resolved IP address to determine a custom port number for the subsequent C2 socket connection.
* Log Source Requirements: Host process creation and command line logs (Sysmon Event ID 1 / Windows Security Event ID 4688) and PowerShell Script Block Logs (Event ID 4104).
* Coverage Check:
    * HIDS (Sysmon + Windows Defender): YES. Sysmon Event ID 1 captures execution of nslookup or dig. Event ID 4104 captures PowerShell script blocks querying TXT records.
    * Windows Security Logs: PARTIAL. Security logs EID 4688 captures command lines if enabled.
* Log Sources Covered:
    - PowerShell Event ID 4104 (ps_script)
    - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
    - None.

### 2. Custom Sigma Rule

```yaml
title: DNS TXT Query via PowerShell Script Block (AN0728-A)
id: f5407a8c-611e-46eb-9f9d-3978490e16ef
status: experimental
description: Detects PowerShell script blocks invoking DNS queries for TXT records, which can indicate dynamic resolution or C2 configuration retrieval.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: ps_script
    product: windows
    # Relies on PowerShell Script Block Logging (Event ID 4104)
detection:
    selection_keywords:
        ScriptBlockText|contains:
            - 'Resolve-DnsName'
            - '[System.Net.Dns]'
            - 'GetHostAddresses'
    selection_txt:
        ScriptBlockText|contains:
            - 'TXT'
            - '16'
    condition: selection_keywords and selection_txt
fields:
    - ScriptBlockText
falsepositives:
    - Legitimate administrative script tasks auditing DNS SPF/TXT records.
level: high
tags:
    - attack.command-and-control
    - attack.t1568.003
    - analytic.an0728
    - detection.det0262
```

```yaml
title: DNS TXT Query via CLI (AN0728-B)
id: 40d64d05-dfe6-405f-b319-d6e87e024dfb
status: experimental
description: Detects command line execution of utilities querying DNS TXT records, indicating dynamic C2 calculation attempts.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_process:
        - Image|endswith:
            - '\nslookup.exe'
            - '\dig.exe'
            - '\host.exe'
        - OriginalFileName:
            - 'nslookup.exe'
            - 'dig.exe'
    selection_args:
        CommandLine|contains:
            - 'txt'
            - 'type=txt'
            - '-query=txt'
    condition: selection_process and selection_args
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - System administrators performing manual DNS checks or SPF queries.
level: high
tags:
    - attack.command-and-control
    - attack.t1568.003
    - analytic.an0728
    - detection.det0262
```
