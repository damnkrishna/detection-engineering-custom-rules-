### 1. Technique Breakdown: T1132

* What it is: Data Encoding. Adversaries may encode data (e.g., using Base64, Hexadecimal, or custom schemes) to obscure payload delivery or command and control traffic. This helps evade basic content filters or signature-based intrusion detection systems. Detecting the CLI execution of command parameters that invoke encoding functions (such as PowerShell base64/hex conversions) helps flag these obfuscation attempts.
* Log Source Requirements:
  * Sysmon Process Creation (Event ID 1) capturing process command-lines containing explicit data encoding/decoding keywords.
* Coverage Check:
  * HIDS (Sysmon): YES. Processes run with encoding/decoding arguments leave command-line logs.
  * NIDS (Zeek/Suricata): PARTIAL. Network logs can capture encoded payloads, but endpoint rules correlate the action to specific local processes.
* Log Sources Covered:
  * Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  * None.

### 2. Custom Sigma Rule

The following rule monitors the command line parameters of shell hosts and scripting utilities for operations executing explicit base64, hexadecimal, or custom conversions.

```yaml
title: Process Command Line Data Encoding or Decoding Activity (AN2116)
id: d4e5f6a7-b8c9-4d0e-9f0a-1b2c3d4e5f95
status: experimental
description: "Detects process command-line parameters indicating the execution of data encoding or decoding operations (e.g., PowerShell conversion classes, certutil hex transformations, or base64 decoding utilities) commonly used to mask payload execution or exfiltration streams."
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\cmd.exe'
            - '\certutil.exe'
            - '\wscript.exe'
            - '\cscript.exe'
    selection_ofn:
        OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.exe'
            - 'Cmd.Exe'
            - 'certutil.exe'
            - 'wscript.exe'
            - 'cscript.exe'
    selection_cli:
        CommandLine|contains:
            - 'FromBase64String'
            - 'ToBase64String'
            - '[System.Convert]'
            - '-encodehex'
            - '-decodehex'
            - 'base64 -d'
            - 'base64 --decode'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_images or selection_ofn) and selection_cli and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - Legitimate administrative scripts or software installation tools that decode configuration values or license keys from base64 or hex during setup.
level: medium
tags:
    - attack.command-and-control
    - attack.t1132
    - analytic.an2116
    - detection.det0973
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Obfuscation inside script blocks
  * The Issue: If the script is obfuscated and constructs the base64 conversion strings dynamically at runtime (e.g., using string concatenation or character arrays), the literal keywords like `FromBase64String` will not appear in the initial process creation command line.
  * The Fix: Enable PowerShell Script Block Logging (Event ID 4104) and look for script block telemetry after runtime deobfuscation has occurred.
* Problem 2: Standard application setup false positives
  * The Issue: Certain installers (like Microsoft SQL server or exchange agents) run setup cmdlets that legitimately use base64 conversions, causing noise.
  * The Fix: Whitelist known administrative parent processes or specific installer directories (e.g. `C:\Windows\Temp\`).
* Problem 3: Custom XOR encoding
  * The Issue: If the attacker uses simple custom XOR loops or bit-shifting instead of standard Base64/Hex classes, the keywords in `selection_cli` will not trigger.
  * The Fix: Monitor for anomalous network payloads or process memory access behaviors.
