### 1. Technique Breakdown: T1092

* What it is: Communication Through Removable Media. Adversaries may use removable media (such as USB drives) to transfer data, drop commands, or execute malicious payloads on air-gapped systems or heavily restricted network segments. This is detected by monitoring the execution of interpreters or binary payloads launched from removable disk volumes.
* Log Source Requirements:
  * Sysmon Process Creation (Event ID 1) to audit command-line paths and binary directories on non-system drives.
* Coverage Check:
  * HIDS (Sysmon): YES. Processes launched from non-standard partitions or USB drive letters generate process creation logs.
  * NIDS (Zeek/Suricata): NO. USB execution is entirely local to the host.
* Log Sources Covered:
  * Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  * None.

### 2. Custom Sigma Rule

```yaml
title: Script or Binary Execution from Removable Media Path (AN2113)
id: d4e5f6a7-b8c9-4d0e-9f0a-1b2c3d4e5f90
status: experimental
description: "Detects the execution of scripting interpreters (PowerShell, CMD, WScript, CScript) or executable binaries located on removable drive paths (such as D:\\ through Z:\\), which is a common indicator of adversaries running payloads or transferring files from physical media on air-gapped systems."
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_interpreters:
        Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\cmd.exe'
            - '\wscript.exe'
            - '\cscript.exe'
            - '\mshta.exe'
    selection_interpreters_ofn:
        OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.exe'
            - 'Cmd.Exe'
            - 'wscript.exe'
            - 'cscript.exe'
            - 'mshta.exe'
    selection_removable_cli:
        CommandLine|re:
            - '(?i)\s+[D-Z]:\\(?!Program Files|Windows)'
    selection_direct_exec:
        Image|re: '(?i)^[D-Z]:\\(?!Program Files|Windows).+\.exe'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (((selection_interpreters or selection_interpreters_ofn) and selection_removable_cli) or selection_direct_exec) and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - User
falsepositives:
    - IT administrators running scripts or installing tools from a mounted network drive or secondary partition that is assigned a drive letter between D and Z.
    - Standard software installers that extract to or run from secondary volumes.
level: medium
tags:
    - attack.command-and-control
    - attack.t1092
    - analytic.an2113
    - detection.det0970
```

### 3. OCSF Normalized Rule

```yaml
title: 'Script or Binary Execution from Removable Media Path (AN2113) (OCSF-Normalized)'
id: 'd4e5f6a7-b8c9-4d0e-9f0a-1b2c3d4e5f90'
status: experimental
description: 'OCSF Normalized rule for Script or Binary Execution from Removable Media Path (AN2113)'
author: Krishna Gupta
logsource:
    product: ocsf
    class: process_activity
detection:
    selection_interpreters:
        process.file.path|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\cmd.exe'
            - '\wscript.exe'
            - '\cscript.exe'
            - '\mshta.exe'
    selection_interpreters_ofn:
        process.file.name:
            - 'PowerShell.EXE'
            - 'pwsh.exe'
            - 'Cmd.Exe'
            - 'wscript.exe'
            - 'cscript.exe'
            - 'mshta.exe'
    selection_removable_cli:
        process.cmd_line|re:
            - '(?i)\s+[D-Z]:\\(?!Program Files|Windows)'
    selection_direct_exec:
        process.file.path|re: '(?i)^[D-Z]:\\(?!Program Files|Windows).+\.exe'
    filter_installer:
        unmapped.parent_image|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (((selection_interpreters or selection_interpreters_ofn) and selection_removable_cli) or selection_direct_exec) and not filter_installer
fields:
    - time
level: high
tags:
    - attack.command-and-control
    - attack.t1092
    - analytic.an2113
    - detection.det0970
```
