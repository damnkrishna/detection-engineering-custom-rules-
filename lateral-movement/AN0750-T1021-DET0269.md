### 1. Technique Breakdown: T1021

* What it is: Remote Services. Adversaries leverage valid credentials to log in remotely to endpoints over Windows admin interfaces (like SMB, WMI, or WinRM). Once authenticated via a network logon (Logon Type 3), they perform administrative or execution commands (such as registering services, launching scheduled tasks, or modifying registry persistence) to establish a foothold or run commands.
* Log Source Requirements: Windows Security Event Log Event ID 4624 (Successful Logon) and Sysmon process creation logs (Event ID 1) containing Logon ID context.
* Coverage Check:
  * HIDS (Sysmon + Wazuh): YES. Security Event ID 4624 captures successful network logons (Type 3) and records the Logon ID. Sysmon Event ID 1 logs process creation events and links them to the initiating Logon ID.
  * NIDS (Suricata + Zeek): YES. Network logs track SMB/RPC connection setups, but endpoint logging is required to identify the post-access process executions.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Windows Security Log Event ID 4624 (security)
* Log Sources Missing / Unused:
  - None.
* Conclusion: Remote service logins and subsequent executions can be detected using process creation and security logs.

### 2. Custom Sigma Rule

```yaml
title: Lateral Movement - Post-Logon Administrative Process Execution (AN0750)
id: 295b1f0e-d6a4-45ef-ac1e-627aa4c20d04
status: experimental
description: Detects command-line interpreters or administrative utilities executing within a Network Logon session (Type 3, excluding SYSTEM sessions), suggesting remote execution via SMB, WMI, or WinRM.
author: Krishna Gupta
date: 2026-06-08
logsource:
    category: process_creation
    product: windows
detection:
    selection_session:
        LogonId|not: '0x3e7' # Exclude standard local SYSTEM session
    selection_executables:
        - Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\sc.exe'
            - '\reg.exe'
            - '\schtasks.exe'
            - '\wmic.exe'
            - '\net.exe'
            - '\net1.exe'
        - OriginalFileName:
            - 'Cmd.Exe'
            - 'PowerShell.EXE'
            - 'sc.exe'
            - 'reg.exe'
            - 'schtasks.exe'
            - 'wmic.exe'
            - 'net.exe'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: selection_session and selection_executables and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate administrative tasks executed remotely using WinRM/WMI script engines by IT engineers.
    - Automated endpoint management software running scheduled tasks under domain admin contexts.
level: medium
tags:
    - attack.lateral-movement
    - attack.t1021
    - analytic.an0750
    - detection.det0269
```

```yaml
title: Remote Logon Session Creation (AN0750-B)
id: f3e873f5-cc2a-41c8-9941-3f4d1f512d9c
status: experimental
description: Detects successful remote network logons (Type 3) or remote interactive RDP logons (Type 10) by administrative or non-standard accounts, suggesting lateral movement.
author: Krishna Gupta
date: 2026-06-16

    service: security
    product: windows
detection:
    selection_eid:
        EventID: 4624
    selection_logon_type:
        LogonType:
            - 3
            - 10
    filter_machine:
        TargetUserName|endswith: '$'
    filter_system:
        TargetUserName:
            - 'ANONYMOUS LOGON'
            - 'SYSTEM'
    condition: selection_eid and selection_logon_type and not (filter_machine or filter_system)
fields:
    - EventID
    - LogonType
    - TargetUserName
    - TargetDomainName
    - IpAddress
falsepositives:
    - Legitimate administrative remote access and script automation.
level: medium
tags:
    - attack.lateral-movement
    - attack.t1021
    - analytic.an0750
    - detection.det0269
```
