### 1. Technique Breakdown: T1498

* What it is: Network Denial of Service. Adversaries execute scripts or customized network stress engines on compromised endpoints to perform network flooding (e.g. UDP, TCP SYN, Slowloris HTTP floods) against external or internal target systems.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Flood utility executions and specific script command-line arguments are captured.
  - NIDS (Suricata + Zeek): YES. Flooding packets are highly visible at the network boundary.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Denial of Service Script Engine Execution (AN1434-A)
id: 50eb0b67-9e94-43a7-8e49-e5f31ae7ab6d
status: experimental
description: Detects command-line execution of Python, PowerShell, or Perl interpreters targeting network flooding or DoS attacks.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\python.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\perl.exe'
            - '\go.exe'
    selection_cli:
        CommandLine|contains:
            - 'slowloris'
            - 'goldeneye'
            - 'hulk.py'
            - 'rudy.py'
            - 'syn-flood'
            - 'udp-flood'
            - 'ping-of-death'
    condition: selection_images and selection_cli
fields:
    - Image
    - CommandLine
    - User
falsepositives:
    - Internal network security team running approved stress tests or load capability checks.
level: high
tags:
    - attack.impact
    - attack.t1498
    - analytic.an1434
    - detection.det0518
```
