### 1. Technique Breakdown: T1495

* What it is: Firmware Corruption. Adversaries modify or corrupt system firmware (such as UEFI, BIOS, or hard drive controller firmware) to make the target system completely inoperable and brick the hardware. In Windows environments, firmware or boot sequence tampering is preceded by command-line execution of tools like bcdedit.exe to modify the Boot Configuration Data (BCD) store, disabling boot recovery menus (recoveryenabled No) or configuring the OS to ignore boot failures (bootstatuspolicy ignoreallfailures), preventing recovery.
* Log Source Requirements: Host process creation and command line logs (Sysmon Event ID 1 / Windows Security Event ID 4688) tracking execution, and PowerShell script block logs (Sysmon Event ID 4104).
* Coverage Check:
  * HIDS (Sysmon + Windows Defender): YES. Sysmon Event ID 1 captures bcdedit.exe executions with full command parameters. Sysmon Event ID 4104 (Script Block) captures scripts modifying boot loader properties.
  * Windows Security Logs: YES. Standard Security Logs track process execution (Event ID 4688) containing the command line arguments.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 4104 (ps_script)
* Log Sources Missing / Unused:
  - None.
* Conclusion: Boot configuration tampering can be detected using process creation and PowerShell script block logs.

### 2. Custom Sigma Rule

```yaml
title: Boot Configuration Tampering via CLI (AN0474-A)
id: ef6c5af9-ea40-4ebc-bce7-c278e4e4caa4
status: experimental
description: Detects command-line modifications using bcdedit.exe to disable boot recovery options, disable safe boot configurations, or set anomalous boot configurations, which is typical of destructive ransomware and system disruption.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
detection:
    selection_bcdedit:
        - Image|endswith: '\bcdedit.exe'
        - OriginalFileName: 'bcdedit.exe'
    selection_bcdedit_cmds:
        CommandLine|contains:
            - '/set'
            - '/deletevalue'
    selection_bcdedit_targets:
        CommandLine|contains:
            - 'recoveryenabled'
            - 'bootstatuspolicy'
            - 'ignoreallfailures'
            - 'safeboot'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: selection_bcdedit and selection_bcdedit_cmds and selection_bcdedit_targets and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - IT administrators configuring boot options during OS installation or system maintenance.
level: high
tags:
    - attack.impact
    - attack.t1495
    - analytic.an0474
    - detection.det0167
```

```yaml
title: Boot Configuration Tampering via PowerShell Script Block (AN0474-B)
id: 2c460dad-d47c-4c3c-b473-021f744a37c1
status: experimental
description: Detects PowerShell script block logs containing commands attempting to modify Windows Boot Configuration Data (BCD).
author: Krishna Gupta
date: 2026-06-16

    selection_keywords:
        ScriptBlockText|contains:
            - 'bcdedit'

            - 'bootstatuspolicy'
            - 'ignoreallfailures'

fields:
    - ScriptBlockText
falsepositives:
    - Legitimate administrative scripts or maintenance tools configuring boot settings.
level: high
tags:
    - attack.impact
    - attack.t1495
    - analytic.an0474
    - detection.det0167
```
