### 1. Technique Breakdown: T1498.002

* What it is: Network Denial of Service: Reflection Amplification. Adversaries abuse misconfigured internet services (like DNS, NTP, SNMP, Memcached) to reflect and amplify traffic toward a target. To execute this from a compromised host, the adversary sends rapid request packets spoofing the target's IP address, or uses scripts to trigger high-rate queries targeting known reflective nodes.
* Log Source Requirements: Sysmon Network Connection events (Event ID 3) and Sysmon Process Creation events (Event ID 1).
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Outbound connection rates and interpreter processes are monitored.
  - NIDS (Suricata + Zeek): YES. Amplified outbound traffic on ports 53/123/161 can be seen at network egress checkpoints.
* Log Sources Covered:
  - Sysmon Event ID 3 (network_connection)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Scripting Process Outbound DNS or NTP Connection Burst (AN1140-A)
id: f6c5baf9-4e78-45dd-ae44-edb7a9123942
status: experimental
description: Detects scripting interpreters initiating connection bursts to DNS or NTP ports. Pair with SIEM-side volume aggregation.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: network_connection
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\python.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\cmd.exe'
            - '\wscript.exe'
            - '\cscript.exe'
    selection_ports:
        DestinationPort:
            - 53
            - 123
    filter_internal:
        # Exclude internal servers and local resolvers
        DestinationIp|startswith:
            - '127.'
            - '10.'
            - '192.168.'
            - '172.16.'
    condition: selection_images and selection_ports and not filter_internal
fields:
    - Image
    - DestinationIp
    - DestinationPort
    - User
falsepositives:
    - Legitimate administration scripts checking time servers or resolving APIs.
level: medium
tags:
    - attack.impact
    - attack.t1498.002
    - analytic.an1140
    - detection.det0408
```

```yaml
title: Outbound Connections to Amplification Ports (AN1140-B)
id: 454c6183-48a4-44de-a265-6bd9b0cf49e8
status: experimental
description: Detects outbound traffic targeting known reflection/amplification ports.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: network_connection
    product: windows
detection:
    selection_ports:
        DestinationPort:
            - 11211
            - 1900
            - 161
    filter_system:
        # Exclude standard SNMP and local SSDP discovery engines
        Image|endswith:
            - '\system32\svchost.exe'
            - '\system32\snmp.exe'
    filter_browsers:
        Image|endswith:
            - '\chrome.exe'
            - '\firefox.exe'
    filter_multicast:
        # Exclude local subnet multicast and broadcast SSDP traffic
        DestinationIp|startswith:
            - '224.'
            - '239.'
            - '255.255.255.255'
            - 'ff'
    condition: selection_ports and not (filter_system or filter_browsers or filter_multicast)
fields:
    - Image
    - DestinationIp
    - DestinationPort
    - User
falsepositives:
    - Legitimate SNMP network polling tools or media discovery agents.
level: medium
tags:
    - attack.impact
    - attack.t1498.002
    - analytic.an1140
    - detection.det0408
```
