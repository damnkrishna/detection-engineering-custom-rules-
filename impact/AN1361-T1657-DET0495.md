### 1. Technique Breakdown: T1657

* What it is: Financial Theft. Adversaries target retail endpoints, Point of Sale (POS) terminals, or billing servers to tamper with database transaction tables, modify accounting settings, or scrape credit card data from RAM, resulting in financial loss.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688, and Sysmon File Creation/Modification events (Event ID 11).
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Scraping tools and database file writes are tracked.
  - NIDS (Suricata + Zeek): NO. Host-local application manipulation.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Point-of-Sale RAM Scraper Process Creation (AN1361-A)
id: ef0bf063-3aef-4545-9ac0-9573ce1caae9
status: experimental
description: Detects command-line execution of Point-of-Sale memory scrapers or tools scanning memory handles.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\alina.exe'
            - '\dexter.exe'
            - '\blackpos.exe'
            - '\poscard.exe'
            - '\memdump.exe'
    selection_orig:
        OriginalFileName:
            - 'alina.exe'
            - 'dexter.exe'
            - 'blackpos.exe'
            - 'poscard.exe'
            - 'memdump.exe'
    selection_cli:
        CommandLine|contains:
            - 'pos-scrape'
            - 'card-grab'
            - 'track2'
            - 'dump-ram'
    filter_installers:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_images or selection_orig) and selection_cli and not filter_installers
fields:
    - Image
    - CommandLine
    - User
falsepositives:
    - Diagnostic tools or memory debuggers run by retail application support teams during maintenance.
level: critical
tags:
    - attack.impact
    - attack.t1657
    - analytic.an1361
    - detection.det0495
```

```yaml
title: Transaction Database File Manipulation (AN1361-B)
id: 61af82bd-f469-431b-8f90-e47f071797d5
status: experimental
description: Detects direct file writes or modifications to POS database files by interpreters or non-db binaries.
author: Krishna Gupta
date: 2026-06-30

    category: file_event
    product: windows
detection:
    selection_paths:
        TargetFilename|contains:
            - '\pos_db\'
            - '\retail_sales\'
            - '\checkout_data\'
    selection_exts:
        TargetFilename|endswith:
            - '.mdf'
            - '.ldf'
            - '.db'
            - '.sqlite'
    filter_db_processes:
        Image|endswith:
            - '\sqlserver.exe'
            - '\mysqld.exe'
            - '\postgres.exe'
            - '\pos_service.exe'
    condition: selection_paths and selection_exts and not filter_db_processes
fields:
    - TargetFilename
    - Image
    - User
falsepositives:
    - Standard checkout terminal patches or software migrations updating db structures.
level: high
tags:
    - attack.impact
    - attack.t1657
    - analytic.an1361
    - detection.det0495
```
