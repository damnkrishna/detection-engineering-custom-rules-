### 1. Technique Breakdown: T1499.003

* What it is: Endpoint Denial of Service: Application Exhaustion Flood. Adversaries target application services (such as web servers, database endpoints, or custom enterprise APIs) with high-rate connection requests to consume execution threads, socket tables, or CPU.
* Log Source Requirements: Sysmon Network Connection events (Event ID 3) / Web Server Logs.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. High volume connections to local listening application ports can be captured by local endpoint network logs.
  - NIDS (Suricata + Zeek): YES. Rapid connection attempts targeting application ports are highly visible on network interfaces.
* Log Sources Covered:
  - Sysmon Event ID 3 (network_connection)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: High Connection Burst to Web Server Port (AN1165-A)
id: 03ca01d6-59cd-4a04-8e77-b27321c61bda
status: experimental
description: Detects process connections targeting web ports. Pair with SIEM-side volume checks to detect flood attempts.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: network_connection
    product: windows
detection:
    selection_ports:
        DestinationPort:
            - 80
            - 443
            - 8080
            - 8443
    filter_browsers:
        Image|endswith:
            - '\chrome.exe'
            - '\firefox.exe'
            - '\msedge.exe'
    filter_webservers:
        # Exclude loopbacks or proxy traffic from webservers
        Image|endswith:
            - '\w3wp.exe'
            - '\nginx.exe'
            - '\httpd.exe'
            - '\tomcat.exe'
    condition: selection_ports and not (filter_browsers or filter_webservers)
fields:
    - Image
    - DestinationIp
    - DestinationPort
    - User
falsepositives:
    - Administrative update engines or development tools communicating with web services.
level: low
tags:
    - attack.impact
    - attack.t1499.003
    - analytic.an1165
    - detection.det0415
```
