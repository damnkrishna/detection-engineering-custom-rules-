### 1. Technique Breakdown: T1491.002

* What it is: Defacement: External Defacement. Adversaries modify content or resources on external services (such as CDN endpoints, public DNS registries, or corporate landing pages hosted externally) to display messages, redirect traffic, or damage the organization's reputation.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688, and Sysmon File Creation/Modification events (Event ID 11).
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Outbound deployment script arguments and local DNS server zone file writes are monitored.
  - NIDS (Suricata + Zeek): NO. Host-local deployment or zone modification execution.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: CDN or External Hosting Update Command Line (AN1622-A)
id: 96c1e183-7a69-4c28-ab02-f262a24d7f19
status: experimental
description: Detects command-line arguments indicating CLI or scripting modifications targeting public CDN or cloud static assets.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\aws.exe'
            - '\az.exe'
            - '\python.exe'
            - '\node.exe'
    selection_cli:
        CommandLine|contains:
            - 's3 sync'
            - 's3 cp'
            - 'cdn profile'
            - 'cloudflare'
            - 'invalidate'
            - 'defaced'
    filter_cicd_images:
        Image|endswith:
            - '\gitlab-runner.exe'
            - '\agent.exe'
            - '\jenkins.exe'
            - '\tcagent.exe'
    filter_cicd_users:
        User|contains:
            - 'service'
            - 'build'
            - 'deploy'
    filter_installers:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: selection_images and selection_cli and not (filter_cicd_images or filter_cicd_users or filter_installers)
fields:
    - Image
    - CommandLine
    - User
falsepositives:
    - Legitimate CI/CD pipelines deploying standard corporate assets to public facing CDNs.
level: medium
tags:
    - attack.impact
    - attack.t1491.002
    - analytic.an1622
    - detection.det0590
```

```yaml
title: Local DNS Server Zone File Modification (AN1622-B)
id: 4a8670e1-72bc-436b-8edb-8c750eb241dc
status: experimental
description: Detects unauthorized edits to active DNS server zone files by non-DNS system processes.
author: Krishna Gupta
date: 2026-06-30

    product: windows
detection:
    selection_paths:

            - '\system32\dns\'

            - '.dns'
    filter_dns:

            - '\system32\dns.exe'
    condition: selection_paths and selection_exts and not filter_dns
fields:
    - TargetFilename
    - Image
    - User
falsepositives:
    - DNS administrators updating zone profiles via standard admin scripts (rare outside of controlled migration windows).
level: high

    - attack.impact

    - analytic.an1622
```
