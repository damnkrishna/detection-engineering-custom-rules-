### 1. Technique Breakdown: T1529

* What it is: System Shutdown/Reboot. Adversaries shut down or reboot target systems to interrupt operations, cover their tracks, or initiate process updates (like loading altered boot records or driver payloads). They achieve this using built-in utilities (like `shutdown.exe`) or administration scripting engines.
* Log Source Requirements: Sysmon Process Creation events (Event ID 1) / Security Event ID 4688, and Windows System Event Log (Event ID 1074 indicating shutdown/restart initiator).
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Invocations of shutdown commands are monitored. Windows System logs capture shutdown signals.
  - NIDS (Suricata + Zeek): NO. Host-local system state execution.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Local System Shutdown/Reboot Invocations (AN1538-A)
id: a5c9c7ac-97fb-4400-a7d4-4099731a94fd
status: experimental
description: Detects command-line execution of shutdown.exe or scripting utilities to shut down or restart the local system.
author: Krishna Gupta
date: 2026-06-30
logsource:
    category: process_creation
    product: windows
detection:
    selection_images:
        Image|endswith:
            - '\shutdown.exe'
    selection_args:
        CommandLine|contains:
            - ' /s'
            - ' /r'
            - ' -s'
            - ' -r'
            - ' /p'
            - ' /h'
    selection_powershell:
        CommandLine|contains:
            - 'Stop-Computer'
            - 'Restart-Computer'
    filter_system_images:
        ParentImage|endswith:
            - '\tiworker.exe'
            - '\svchost.exe'
            - '\trustedinstaller.exe'
    filter_system_user:
        User: 'NT AUTHORITY\SYSTEM'
    condition: ((selection_images and selection_args) or selection_powershell) and not (filter_system_images or filter_system_user)
fields:
    - Image
    - CommandLine
    - User
falsepositives:
    - Legitimate system restarts triggered by administrators or patching engines (e.g. Windows Update).
level: high
tags:
    - attack.impact
    - attack.t1529
    - analytic.an1538
    - detection.det0559
```

```yaml
title: Remote System Shutdown Invocations (AN1538-B)
id: 2bcffae0-bda6-4502-a420-9f8a642777e1

    selection_images:

            - '\shutdown.exe'

            - ' /m'

            - '\wmic.exe'
            - '\wbem\WmiPrvSE.exe'
        CommandLine|contains:
            - 'Win32_OperatingSystem'
            - 'Reboot'
            - 'Shutdown'
    condition: (selection_images and selection_remote_args) or selection_wmic
fields:
    - Image
    - CommandLine
    - User
falsepositives:
    - IT administrators remotely rebooting servers during maintenance windows.
level: high

    - attack.impact
    - attack.t1529
    - analytic.an1538
    - detection.det0559
```
