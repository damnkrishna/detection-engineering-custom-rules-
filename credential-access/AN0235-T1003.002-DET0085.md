### 1. Technique Breakdown: T1003.002

* What it is: OS Credential Dumping: Security Account Manager (SAM). Adversaries target the SAM database on Windows to extract local account credentials (NTLM hashes). This allows them to crack passwords offline or use the hashes directly for pass-the-hash attacks. The most common method is exporting the SAM, SYSTEM, and SECURITY registry hives using built-in tools like reg.exe.
* Log Source Requirements: Host process creation and command line logs (Sysmon Event ID 1 / Windows Security Event ID 4688) tracking execution, registry write logs (Sysmon Event ID 13), and file system logs (Sysmon Event ID 11) tracking file creation.
* Coverage Check:
  * HIDS (Sysmon + Windows Defender): YES. Sysmon Event ID 1 (Process Creation) captures reg.exe execution. Event ID 13 (Registry Set) captures modification to registry hives. Event ID 11 (File Event) captures raw registry hive dumps written to disk.
  * Windows Security Logs: YES. Standard Security Logs track process execution (Event ID 4688) containing the command line arguments.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 13 (registry_set)
  - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
  - None.
* Conclusion: SAM registry hive export attempts can be detected using process creation, registry modification, and file event logs.

### 2. Custom Sigma Rule

The detection logic is split into three rules targeting process creation, registry modifications, and file creation events respectively.

Rule 1 of 3: Suspicious SAM Registry Hive Export via CLI (Process Creation)
```yaml
title: Suspicious SAM Registry Hive Export via CLI (AN0235-A)
id: 5a415a72-68c8-4720-8025-a6abfa7216dc
status: experimental
description: Detects attempts to export the SAM, SYSTEM, or SECURITY registry hives using the reg.exe command line utility, indicating potential credential dumping.
author: Krishna Gupta
date: 2026-06-12
logsource:
    category: process_creation
    product: windows
detection:
    selection_img:
        - Image|endswith: '\reg.exe'
        - OriginalFileName: 'reg.exe'
    selection_action:
        CommandLine|contains:
            - 'save'
            - 'export'
            - 'backup'
    selection_target:
        CommandLine|contains:
            - 'HKLM\SAM'
            - 'HKLM\SYSTEM'
            - 'HKLM\SECURITY'
            - 'HKEY_LOCAL_MACHINE\SAM'
            - 'HKEY_LOCAL_MACHINE\SYSTEM'
            - 'HKEY_LOCAL_MACHINE\SECURITY'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: selection_img and selection_action and selection_target and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate system backup operations or imaging tools.
    - Rare administrative troubleshooting by IT personnel.
level: high
tags:
    - attack.credential-access
    - attack.t1003.002
    - analytic.an0235
    - detection.det0085
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Evasion via Volume Shadow Copies (VSS)
  * The Issue: Attackers don't have to use reg.exe. They can use vssadmin or WMI to create a volume shadow copy and simply copy the raw SAM files directly out of C:\Windows\System32\config\.
  * The Fix: Rely on Rule 3 (File Event) if they attempt to write the files to Temp folders, or create a separate correlation rule looking for vssadmin.exe create shadow combined with copy commands pointing to the config directory.

* Problem 2: API Abuse (In-Memory Dumping)
  * The Issue: Sophisticated malware or tools like Mimikatz don't spawn reg.exe. They make direct Windows API calls (like RegSaveKey) to dump the hives. Process creation logs (Event ID 1) will be completely blind to this.
  * The Fix: Monitor Registry Set events via Rule 2, or enable Registry Auditing (Event IDs 12, 13, 14) for the specific SAM/SYSTEM paths.

* Problem 3: Command Line Obfuscation
  * The Issue: cmd.exe allows for string splitting and character insertion. An attacker executing r^e^g s^a^v^e HKLM\SAM will bypass the literal string matches in the Sigma rule.
  * The Fix: Use OriginalFileName: 'reg.exe' to capture execution regardless of command obfuscation or binary renaming.

### 4. Test Cases (Engine Pipeline Verification)

#### True Positives
* True Positive 1: SAM Export via Reg.exe (Rule 1)
  * The Log: Process Activity with Image `reg.exe` and CommandLine `reg save HKLM\SAM C:\Temp\sam.save`.
  * Expected Outcome: Matches `selection_img`, `selection_action`, and `selection_target`. MUST trigger an alert.

* True Positive 2: Suspicious SAM Registry Set (Rule 2)
  * The Log: Registry Activity on `HKLM\SAM` by Image `C:\Temp\malware.exe`.
  * Expected Outcome: Matches `selection_target` and does not match `filter_system`. MUST trigger an alert.

* True Positive 3: SAM File Creation in Temp (Rule 3)
  * The Log: File Activity creating `C:\Temp\sam.bak` by Image `C:\Temp\malware.exe`.
  * Expected Outcome: Matches `selection_target` and `selection_files`, and does not match `filter_system`. MUST trigger an alert.

* True Positive 4: Malformed JSON Robustness Test (Rule 1)
  * The Log: Process Activity simulating TP-01 but intentionally omitting the `unmapped` object entirely.
  * Expected Outcome: Engine parser should degrade gracefully and still trigger the alert. MUST trigger an alert.

* True Positive 5: Schema Type Validation Failure (Rule 1)
  * The Log: Exact match of TP-01, but `activity_id` is passed as a string `"1"` instead of an integer `1`.
  * Expected Outcome: Tests if the engine's JSON parser crashes on type mismatches or coerces the type gracefully. MUST trigger an alert.

* True Positive 6: Exact Duplicate Event (Rule 1)
  * The Log: Exact duplicate of TP-01 with the exact same timestamp.
  * Expected Outcome: Tests if the engine's deduplication window correctly suppresses identical events.

#### Benign / True Negatives
* Benign 1: Administrator Backup (Rule 1 Filter)
  * The Log: Process Activity matching TP-01 but ParentImage is `msiexec.exe`.
  * Expected Outcome: Matches `filter_installer`. MUST NOT trigger an alert.

* Benign 2: System Service Registry Modification (Rule 2 Filter)
  * The Log: Registry Activity matching TP-02 but Image is `lsass.exe`.
  * Expected Outcome: Matches `filter_system`. MUST NOT trigger an alert.

* Benign 3: System Component File Creation (Rule 3 Filter)
  * The Log: File Activity matching TP-03 but Image is `C:\Windows\System32\wbem\wmiprvse.exe`.
  * Expected Outcome: Matches `filter_system`. MUST NOT trigger an alert.
