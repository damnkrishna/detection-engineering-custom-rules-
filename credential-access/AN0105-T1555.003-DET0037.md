### 1. Technique Breakdown: T1555.003

* What it is: Credentials from Password Stores: Credentials from Web Browsers. Adversaries search for and extract the local files where web browsers (like Chrome, Edge, and Firefox) store saved usernames, passwords, and session cookies. These are typically SQLite databases (like Login Data or Cookies) or JSON files.
* Log Source Requirements: Host process creation and command line logs (Sysmon Event ID 1 / Windows Security Event ID 4688) tracking execution, and file system logs (Sysmon Event ID 11) tracking file creation or access.
* Coverage Check:
  * HIDS (Sysmon + Windows Defender): YES. Sysmon Event ID 1 (Process Creation) is highly effective at catching Living off the Land (LotL) techniques where attackers use native commands (copy, xcopy, tar) to stage these database files for exfiltration. Sysmon Event ID 11 (File Event) tracks unauthorized files being accessed or copied by non-browser processes.
  * Windows Security Logs: YES. Standard Security Logs track process execution (Event ID 4688) containing the command line arguments.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 11 (file_event)
* Log Sources Missing / Unused:
  - None.
* Conclusion: Browser credential store access attempts using command line utilities can be detected using process creation and command line logs. Access by unauthorized processes to credential store files can be detected using file event logs.


* Benign 3: Brave Browser Operation (Rule 2 Filter)
  * The Log: File Event with Image `brave.exe` reading the Brave `Login Data` file.
  * Expected Outcome: The `Image` explicitly matches the `filter_browsers` allowlist (`\brave.exe`). MUST NOT trigger an alert.

### 2. Custom Sigma Rule

The detection logic is split into two rules targeting command line utility copy operations and direct file system access respectively.

Rule 1 of 2: Suspicious Browser Credential Store Access via CLI (Process Creation)
```yaml
title: Suspicious Browser Credential Store Access via CLI (AN0105-A)
id: 7c8e9d1a-4f5b-6a2c-3d8e-1f2a3b4c5d6e
status: experimental
description: Detects command-line operations attempting to copy, compress, or access web browser credential and cookie databases, indicating potential credential theft.
author: Krishna Gupta
date: 2026-06-12
logsource:
    category: process_creation
    product: windows
detection:
    selection_tools_image:
        Image|endswith:
            - '\cmd.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\xcopy.exe'
            - '\robocopy.exe'
            - '\tar.exe'
            - '\7z.exe'
    selection_tools_original:
        OriginalFileName:
            - 'Cmd.Exe'
            - 'PowerShell.EXE'
            - 'pwsh.dll'
            - 'xcopy.exe'
            - 'robocopy.exe'
            - 'tar.exe'
            - '7z.exe'
    selection_chrome_login:
        CommandLine|contains|all:
            - '\Google\Chrome\User Data\'
            - '\Login Data'
    selection_chrome_cookies:
        CommandLine|contains|all:
            - '\Google\Chrome\User Data\'
            - '\Network\Cookies'
    selection_edge_login:
        CommandLine|contains|all:
            - '\Microsoft\Edge\User Data\'
            - '\Login Data'
    selection_edge_cookies:
        CommandLine|contains|all:
            - '\Microsoft\Edge\User Data\'
            - '\Network\Cookies'
    selection_firefox:
        CommandLine|contains:
            - '\Mozilla\Firefox\Profiles\'
    selection_files:
        CommandLine|contains:
            - 'logins.json'
            - 'key4.db'
            - 'key3.db'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_tools_image or selection_tools_original) and (selection_chrome_login or selection_chrome_cookies or selection_edge_login or selection_edge_cookies or selection_firefox or selection_files) and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Legitimate browser profile migrations or backup scripts by administrators.
    - Endpoint management tools performing user state migrations.
level: high
tags:
    - attack.credential-access
    - attack.t1555.003
    - analytic.an0105
    - detection.det0037
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Info Stealers & API Abuse (The Biggest Blind Spot)
  * The Issue: Dedicated stealer malware (like RedLine, Vidar, or Lumma) does not spawn cmd.exe or xcopy.exe to grab these files. The malware process opens the SQLite database directly using Windows API calls. Sysmon Event ID 1 will completely miss this because the command line won't show the file path.
  * The Fix: Enable Windows Security Auditing for Object Access (Event ID 4663) specifically on those browser Login Data files, and then filter out the legitimate browser executable (e.g., alert if any process other than chrome.exe reads the Chrome Login Data file). Alternatively, rely on Rule 2 (File Event) when a non-whitelisted process accesses or stages these files.

* Problem 2: File Locking
  * The Issue: If the browser is open, the Login Data file is locked. Basic copy commands will fail. Advanced scripts will bypass this by making a shadow copy of the drive first, or by killing the browser process entirely.
  * The Fix: Cross-correlate this rule with unexpected taskkill /IM chrome.exe commands, or the Volume Shadow Copy creation rule.

* Problem 3: Path Variations
  * The Issue: Browsers support multiple profiles. If a user sets up a secondary profile, the path changes from \Default\Login Data to \Profile 1\Login Data.
  * The Fix: Check for broad keyword sequences like User Data or profile directories in target filenames and command lines, updating signatures as browser folder structures evolve.

### 4. Test Cases (Engine Pipeline Verification)

#### True Positives
* True Positive 1: Chrome Credential Access via CMD (Rule 1)
  * The Log: Process Creation (Sysmon Event ID 1 / Windows Security 4688) with Image `cmd.exe` and CommandLine `cmd.exe /c copy "C:\Users\Target\AppData\Local\Google\Chrome\User Data\Default\Login Data" C:\Temp\loot.db`
  * Expected Outcome: Matches `selection_tools_image` (`\cmd.exe`) AND `selection_chrome_login` keywords. MUST trigger an alert.

* True Positive 2: Firefox Profile Archiving via 7-Zip (Rule 1)
  * The Log: Process Creation (Sysmon Event ID 1 / Windows Security 4688) with Image `7z.exe` and CommandLine `7z.exe a -tzip C:\Temp\ff_loot.zip "C:\Users\Target\AppData\Roaming\Mozilla\Firefox\Profiles\*"`
  * Expected Outcome: Matches `selection_tools_image` (`\7z.exe`) AND `selection_firefox` keywords. MUST trigger an alert.

* True Positive 3: Edge Cookie Theft via PowerShell (Rule 1)
  * The Log: Process Creation (Sysmon Event ID 1 / Windows Security 4688) with Image `powershell.exe` and CommandLine `powershell -c Copy-Item "C:\Users\Target\AppData\Local\Microsoft\Edge\User Data\Default\Network\Cookies" -Destination "C:\Temp\cookies"`
  * Expected Outcome: Matches `selection_tools_image` (`\powershell.exe`) AND `selection_edge_cookies` keywords. MUST trigger an alert.

* True Positive 4: Direct File Read by Info Stealer Malware (Rule 2)
  * The Log: File Event (Sysmon Event ID 11 / OCSF file_activity) with Image `redline_stealer_x64.exe` and TargetFilename `C:\Users\Target\AppData\Local\Google\Chrome\User Data\Default\Login Data`
  * Expected Outcome: The path matches `selection_paths` and `selection_files`, and the image is not in `filter_browsers`. MUST trigger an alert.

* True Positive 5: Malformed JSON Robustness Test (Rule 1)
  * The Log: Process Creation (Sysmon Event ID 1 / OCSF process_activity) simulating TP-01 but intentionally omitting the `unmapped` object entirely to test parser fault tolerance.
  * Expected Outcome: Engine parser should degrade gracefully and still trigger the alert based on the existing `process.file.path` and `process.cmd_line` fields matching `selection_tools_image` and `selection_chrome_login`. MUST trigger an alert.


* True Positive 6: Renamed Binary Evasion (Rule 1)
  * The Log: Process Creation with Image `C:\Temp\totally_not_cmd.exe` but `unmapped.OriginalFileName` is `Cmd.Exe`.
  * Expected Outcome: Matches `selection_tools_original` instead of `selection_tools_image`. MUST trigger an alert.

* True Positive 7: Rule 2 Path Isolation (Rule 2)
  * The Log: File Event reading `C:\Users\Target\AppData\Local\Google\Chrome\User Data\Default\Preferences`.
  * Expected Outcome: Matches `selection_paths` but NOT `selection_files`, proving the OR logic works. MUST trigger an alert.

* True Positive 8: Schema Type Validation Failure (Rule 1)
  * The Log: Exact match of TP-01, but `activity_id` is passed as a string `"1"` instead of an integer `1`.
  * Expected Outcome: Tests if the engine's JSON parser crashes on type mismatches or coerces the type gracefully. MUST trigger an alert (if coercion succeeds) or log a parser error.

* True Positive 9: Exact Duplicate Event (Rule 1)
  * The Log: Exact duplicate of TP-01 with the exact same timestamp.
  * Expected Outcome: Tests if the engine's deduplication window correctly suppresses or passes identical events.

#### Benign / True Negatives
* Benign 1: Legitimate Browser Operation (Rule 2 Filter)
  * The Log: File Event (Sysmon Event ID 11 / OCSF file_activity) with Image `chrome.exe` and TargetFilename `C:\Users\Target\AppData\Local\Google\Chrome\User Data\Default\Login Data`
  * Expected Outcome: The `Image` explicitly matches the `filter_browsers` allowlist (`\chrome.exe`). MUST NOT trigger an alert.

* Benign 2: Legitimate Administrator Backup (Rule 1 Filter)

  * Expected Outcome: Even though the command line matches theft parameters, it is executed by an installer (`ParentImage: \msiexec.exe`), matching the `filter_installer` allowlist. MUST NOT trigger an alert.
