### 1. Technique Breakdown: T1552

* What it is: Unsecured Credentials. Adversaries may search for unsecured credentials stored in files, registry, or configuration files on compromised systems to obtain them for lateral movement or privilege escalation.
* Log Source Requirements: Sysmon Process Creation (Event ID 1) / Windows Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Command-line credential searches are captured.
  - NIDS (Suricata + Zeek): NO. Host-local file access.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

#### Rule 1 of 1: Credential String Search in Files and Registry
Detects the use of findstr or reg query to search for password strings stored in plaintext files or registry keys.

```yaml
title: Credential String Search in Files and Registry (AN2103)
id: 2a8c5e71-3f9b-4d26-c8e1-7b4d9a15f263
status: experimental
description: Detects findstr.exe or reg.exe being used to search for plaintext password strings in files or registry, indicating unsecured credential harvesting. Includes OriginalFileName to resist binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_findstr:
        Image|endswith:
            - '\findstr.exe'
    selection_findstr_ofn:
        OriginalFileName: 'FINDSTR.EXE'
    selection_findstr_cli:
        CommandLine|re:
            - '(?i)\b(password|passwd|credentials|connectionstring)\b'
    selection_reg:
        Image|endswith:
            - '\reg.exe'
    selection_reg_ofn:
        OriginalFileName: 'reg.exe'
    selection_reg_cli:
        CommandLine|contains:
            - 'password'
            - 'passwd'
            - 'DefaultPassword'
            - 'AutoAdminLogon'
    filter_av_scan:
        ParentImage|endswith:
            - '\MsMpEng.exe'
            - '\SenseCnfg.exe'
    condition: (((selection_findstr or selection_findstr_ofn) and selection_findstr_cli) or ((selection_reg or selection_reg_ofn) and selection_reg_cli)) and not filter_av_scan
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Security scanners or vulnerability assessment tools searching for plaintext credential exposure.
level: high
tags:
    - attack.credential_access
    - attack.t1552
    - analytic.an2103
    - detection.det0960
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: PowerShell Credential Search
  * The Issue: `Select-String` or `Get-Content | Where-Object` in PowerShell achieves the same result without invoking findstr.exe.
  * The Fix: Monitor PowerShell Script Block Logging (Event ID 4104) for password/credential string searches.
* Problem 2: Case Sensitivity
  * The Issue: `PASSWORD`, `Password`, `password` are all common variants. Sigma's `contains` is case-insensitive by default in most SIEM implementations, but verify your deployment.
  * The Fix: Confirm case-insensitive matching is enabled in your SIEM's Sigma translation backend.
* Problem 3: OriginalFileName availability
  * The Issue: OriginalFileName is only present when PE metadata is intact.
  * The Fix: Treat Image and OriginalFileName as complementary — either match alone is sufficient.
