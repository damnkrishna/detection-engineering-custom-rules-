### 1. Technique Breakdown: T1552

* What it is: Unsecured Credentials. Adversaries may search for unsecured credentials stored in files, registry, or configuration files on compromised systems to obtain them for lateral movement or privilege escalation.
* Log Source Requirements: Sysmon Process Creation (Event ID 1) / Windows Event ID 4688.
* Coverage Check:
  - HIDS (Sysmon + Windows Defender): YES. Command-line credential searches are captured.
  - NIDS (Suricata + Zeek): NO. Host-local file access.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Credential String Search in Files and Registry (AN2103)
id: 435a077a-9f71-484a-bd9f-5ef592f258f5
status: experimental
description: Detects findstr.exe or reg.exe being used to search for plaintext password strings in files or registry, indicating unsecured credential harvesting. Includes OriginalFileName to resist binary-rename evasion.
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_findstr:
        Image|endswith:
            - '\findstr.exe'
    selection_findstr_ofn:
        OriginalFileName: 'FINDSTR.EXE'
    selection_findstr_cli:
        CommandLine|re:
            - '(?i)\b(password|passwd|credentials|connectionstring)\b'
    selection_reg:
        Image|endswith:
            - '\reg.exe'
    selection_reg_ofn:
        OriginalFileName: 'reg.exe'
    selection_reg_cli:
        CommandLine|contains:
            - 'password'
            - 'passwd'
            - 'DefaultPassword'
            - 'AutoAdminLogon'
    filter_av_scan:
        ParentImage|endswith:
            - '\MsMpEng.exe'
            - '\SenseCnfg.exe'
    condition: (((selection_findstr or selection_findstr_ofn) and selection_findstr_cli) or ((selection_reg or selection_reg_ofn) and selection_reg_cli)) and not filter_av_scan
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Security scanners or vulnerability assessment tools searching for plaintext credential exposure.
level: high
tags:
    - attack.credential_access
    - attack.t1552
    - analytic.an2103
    - detection.det0960
```

status: experimental
description: 'OCSF Normalized rule for Credential String Search in Files and Registry (AN2103)'

    product: ocsf

            - '\findstr.exe'

        process.file.name: 'FINDSTR.EXE'

            - '(?i)\b(password|passwd|credentials|connectionstring)\b'
    selection_reg:
        process.file.path|endswith:
            - '\reg.exe'

            - 'password'

            - '\MsMpEng.exe'

    - time
level: high

    - attack.credential_access
