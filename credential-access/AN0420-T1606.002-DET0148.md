### 1. Technique Breakdown: T1606.002

* What it is: Forge Web Credentials: SAML Tokens (widely known as a Golden SAML attack). Adversaries who compromise an Identity Provider (IdP) like Active Directory Federation Services (AD FS) steal the token-signing certificate and the Distributed Key Manager (DKM) key. With these secrets, they can offline-forge perfectly valid SAML tokens. This allows them to bypass multi-factor authentication (MFA) and access federated cloud services (like Microsoft 365 or AWS) as any user in the domain.
* Log Source Requirements: Endpoint process execution, WMI querying, or file access monitoring on the AD FS server, and PowerShell script block logging (Sysmon Event ID 4104).
* Coverage Check:
  * HIDS (Sysmon + Windows Defender): YES. Sysmon Event ID 1 (Process Creation) can catch the attacker executing tools on the AD FS server to extract the certificates and keys from the Windows Internal Database (WID) or via PowerShell. Sysmon Event ID 4104 (Script Block) is effective at catching script-based queries.
  * Windows Security Logs: YES. Standard Security Logs track process execution (Event ID 4688) containing the command line arguments.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 4104 (ps_script)
* Log Sources Missing / Unused:
  - None.
* Conclusion: AD FS SAML certificate extraction attempts on local endpoints can be detected using process creation and PowerShell script block logs.

### 2. Custom Sigma Rule

The detection logic is split into command-line execution monitoring and script block content monitoring.

Rule 1 of 2: Suspicious AD FS Database Query for SAML Certificate Extraction via CLI (Process Creation)
```yaml
title: Suspicious AD FS Database Query for SAML Certificate Extraction via CLI (AN0420-A)
id: 4f3a2b1c-8d7e-9f0a-1b2c-3d4e5f6a7b8c
status: experimental
description: Detects command-line execution attempting to query the Windows Internal Database (WID) to extract AD FS configuration and token-signing certificates, a precursor to Golden SAML token forging.
author: Krishna Gupta
date: 2026-06-12
logsource:
    category: process_creation
    product: windows
detection:
    selection_sqlcmd_image:
        Image|endswith: '\sqlcmd.exe'
    selection_sqlcmd_original:
        OriginalFileName: 'SQLCMD.EXE'
    selection_pipe:
        CommandLine|contains:
            - 'np:\\.\pipe\microsoft##ssee\tsql\query'
            - 'np:\\.\pipe\WID\tsql\query'
    selection_db:
        CommandLine|contains:
            - 'AdfsConfiguration'
            - 'IdentityServerPolicy'
    selection_adfs_tools:
        CommandLine|contains:
            - 'ADFSpoof'
            - 'Export-AdfsCertificate'
    selection_shells_image:
        Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\cmd.exe'
    selection_shells_original:
        OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.dll'
            - 'Cmd.Exe'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (( (selection_sqlcmd_image or selection_sqlcmd_original) and selection_pipe and selection_db ) or ( (selection_shells_image or selection_shells_original) and selection_adfs_tools )) and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Rare AD FS backup or migration scripts executed by identity administrators.
level: critical
tags:
    - attack.credential-access
    - attack.defense-evasion
    - attack.t1606.002
    - analytic.an0420
    - detection.det0148
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Cloud Token Usage
  * The Issue: Once certificate material is stolen, usage occurs off-network on cloud endpoints.
  * The Fix: Ingest cloud identity logs to perform correlation between SAML logins and anomalous user profiles.

* Problem 2: WMI/API-Based Extraction
  * The Issue: Attackers can call WMI namespaces directly (ROOT\ADFS) rather than running sqlcmd.exe.
  * The Fix: Enable auditing for WMI Activity Event IDs 5858, 5859, 5861 on AD FS hosts.

* Problem 3: DKM Key Stealing
  * The Issue: Decrypting the AD FS certificate requires the Active Directory Distributed Key Manager (DKM) key.
  * The Fix: Target AD replication queries (Event ID 4662) targeting the DKM container by non-DC hosts.

### 4. Test Cases (Engine Pipeline Verification)

#### True Positives
* True Positive 1: AD FS WID Query (Rule 1)
  * The Log: Process Activity with Image `sqlcmd.exe` and CommandLine `sqlcmd.exe -S np:\\.\pipe\microsoft##ssee\tsql\query -Q "SELECT * FROM AdfsConfiguration"`.
  * Expected Outcome: Matches `selection_sqlcmd`, `selection_pipe`, and `selection_db`. MUST trigger an alert.

* True Positive 2: PowerShell AD FS Certificate Export (Rule 2)
  * The Log: Process Activity with CommandLine containing `Export-AdfsCertificate`.
  * Expected Outcome: Matches `selection_keywords`. MUST trigger an alert.

* True Positive 3: Malformed JSON Robustness Test (Rule 1)
  * The Log: Process Activity simulating TP-01 but intentionally omitting the `unmapped` object entirely.
  * Expected Outcome: Engine parser should degrade gracefully and still trigger the alert. MUST trigger an alert.

* True Positive 4: Schema Type Validation Failure (Rule 1)
  * The Log: Exact match of TP-01, but `activity_id` is passed as a string `"1"` instead of an integer `1`.
  * Expected Outcome: Tests if the engine's JSON parser crashes on type mismatches or coerces the type gracefully. MUST trigger an alert.

* True Positive 5: Exact Duplicate Event (Rule 1)
  * The Log: Exact duplicate of TP-01 with the exact same timestamp.
  * Expected Outcome: Tests if the engine's deduplication window correctly suppresses identical events.

#### Benign / True Negatives
* Benign 1: Installer Executing SQLCMD (Rule 1 Filter)
  * The Log: Process Activity matching TP-01 but ParentImage is `msiexec.exe`.
  * Expected Outcome: Matches `filter_installer`. MUST NOT trigger an alert.
