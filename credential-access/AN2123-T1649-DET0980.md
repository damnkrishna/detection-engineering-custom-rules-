### 1. Technique Breakdown: T1649

* What it is: Steal or Forge Authentication Certificates. Adversaries may steal private keys or certificates, or forge certificates, to authenticate as users or computers, or to establish secure tunnels. This is monitored by detecting commands attempting to export certificates (using parameters like `exportPFX`) or execution of credential recovery tools targeting certificate structures (such as `Certify.exe`).
* Log Source Requirements:
  * Sysmon Process Creation (Event ID 1) capturing command line keywords related to certificate and private key export/theft.
* Coverage Check:
  * HIDS (Sysmon): YES. Certificate management utilities run via command line leave process telemetry.
  * NIDS (Zeek/Suricata): NO. local exporting of certificates is not visible on the network interface.
* Log Sources Covered:
  * Sysmon Event ID 1 (process_creation)
* Log Sources Missing / Unused:
  * None.

### 2. Custom Sigma Rule

```yaml
title: Authentication Certificate or Private Key Export Tool Execution (AN2123)
id: 5d17fc7f-9fab-4838-ab02-0115ca5f13f5
status: experimental
description: "Detects the execution of known AD CS enumeration tools (e.g. Certify) or command-line parameters attempting to export authentication certificates and private keys (such as certutil.exe -exportPFX or similar commands) to steal credentials."
author: Krishna Gupta
date: 2026-07-01
logsource:
    category: process_creation
    product: windows
detection:
    selection_certify:
        Image|endswith: '\certify.exe'
    selection_certify_ofn:
        OriginalFileName: 'Certify.exe'
    selection_export_images:
        Image|endswith:
            - '\certutil.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
    selection_export_ofn:
        OriginalFileName:
            - 'certutil.exe'
            - 'PowerShell.EXE'
            - 'pwsh.exe'
    selection_export_cli:
        CommandLine|contains:
            - '-exportPFX'
            - '-exportpfx'
            - 'Export-PfxCertificate'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_certify or selection_certify_ofn or ((selection_export_images or selection_export_ofn) and selection_export_cli)) and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - User
falsepositives:
    - Administrators legitimately backing up server certificates or exporting public keys for deployment.
level: high
tags:
    - attack.credential-access
    - attack.t1649
    - analytic.an2123
    - detection.det0980
```

### 3. OCSF Normalized Rule

```yaml
title: 'Authentication Certificate or Private Key Export Tool Execution (AN2123) (OCSF-Normalized)'
id: '5d17fc7f-9fab-4838-ab02-0115ca5f13f5'
status: experimental
description: 'OCSF Normalized rule for Authentication Certificate or Private Key Export Tool Execution (AN2123)'
author: Krishna Gupta
logsource:
    product: ocsf
    class: process_activity
detection:
    selection_certify:
        process.file.path|endswith: '\certify.exe'
    selection_certify_ofn:
        process.file.name: 'Certify.exe'
    selection_export_images:
        process.file.path|endswith:
            - '\certutil.exe'
            - '\powershell.exe'
            - '\pwsh.exe'
    selection_export_ofn:
        process.file.name:
            - 'certutil.exe'
            - 'PowerShell.EXE'
            - 'pwsh.exe'
    selection_export_cli:
        process.cmd_line|contains:
            - '-exportPFX'
            - '-exportpfx'
            - 'Export-PfxCertificate'
    filter_installer:
        unmapped.parent_image|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_certify or selection_certify_ofn or ((selection_export_images or selection_export_ofn) and selection_export_cli)) and not filter_installer
fields:
    - time
level: high
tags:
    - attack.credential-access
    - attack.t1649
    - analytic.an2123
    - detection.det0980
```
