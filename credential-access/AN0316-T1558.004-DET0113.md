### 1. Technique Breakdown: T1558.004

* What it is: Steal or Forge Kerberos Tickets: AS-REP Roasting. Adversaries hunt for Active Directory user accounts that have the "Do not require Kerberos preauthentication" flag enabled. If this flag is set, anyone can request an Authentication Service (AS) ticket for that user. The Domain Controller will respond with an AS-REP message that contains a chunk of data encrypted with the user's password hash. The attacker saves this data and cracks it offline.
* Log Source Requirements: Host process creation and command line logs (Sysmon Event ID 1 / Windows Security Event ID 4688) tracking execution, and PowerShell script block logs (Sysmon Event ID 4104).
* Coverage Check:
  * HIDS (Sysmon + Windows Defender): YES. Sysmon Event ID 1 (Process Creation) is great for catching the command-line execution of tools like Rubeus, PowerView, or Impacket. Sysmon Event ID 4104 (Script Block) captures scripts performing these operations in memory.
  * Windows Security Logs: YES. Standard Security Logs track process execution (Event ID 4688) containing the command line arguments.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 4104 (ps_script)
* Log Sources Missing / Unused:
  - None.
* Conclusion: AS-REP roasting tool execution on local endpoints can be detected using process creation and PowerShell script block logs.

### 2. Custom Sigma Rule

The detection logic is split into command-line execution monitoring and script block content monitoring.

Rule 1 of 2: AS-REP Roasting Tool Execution via CLI (Process Creation)
```yaml
title: AS-REP Roasting Tool Execution via CLI (AN0316-A)
id: 8a4c3f1b-7d2e-491a-b60c-5e9f2d1a3b4c
status: experimental
description: Detects command-line parameters associated with AS-REP Roasting attacks, targeting accounts with Kerberos pre-authentication disabled to extract crackable hashes.
author: Krishna Gupta
date: 2026-06-12
logsource:
    category: process_creation
    product: windows
detection:
    selection_rubeus_cmd:
        CommandLine|contains:
            - 'asreproast'
    selection_powerview:
        CommandLine|contains:
            - 'PreauthNotRequired'
    selection_impacket:
        CommandLine|contains:
            - 'GetNPUsers'
    selection_shells_image:
        Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
            - '\cmd.exe'
    selection_shells_original:
        OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.dll'
            - 'Cmd.Exe'
    filter_installer:
        ParentImage|endswith:
            - '\msiexec.exe'
            - '\setup.exe'
    condition: (selection_rubeus_cmd or ( (selection_shells_image or selection_shells_original) and (selection_powerview or selection_impacket) )) and not filter_installer
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Internal security teams conducting routine Active Directory misconfiguration audits.
    - Automated IAM tools querying for vulnerable account flags.
level: high
tags:
    - attack.credential-access
    - attack.t1558.004
    - analytic.an0316
    - detection.det0113
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Rogue Devices (Out-of-Band Attack)
  * The Issue: If an attacker roasts AD accounts from a rogue Linux host on the network, local endpoint Sysmon logs will show no process or command line activity.
  * The Fix: Enable Domain Controller Kerberos Event ID 4768 auditing (Pre-Authentication Type=0, Encryption=0x17) or capture network traffic patterns.

* Problem 2: Script Block Logging Disabled
  * The Issue: If Script Block Logging is disabled, in-memory script execution won't be captured.
  * The Fix: Monitor process creation telemetry and ensure Script Block logging compliance across all domain hosts.

* Problem 3: Routine Auditing Noise
  * The Issue: Legitimate AD audit scanners might trigger these alerts.
  * The Fix: Baseline administrative service accounts and exclude them from alerting when using specific domain query tools.
