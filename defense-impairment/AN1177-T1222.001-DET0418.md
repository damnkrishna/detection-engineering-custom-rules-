### 1. Technique Breakdown: T1222.001

* What it is: File and Directory Permissions Modification: Windows Permissions. Adversaries modify Discretionary Access Control Lists (DACLs) and permissions using native Windows utilities (like `icacls.exe`, `takeown.exe`, `attrib.exe`) to access restricted files, hide malicious artifacts, or weaken system defenses.
* Log Source Requirements: Process creation logs (Sysmon Event ID 1 / Windows Security Event ID 4688) and Object Access logs (Windows Security Event ID 4670 - Permissions changed).
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 logs the execution of utilities like `icacls.exe` and their command-line arguments.
    * NIDS (Suricata + Zeek): NO. File permissions manipulation is a local host filesystem activity.

### 2. Custom Sigma Rule

This rule utilizes Sysmon Event ID 1 (Process Creation) to detect the execution of native Windows permission modification utilities with suspicious parameters indicating intent to grant access or take ownership.

```yaml
title: File and Directory Permissions Modification (AN1177)
id: cb120e3f-6772-4d1a-8288-51f7bb9183cc
status: experimental
description: Detects the execution of permission-modifying utilities with suspicious parameters indicating privilege escalation intent.
author: Krishna Gupta
date: 2026-06-09
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_tools:
        Image|endswith:
            - '\icacls.exe'
            - '\takeown.exe'
            - '\cacls.exe'
    selection_args:
        CommandLine|contains:
            - '/grant'
            - '/takeown'
            - 'Set-Acl'
            - 'Everyone:F'
    condition: selection_tools and selection_args
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - System administrators managing file shares or restoring backups.
    - Software installers configuring application directories.
level: medium
tags:
    - attack.defense-evasion
    - attack.t1222.001
    - analytic.an1177
    - detection.det0418
```

### 3. Blind Spots & Tuning (The "Problems")

* Problem 1: Command Line Obfuscation
  * The Issue: Adversaries can obfuscate command-line arguments using environment variables, caret escapes (^), or base64 encoding, evading simple string matching.
  * The Fix: Implement PowerShell Script Block Logging and utilize regex or script-decoding scripts in the SIEM to check arguments.

* Problem 2: Administrative Activity Noise
  * The Issue: IT administrators legitimately run command-line tools or installers that trigger these rules during system maintenance.
  * The Fix: Establish a baseline of legitimate admin tools, whitelisting specific administrative account names or management servers.

* Problem 3: Masquerading via Renamed Binaries
  * The Issue: Attackers rename native Windows utilities (such as net.exe or cmd.exe) to custom filenames to bypass path-based filters.
  * The Fix: Incorporate Masquerade-resistant criteria, matching on OriginalFileName rather than the static Image path in process creation logs.
