### 1. Technique Breakdown: T1553.003

* What it is: Subvert Trust Controls: SIP and Trust Provider Hijacking. Adversaries may hijack Subject Interface Packages (SIPs) and Trust Providers in Windows to bypass code signing protections. By modifying registry keys associated with `Cryptography\Providers\Trust`, attackers can force Windows to use a malicious DLL to validate digital signatures. This causes the OS to falsely trust unsigned or maliciously signed files.
* Log Source Requirements: Registry modification logs (Sysmon Event ID 13/14) and Image Load logs (Sysmon Event ID 7).
* Coverage Check:
    * HIDS (Sysmon + Wazuh): YES. Sysmon Event IDs 12/13/14 monitor registry keys. Sysmon Event ID 7 can capture the loading of non-Microsoft DLLs into processes like `signtool.exe` or `explorer.exe`.
    * NIDS (Suricata + Zeek): NO. Registry tampering and trust provider validation occur strictly at the OS level.

### 2. Custom Sigma Rule

```yaml
title: SIP and Trust Provider Hijacking (AN1222)
id: 7a8a1ac5-21a4-4f2b-a48b-f55ae2c9f8eb
status: experimental
description: Detects abnormal registry modifications to Subject Interface Packages (SIPs) and Trust Providers.
author: Krishna Gupta
date: 2026-06-09
logsource:
    category: registry_set
    product: windows
    # Relies on Sysmon Event ID 13
detection:
    selection_keys:
        TargetObject|contains:
            - 'SOFTWARE\Microsoft\Cryptography\Providers\Trust'
            - 'SOFTWARE\Microsoft\Cryptography\OID\EncodingType 0\CryptSIPDll'
    condition: selection_keys
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - TargetObject
    - Details
    - User
    - LogonId
falsepositives:
    - Installation of legitimate third-party security software or custom trust providers.
    - Major Windows OS upgrades patching cryptographic components.
level: high
tags:
    - attack.defense-evasion
    - attack.t1553.003
    - analytic.an1222
    - detection.det0442
```
