### 1. Technique Breakdown: T1484

* What it is: Domain or Tenant Policy Modification. Adversaries modify domain or tenant policies to establish persistence, elevate privileges, or facilitate lateral movement. In Active Directory, this includes modifying GPOs, altering domain trust relationships (to allow access from external malicious domains), or changing directory service object permissions (to grant replication/delegation rights). Adversaries use CLI tools like `netdom.exe`, `nltest.exe`, or PowerShell AD modules to make these modifications.
* Log Source Requirements: Endpoint logs capturing process creation and command line parameters (specifically targeting administrative Active Directory and trust management utilities).
* Coverage Check:
* HIDS (Sysmon + Wazuh): YES. Sysmon Event ID 1 (Process Creation) logs the execution of utilities like `netdom.exe`, `nltest.exe`, or PowerShell Active Directory cmdlets.
* NIDS (Suricata + Zeek): NO. Trust and policy modifications are local configurations or RPC-based changes. Network logs can capture the replication or RPC calls (like `DRSUAPI`), but do not parse them as policy modification events.
* Log Sources Covered:
  - Sysmon Event ID 1 (process_creation)
  - Sysmon Event ID 4104 (ps_script)
* Log Sources Missing / Unused:
  - None.

### 2. Custom Sigma Rule

```yaml
title: Command-Line Domain Trust or Policy Modification (AN0755)
id: 3d6a93fc-a1e0-4472-a102-9b8b5da8b4c9
status: experimental
description: Detects command-line execution of netdom.exe, nltest.exe, or PowerShell Active Directory cmdlets used to modify domain trust relationships, register rogue domain controllers, or alter domain policy.
author: Krishna Gupta
date: 2026-06-07
logsource:
    category: process_creation
    product: windows
    # Relies on Sysmon Event ID 1
detection:
    selection_netdom:
        - Image|endswith: '\netdom.exe'
        - OriginalFileName: 'netdom.exe'
    selection_netdom_args:
        CommandLine|contains:
            - 'trust'
            - 'member'
    selection_nltest:
        - Image|endswith: '\nltest.exe'
        - OriginalFileName: 'nltest.exe'
    selection_nltest_args:
        CommandLine|contains:
            - '/trust_commit'
            - '/dsreg'
            - '/domain_trusts'
    selection_powershell:
        - Image|endswith:
            - '\powershell.exe'
            - '\pwsh.exe'
        - OriginalFileName:
            - 'PowerShell.EXE'
            - 'pwsh.dll'
    selection_powershell_cmdlets:
        CommandLine|contains:
            - 'Add-ADDomainTrust'
            - 'Remove-ADDomainTrust'
            - 'Set-ADDomainTrust'
    condition: (selection_netdom and selection_netdom_args) or (selection_nltest and selection_nltest_args) or (selection_powershell and selection_powershell_cmdlets)
fields:
    - Image
    - OriginalFileName
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - CurrentDirectory
    - User
    - LogonId
falsepositives:
    - Authorized active directory migration activities or configuration of cross-forest trusts by enterprise domain administrators.
level: high
tags:
    - attack.defense-evasion
    - attack.privilege-escalation
    - attack.t1484
    - analytic.an0755
    - detection.det0270
```
